Mètodes de les llistes en JavaScript

Mètodes dels arrays

Alguns mètodes modifiquen la mateixa llista; altres no la modifiquen però retornen una llista nova; alguns modifiquen la llista i retornen una llista nova.

Mostrar tots els elements de l'array

Si és necessari, un array es converteix automàticament a un string separant els elements amb una coma:

let cicles = ["SMX", "DAW"];
alert(cicles);    // Escriu 'SMX,DAW'

Si es vol un altre tipus de separador, es pot utilitzar la comanda join():

let cicles = ["SMX", "DAW"];
alert(cicles.join(" - "));    // Escriu 'SMX - DAW'

Recórrer tots els elements d'un array

Es pot accedir a tots els elements utilitzant bucles (for, while...).

Si es fa així cal saber quants elements té l'array.
Aquest valor es troba a la propietat length:

let cicles = ["SMX", "ASX", "DAW"];

for (let i = 0; i < cicles.length; i++) {
  console.log("\n" + cicles[i]);
}

for ... of

També es pot utilitzar for ... of (no confondre amb for ... in).

Cal utilitzar una variable (en aquest cas c) a la qual s'assigna un element diferent de la llista (en aquest cas cicles) en cada iteració del bucle:

let cicles = ["SMX", "ASX", "DAW"];

for (let c of cicles) {
  console.log("\n" + c);
}

Funcions per buscar elements dins d'un array

  • includes(v): retorna true si existeix el valor v dins de l'array.
  • indexOf(v): retorna l'index del primer element amb el valor v.
    Opcionalment es pot indicar a partir de quin índex s'ha de començar a buscar.
  • lastIndexOf(v): igual que l'anterior, però comença a buscar pel final.

Ordenar l'array

La comanda sort() ordena l'array alfabèticament de més petit a més gran.

La comanda reverse() inverteix la posició de tots els elements: si es vol ordenar un array inversament, primer s'utilitza la comanda sort() i després reverse().

Si l'array conté números, l'ordre pot ser incorrecte: el número 2 es posaria després del 10.
En aquest cas es pot ordenar utilitzant una funció personalitzada que indiqui si un element és més gran, més petit o igual que un altre.
Aquesta funció ha de retornar:

  • Un número negatiu (< 0) si el primer element és menor que el segon.
  • Un número positiu (> 0) si el primer element és més gran que el segon.
  • 0 (zero) si els dos elements són iguals.

let edats = [35, 9, 18];

function ordreXY(x, y) {
  if (x < y) return -1;
  else if (x > y) return 1;
  else return 0;
  // return x - y;    // Opció més simplificada
}

edats.sort();          // edats = [18, 35, 9];
edats.sort(ordreXY);   // edats = [9, 18, 35];
edats.reverse();       // edats = [35, 18, 9];

Altres funcions

  • string.split(separador): genera un array separant un string. Cal indicar el caràcter o caràcters que es buscaran per fer la separació.
  • slice(ini, fi): genera una nova llista amb els elements entre ini (inclòs) i fi (no inclòs).
    Tots dos paràmetres són opcionals i també poden tenir valors negatius.
  • splice(): permet afegir o eliminar elements a una llista (pot tenir deiferents paràmetres).
