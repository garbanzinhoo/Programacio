Tipus de dades simples

Literal, constant o variable?

En el següent codi, identifica quins elements són literals, quins són constants i quins són variables:

final String LLETRES = "TRWAGMYFPDXBNJZSQVHLCKE";
final int DNI = 12345678;
int residu = DNI % 23;
char lletra = LLETRES.charAt(residu);
System.out.println("La lletra del DNI " + DNI + " és " + lletra);

El tipus de dada més adient

Quin tipus de dada és el més adequat per emmagatzemar els següents valors?

  • L'edat d'una persona
  • El preu d'un ordinador
  • Si ets major d'edat
  • El nombre d'alumnes de l'institut Sa Palomera (o similar)
  • La lletra del DNI
  • El número PI
  • El nom d'una persona
  • El nombre d'habitants de Catalunya
  • El resultat de calcular l'area d'un cercle
  • La quantitat de bytes que hi caben en un disc d'un TB (terabyte)

Treballa amb l'IDE

Copia el següent codi en el teu IDE i fes les següents accions:

  • Defineix el tipus que creguis més convenient per a cada variable
  • Pensa on es poden produir errors al compilar
  • Corregeix els errors
  • Pensa quin resultat obtindràs quan executis el programa
  • Executa el programa i comprova si el resultat és l'esperat

a = 512343;
b = 3431231;
System.out.println(a + b);
