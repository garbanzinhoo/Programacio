Constants

Importància de l'utilització de constants

Quan un comença a programar no acostuma a utilitzar constants.

Si es pot utilitzar directament un valor literal...

if (nota > 10) alert("La nota no pot ser superior a 10");

... perquè cal definir una constant?

const NOTA_MAX = 10;
...
if (nota > NOTA_MAX) alert("La nota no pot ser superior a " + NOTA_MAX);

Avantatges d'utilitzar constants

  • Utilitzar un nom en lloc d'un número ens dóna més informació de per a què serveix aquella dada:
    NOTA_MAX dóna molta més informació que 10.
  • Si cal canviar el valor, només cal fer-ho en el lloc on està definida la constant:
    no cal buscar i substituir en tot el document (es poden substituir valors que no toca o deixar-se'n algun).
  • Pot ser més endavant sigui necessari canviar el valor o canviar la constant per una variable.

Exemples d'utilització

Les constants no serveixen només per substituir valors numèrics.
També es poden utilitzar per representar cadenes de caràcters, missatges d'error o, fins i tot, objectes.

Exemple 1

Utilitzar constants per definir missatges d'error:

const NUM_DIGITS_DNI = 8;
const ERROR_NUM_DIGITS = "El nombre de dígits del DNI ha de ser 8.";
const ERROR_LLETRA_DNI = "La lletra del DNI no és correcta.";
...
if (dni.length() != NUM_DIGITS_DNI) alert(ERROR_NUM_DIGITS);
if (!comprovarLletraDNI(dni, lletra)) alert(ERROR_LLETRA_DNI);

Exemple 2

Utilitzar constants amb objectes per associar valors numérics amb text:

const SUSPEN = {valor:2, nota:"Suspén"};
const MILLORAR = {valor:4, nota:"Necessita millorar"};
const PROGRESSA = {valor:6, nota:"Progressa adequadament"};
const MOLTBE = {valor:8, nota:"Molt bé!"};
...

Exemple 3

Suposem que en un joc hi ha un conjunt d'objectes disposats en files i columnes, i en diverses parts del programa es necessita saber el nombre de files i columnes.

Si després de provar el joc es decideix que el nombre de files i/o columnes és massa gran (o massa petit), només serà necessari canviar el valor en la definició d'aquestes constants.

Millor encara: si més endavant es decideix que, al passar a nivells més difícils, és convenient augmentar el nombre de files i/o columnes, només caldrà convertir aquestes constants en variables i modificar-les convenientment cada cop que el jugador passi al següent nivell.
