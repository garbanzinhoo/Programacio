String (cadena de caràcters)

Els objectes creats amb la classe String són immutables.
Això vol dir que, un cop creats, no es poden modificar directament.

Alguns mètodes d'aquesta classe serveixen per fer modificacions però retornen un nou objecte que es pot guardar en una variable diferent o en la mateixa variable:

String hola = "HOLA";
hola.replace('A', 'I');          // NO FA CAP CANVI A LA VARIABLE hola!
hola = hola.replace('A', 'I');   // ARA SÍ

També es pot utilitzar l'operador + per concatenar diferents strings, però el resultat, si no es mostra immediatament, també s'ha de guardar en algun lloc.

String hola = "Hello";
String mon = "World";
hola = hola + " " + mon;

Per comparar dues strings no es poden utilitzar els comparadors ==, !=, <, >, <= o >=.
S'han d'utilitzar els mètodes equals(), equalsIgnoreCase(), compareTo(), o compareToIgnoreCase() de la classe String:

String s1 = "ABC";
String s2 = "abc";
if (s1 == s2.toUpperCase()) ...        // ERROR! (dirà que no són iguals)
if (s1.equals(s2.toUpperCase())) ...   // OK

Mètodes "String"

Propietats i mètodes dels "strings"

Els mètodes més importants són:

  • length(): retorna el nombre de caràcters que conté la cadena.
  • charAt(n): retorna el caràcter en la posició n-èsima.
  • equals(String): retorna true si les dues cadenes contenen els mateixos caràcters.
  • equalsIgnoreCase(String): retorna true si les dues cadenes contenen els mateixos caràcters, sense distingir entre majúscules i minúscules.
  • compareTo(String): compara dues cadenes lexicogràficament. Retorna un valor negatiu si la primera cadena és menor que la segona, 0 si són iguals, i un valor positiu si la primera és la més gran.
  • compareToIgnoreCase(String): igual que l'anterior però sense distingir majúscules i minúscules.
  • toLowerCase(): retorna la cadena convertida a minúscules.
  • toUpperCase(): retorna la cadena convertida a majúscules.
  • trim(): retorna una cadena eliminant els espais del principi i del final.
  • contains(String): comprova si una cadena conté una altra cadena.
  • indexOf(String|char[, n]): retorna la primera posició de la cadena o caràcter buscats, o -1 si no la troba. El paràmetre opcional n permet començar la cerca a partir d'una posició determinada.
  • substring(start[, end]): retorna la subcadena entre els índexs start i end (o fins al final). El caràcter en la posició end no s'inclou.
  • replace(c1, c2): retorna la cadena després de substituir c1 per c2.
  • repeat(n): retorna la cadena repetida n vegades.
  • startsWith(String): comprova si la cadena comença amb la subcadena especificada.
  • endsWith(String): comprova si la cadena acaba amb la subcadena especificada.
  • split(String): retorna un array de String que és el resultat de separar la cadena utilitzant una altra cadena com a separador.

Aquests mètodes sempre s'han d'utilitzar amb un String: pot ser un literal (un text entre cometes) o una variable de tipus String.

La majoria de mètodes retornen un nou String. Altres poden retornar un número enter, un booleà o fins i tot un array de Strings.

int l = "Hello World".length();        // 11
char c = "Hello World".charAt(6);      // 'W'

String hola = "Hello World";
boolean inclou = hola.contains("World");            // true
int ndx = hola.indexOf(" ");                        // 5
String s1 = hola.substring(0, ndx).toUpperCase();   // "HELLO"
String s2 = hola.substring(ndx+1).toLowerCase();    // "world"

ATENCIÓ: la primera lletra d'un string és la 0 (zero), i l'última és length() - 1!

String s = "Hola";
int mida = s.length();    // mida = 4
char c = s.charAt(0);     // c = 'H'
c = s.charAt(mida - 1);   // c = 'a'
c = s.charAt(mida);       // ERROR!

Si s'intenta accedir a una posició negativa o superior o igual a la seva mida, es produirà una excepció!

Convertir strings a números i números a strings

int n = Integer.parseInt("1234");    // 1234
n = Integer.valueOf("1234");         // 1234
float f = Float.parseFloat("1234");  // 1234.0
f = Float.valueOf("1234");           // 1234.0

String s = "" + 1234;                // "1234"
s = Integer.toString(1234);          // "1234"
s = String.valueOf(1234);            // "1234"
s = Float.toString(1234);            // "1234.0"
