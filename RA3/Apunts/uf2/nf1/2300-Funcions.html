Funcions en JavaScript

Característiques de les funcions

Referència

Referència detallada (MDN)

En JavaScript, les funcions són igual que qualsevol altre objecte:

  • Es poden assignar a variables.
  • Es poden posar com a propietats d'altres objectes.
  • Es poden passar com a paràmetres a altres funcions.
  • Poden contenir propietats i mètodes (variables i funcions definides en el seu interior).

Definició d'una funció

Per definir una funció s'utilitza la paraula reservada function.
Normalment se li dóna un nom (encara que també es poden definir funcions anònimes) i entre parèntesis es posen, si n'hi ha, els paràmetres que se li passaran quan se la cridi.
Després es posen les instruccions que ha d'executar dins d'un bloc de codi ({...}).

Com objectes que són, tenen algunes propietats per defecte.
Per exemple, la propietat name guarda el nom, si en té.

Utilitzant la comanda typeof es pot comprovar si un objecte és una funció.

function missatge() {
    console.log("Soc una funció!");
}

missatge();                     // Escriu 'Soc una funció'
console.log(missatge.name);     // Escriu 'missatge'
console.log(typeof missatge);   // Escriu 'function'

Ámbit d'una funció i invocació

Una funció es pot utilitzar dins l'àmbit on s'ha definit:

  • Si s'ha definit en el cos del programa, es guarda com una propietat o mètode de l'objecte window i estarà accessible des de qualsevol lloc del programa.
  • Si es defineix dins d'un objecte (com una propietat més), només es podrà invocar utilitzant aquest objecte.
  • Si es defineix dins d'una altra funció, només estarà accessible des de dins d'aquesta funció.

Per fer que s'executi el codi d'una funció, cal cridar-la amb el seu nom i els arguments entre parèntesis:

function missatge(m) {
    alert(m);
}

missatge("Hello world!");
