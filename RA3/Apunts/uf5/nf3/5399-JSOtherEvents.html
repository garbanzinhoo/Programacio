Altres esdeveniments

Esdeveniments relacionats amb la finestra

  • scroll: quan es desplaça el contingut d'una finestra.
  • resize: quan canvia la mida de la finestra del navegador.
  • fullscreenchange: quan la pàgina passa a mode de pantalla completa.
  • fullscreenerror: si un element no es pot veure en mode de pantalla completa.

Esdeveniments relacionats amb la càrrega de pàgines i arxius

  • load: es dispara quan l'objecte s'ha carregat. S'acostuma a utilitzar amb body.
  • beforeunload: es dispara quan s'està a punt de descarregar el document.
    S'utilitza per avisar l'usuari que està apunt de canviar a una altra pàgina.
  • error: es dispara quan es produeix un error al descarregar un arxiu extern.

Esdeveniments relacionats amb seleccionar, tallar, copiar i enganxar

  • select: quan s'ha seleccionat un text.
  • cut: quan es talla un troç de text seleccionat.
  • copy: quan es copia un troç de text seleccionat.
  • paste: quan es copia un troç de text tallat o copiat prèviament.

Comandes relacionades

  • select(): per seleccionar tot el text d'un element de tipus input o textarea.
  • window.getSelection().toString(): per obtenir el text seleccionat.

També hi ha mètodes per seleccionar trossos de text dins de qualsevol element del document, però poden variar depenent del navegador.

Estils CSS relacionats

  • user-select:none: per evitar que se seleccioni el text d'un element o de tot el document.

Esdeveniments relacionats amb la reproducció de so i vídeo

Referència àudio i vídeo

  • loadstart: es dispara quan el navegador comença a carregar un àudio o vídeo.
  • progress: es dispara mentre el navegador està descarregant l'àudio o vídeo.
  • abort: es dispara quan s'aborta la càrrega d'un àudio o vídeo.
  • canplay: quan l'àudio o vídeo ja està a punt per reproduir-se.
  • play: quan es comença a reproduir un àudio o vídeo.
  • playing: quan es pot continuar reproduïnt després d'haver-lo posat en pausa.
  • waiting: quan s'atura la reproducció perquè s'estan esperant les següents dades.
  • timeupdate: quan canvia la posició de reproducció.
  • volumechange: quan canvia el volum de reproducció.
  • pause: quan es posa en pausa.
  • ended: quan s'ha acabat la reproducció.

Esdeveniments relacionats amb les animacions CSS

  • animationstart: es dispara quan comença una animació CSS.
  • animationend: es dispara quan acaba una animació CSS.
  • animationiteration: es dispara cada vegada que l'animació es repeteix.
    Només es dispara en animacions que tenen l'atribut per repetir-se automàticament.

Esdeveniment relacionat amb les transicions CSS

Quan acaba una transició es dispara l'esdeveniment transitionend.

Altres esdeveniments

  • beforeprint: quan una pàgina està a punt de començar a imprimir-se.
  • afterprint: quan una pàgina ha començat a imprimir-se.
  • online: quan el navegador està a punt de començar a treballar on-line (es pot utilitzar navigator.onLine).
  • offline: quan el navegador està a punt de començar a treballar off-line (es pot utilitzar navigator.offLine).
  • pagehide: quan l'usuari surt de la pàgina (al refrescar, fer clic en un link, enviar un formulari, tancar el navegador...).
    És semblant a unload.
  • pageshow: quan l'usuari entra en una pàgina.
    És semblant a load.
