Mostrar dades amb format

Mostrar les dades amb un format determinat

El mètode System.out.printf(missatge, arguments) permet incloure dins del text una sèrie de paràmetres per indicar en quin format es volen veure els arguments que se li passen.

El format d'aquests paràmetres és el següent (els què van entre [ i ] vol dir que són opcionals):

%[flags][width][.precision]conversion-character

Depenent de la configuració local (país), el separador de decimals i de milers canvia entre . i ,.

  • El % és obligatori. Indica que el que ve a continuació és l'especificació de format.
  • flags: pot contenir més d'un caràcter i cada un té un significat diferent:
    • -: alinea a l'esquerra.
    • +: mostra el signe positiu davant dels números (el signe negatiu sempre es mostra).
    • 0: afegeix zeros a l'esquerra dels números per completar el nombre de caràcters indicat en width.
    • ,: amb números més grans que 1000, separa cada tres dígits de la part entera amb . o ,.
  • width: és un número enter que indica el nombre mínim de caràcters que s'han de d'escriure (l'amplada de la columna quan es volen mostrar les dades en columnes).
  • .precision: és un número enter positiu que indica el nombre de decimals que s'han de d'escriure.
    S'ha de posar el . abans dels dígits.
  • El conversion-caracter és obligatori i consisteix en una lletra que indica el tipus de dada:
    • s: text (String).
    • d: enters (byte, short, int o long).
    • f: reals (float o double).
    • b: booleans.
    • t: data i hora.

String nom = "Mary";
int edat = 30;
float altura = (float)1.68;
// Mostrarà Hola Mary, tens 30 anys i medeixes 1,68 metres
System.out.printf("Hola %s, tens %d anys i medeixes %.2f metres\n", nom, edat, altura);

Com que el símbol % és un caràcter especial, si es vol escriure aquest caràcter cal posar %%:

float iva = 21;
System.out.printf("IVA: %.2f%%\n", iva);    // Mostrarà IVA: 21,00%

Crear un strig amb format

Si en comptes de mostrar les dades formatades per pantalla es vol crear un string amb les dades formatades, es pot fer amb el mètod format() de la classe String:

String s = String.format("%02d:%02d:%02d", 1, 2, 3);    // s = "01:02:03"
System.out.println(s);

El mètode format() té els mateixos paràmetres que el mètode printf().
