Introduir dades

Llegir diferents tipus de dades

Quan es treballa amb el terminal, cal que l'usuari pugui introduir dades escrivint-les pel teclat.

Per fer que el programa s'aturi i esperi que l'usuari introdueixi les dades cal:

  • Importar una llibreria: import java.util.Scanner.
  • Crear un objecte d'aquesta classe: static Scanner scan = new Scanner(System.in).
  • Utilitzar algunes de les seves funcions i guardar el resultat en una variable: s = scan.nextLine().
Exemple

import java.util.Scanner;

public class Main {
    static Scanner scan = new Scanner(System.in);

    public static void main(final String[] args) {
        // Codi del programa
        String nom;
        System.out.print("Com et dius? ");
        nom = scan.nextLine();
        System.out.println("Hola " + nom);
    }
}

Tractar les dades introduïdes

De vegades, els usuaris escriuen espais al principi o al final de la resposta que no s'han de tenir en compte.
O cal que la resposta sigui en majúscules però l'escriuen en minúscules o barrejant majúscules i minúscules.

Per aquests casos hi ha dos mètodes que es poden aplicar a les respostes per evitar errors en el processament posterior:

  • toUpperCase() (o toLowerCase()): converteix tot a majúscules (o a minúscules).
  • trim(): elimina els espais que pugui haver al principi i al final del text.
Exemple

String capital;
System.out.print("Quina és la capital de Portugal? ");
capital = scan.nextLine();
capital = capital.trim();
capital = capital.toUpperCase();
if (capital.equals("LISBOA")) System.out.println("Correcte!");

També es podria haver fet amb menys instruccions:

capital = scan.nextLine().trim().toUpperCase();

Mètodes per llegir diferents tipus de dades

L'objecte creat (scan) inclou mètodes per poder llegir les dades introduïdes de diferents formes.

Llegir tot el què ha escrit l'usuari

El mètode scan.nextLine() llegeix tot el text introduït amb el teclat, incloent l'INTRO que s'ha de prémer al final, i retorna un text que s'ha de guardar en una variable de tipus String:

String nomCognoms;
...
nomCognoms = scan.nextLine();

Quan el programa arribi a aquesta línia, esperarà fins que rebi un salt de línia (INTRO), i guardarà el text en la variable nomCognoms.

També es pot utilitzar per llegir un valor numèric, però s'ha de convertir després de llegir-lo:

int edat = Integer.parseInt(scan.nextLine());

Si el què ha escrit l'usuari no és un número, es generarà una excepció i es tancarà el programa.
