Arxius orientats a caràcters

La informació que contenen aquest tipus d'arxius està en format text.

Exemples d'aquests tipus de fitxers:

  • Arxius de text: .txt generats amb un editor de text pla (Bloc de notes, gEdit...).
  • Arxius de codi: .java (llenguatge Java), .py (llenguatge Python), .c, .php, .js.
  • Arxius per pàgines Web: .html, .css.
  • Arxius de dades: .csv (dades d'un full de càlcul), .dwg (dibuix tècnic).
  • Arxius de configuració: .sys, .cfg.

Llegir un arxiu de text

Un arxiu de text es llegeix de forma molt similar a com es llegeixen les dades que introdueix un usuari amb el teclat: utilitzant un objecte de tipus Scanner i les seves funcions.

Però en lloc de llegir les dades de System.in, s'han d'agafar d'un arxiu identificat amb un objecte File:

try {
    File f = new File("Proves/arxiu1.txt");
    Scanner reader = new Scanner(f);
    String s;

    while (reader.hasNext()) {
        s = reader.next();
        System.out.println(s);
    }

    reader.close();
} catch (Exception e) {
    e.printStackTrace();
}

És recomanable comprovar si existeix la ruta abans de crear l'objecte Scanner.
Un cop s'ha llegit un tros de l'arxiu no es pot tornar enrere: s'ha de tancar i obrir per tornar a començar.
S'ha de tancar l'arxiu quan s'acabin les operacions de lectura!

Determinar quantes dades s'han de llegir

Normalment es poden llegir línies senceres (nextLine()) o elements separats per espais, tabuladors o salts de línia (next(), nextInt(), nextFloat()...).

En qualsevol cas, es poden utilitzar les següents tècniques:

  • Si es coneix el nombre de dades a llegir, es poden llegir una a una o utilitzar un bucle.
  • Posar el nombre d'elements que hi ha al principi de l'arxiu.
  • Posar un valor especial com a l'últim element de l'arxiu.
  • Llegir fins que no quedin més elements (es pot comprovar amb hasNext()).
    Sempre s'ha de comprovar que no queden més dades per evitar una excepció.

Processar les dades

Bàsicament hi ha dues estratègies:

  • Tractar les dades a mida que es van llegint.
  • Emmagatzemar-les (per exemple, en un array) i processar-les després.
    Cal vigilar si la quantitat de dades és molt gran.

Escriure en un arxiu de text

També es pot fer de forma similar a com s'escriu en pantalla: utilitzant un objecte de tipus PrintStream i les seves funcions.

Peró en lloc d'escriure les dades en System.out, s'han d'enviar a un objecte File:

try {
    File f = new File("Proves/arxiu2.txt");
    PrintStream writer = new PrintStream(f);

    writer.print(0);
    for (int i = 1; i < 10; i++) {
        writer.print(" " + i);
    }

    writer.close();
} catch (Exception e) {
    e.printStackTrace();
}

És recomanable comprovar si existeix la carpeta pare de l'arxiu abans de crear l'objecte PrintStream.
Si l'arxiu no existeix, es crea. Si existeix, s'esborra el seu contingut (no es pot afegir)!
Un cop s'ha escrit un tros, no es pot tornar enrere per canviar les dades anteriors.
S'ha de tancar l'arxiu quan s'acabin les operacions d'escriptura!
