Modificar la seqüència d'un bucle

Modificació de la seqüència dins dels bucles

Comanda "break"

Serveix per trencar la seqüència del codi que hi ha dins d'un bucle fent que aquest acabi la seva execució.

En el següent exemple, quan la variable n arriba a un múltiple de 7, s'acaba el bucle, encara que no es compleixi la condició de finalització (que la variable i arribi a 30):

let i = 0, multiple = 7, n;

while (i < 30) {
    n = (i * 2) + 1;
    if (n % multiple == 0) break;
    i++;
}

La comanda break pot servir per trencar un bucle aparentment infinit:

while (true) {
    n = prompt("Escriu un número enter positiu");
    if (n < 0) break;
    alert("El doble de " + n + " és " + (n * 2));
}

Comanda "continue"

Serveix per saltar des d'on es troba aquesta sentència fins al final del codi del bucle, just abans de modificar la variable de control.

En el següent exemple, només escriu múltiple de 5 quan la variable i sigui múltiple de 5.

for (let i = 0; i < 30; i++) {
  if (i % 5 != 0) continue;
  alert(i + " és múltiple de 5");
}

En molts casos, tant el continue com el break es poden evitar fent alguna petita modificació.
En l'exemple anterior, es podria fer:

for (let i = 0; i < 30; i++) {
  if (i % 5 == 0) alert(i + " és múltiple de 5");
}

Però en altres casos, intentar eliminar-los pot complicar excessivament el codi.
Es podria eliminar fàcilment el break del següent codi?

let i = 1;

while (i < 50) {
  if (i % 7 == 0) {
    if (i % 5 == 0) {
      alert("El primer múltiple de 7 i de 5 és " + i);
      break;
    }
    else {
      if (i % 3 == 0) alert(i + " és múltiple de 3 i de 7 però no de 5");
      else alert(i + " és múltiple de 7 però no ho és de 3 ni de 5");
    }
  }
  i++;
}
alert("He provat " + i + " valors");
