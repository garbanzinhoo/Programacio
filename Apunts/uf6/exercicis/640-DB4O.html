Nutricionista

Fes un programa (mode consola i/o escriptori) per gestionar els pacients d'un nutricionista utilitzant db4o.

Ha de permetre afegir, consultar, modificar i eliminar un pacient.

També s'han de poder fer consultes per rang d'edat, per índex de massa corporal (IMC)...

Primer, fes-ho només amb la classe Pacient, que contingui el nom, el pes i l'altura.

Opcionalment, amplia el programa per poder distingir tipus de pacients afegint les subclasses Adult i Infant.

Agència de viatges

Fes un programa (mode consola i/o escriptori) per gestionar una agència de viatges:

Ha de guardar objectes de la classe Client que conté els següents atributs:

  • nif
  • cognoms, nom
  • data de naixement
  • vacunat
  • llista de viatges

La llista de viatges ha de contenir objectes de la classe Viatge:

  • destí
  • data d'inici
  • durada (en dies)
  • preu

Les opcions mínimes que cal implementar en el programa són:

  • Afegir client.
  • Afegir viatge a un client.
  • Mostrar tots els clients.
  • Mostrar els viatges d'un client.

Opcionalment, pots afegir totes les que et semblin interessants:

  • Modificar i/o eliminar un client.
  • Eliminar viatge d'un client.
  • Eliminar viatges segons el destí.
  • Eliminar viatges anteriors a una data.
  • Consultar clients que tenen viatges pendents (i quin és el primer viatge pendent).
    Es podrien ordenar per la data d'inici del viatge.
  • Consultar els clients no vacunats (o els vacunats).
  • Consultar els clients VIP (els que han fet 3 o més viatges amb l'agència o han gastat 3000 € o més).
  • ......

Gestor de bases de dades orientades a objectes

Fes un programa (mode consola i/o escriptori) que permeti seleccionar una BDOO (arxius .db4o) i mostri totes les classes d'objectes que conté.

També s'ha de poder seleccionar una de les classes i mostrar els objectes que conté.

Opcionalment, pots fer que es mostri tota la informació en forma d'arbre:
