Llenguatge Java

Java

Java és un llenguatge mixt (compilat i interpretat), de propòsit general (tant serveix per fer aplicacions d'escriptori com aplicacions web en servidors) i orientat a objectes.

És un llenguatge d'alt nivell (no se sembla gaire al codi màquina) i fortament tipat (s'ha de definir de quin tipus és cada variable i no se li poden assignar dades d'altres tipus).

Els programes es poden executar pràcticament en qualsevol sistema informàtic.
Per poder-los executar cal tenir instal·lat el paquet JRE (Java Runtime Environment).
Aquest paquet inclou la JVM (Java Virtual Machine), que conté l'intèrpret de Java.
La JVM serveix per executar arxius .class o .jar, que són els arxius executables de Java.

Eines per fer programes amb Java

JDK

Aquest paquet inclou també el JRE i el compilador de Java.
El compilador converteix els arxius .java, que contenen el codi font del programa escrit en llenguatge Java, a bytecode i el guarda en un arxiu .class

Editors

Qualsevol editor de text pla (tipus Bloc de notes) pot servir, però és convenient que inclogui les següents característiques:

  • Marcar amb diferents colors les paraules reservades del llenguatge.
  • Eines avançades per buscar i substituir text.
  • Autotabulació (autoindentació).
  • Marcar i comprovar inici i final de parèntesis i blocs.
  • Agrupar (amagar) i desagrupar blocs de codi.
  • Autocompletar comandes i noms de variables i funcions.
