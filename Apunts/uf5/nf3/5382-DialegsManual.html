Diàlegs

Crear diàlegs manualment

JDialog ref. (Java SE 17)

  1. Crear una classe que hereti de JDialog.
  2. Crear i afegir els elements del diàleg.
  3. Crear els listeners dels botons i altres elements.
  4. Crear el codi per inicialitzar el diàleg i/o per obtenir les dades.

La major part del codi és el mateix que s'ha fet utilitzant l'IDE.
Només cal agafar el panell principal (contentPane), canviar el seu layout i crear els elements:

// Panell principal
contentPane = (JPanel) getContentPane();

// Botons OK i Cancel
buttonOK = new JButton("OK");
buttonCancel = new JButton("Cancel");

// Afegir botons OK i Cancel a un panell
JPanel pBotons = new JPanel(new GridLayout(1,2, 10, 0));
pBotons.add(buttonOK);
pBotons.add(buttonCancel);
pBotons.setAlignmentX( Component.LEFT_ALIGNMENT );

// CheckBox i RadioButton
transparent = new JCheckBox("Transparent");
vermell = new JRadioButton("Vermell");
verd = new JRadioButton("Verd");
blau = new JRadioButton("Blau");

// Afegir botons de colors a un grup i seleccionar el primer
ButtonGroup bg = new ButtonGroup();
bg.add(vermell);
bg.add(verd);
bg.add(blau);
vermell.setSelected(true);

// Afegir botons de colors a un panell
JPanel pRadio = new JPanel();
pRadio.setLayout(new BoxLayout(pRadio, BoxLayout.Y_AXIS));
pRadio.setBorder(new EmptyBorder(12, 20, 10, 10));
pRadio.add(vermell);
pRadio.add(verd);
pRadio.add(blau);

// Configurar panell principal
contentPane.setBorder(new EmptyBorder(10, 10, 10, 10));
contentPane.setLayout(new BoxLayout(contentPane, BoxLayout.Y_AXIS));

// Afegir CheckBox i panells secundaris al panell principal
contentPane.add(transparent);
contentPane.add(pRadio);
contentPane.add(pBotons);
