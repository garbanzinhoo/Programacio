Identificar constants i variables

Per poder utilitzar una variable o una constant, cal definir-la indicant de quin tipus és i donant-li un nom.
Es poden definir més d'una variable del mateix tipus en la mateixa sentència.
També se li pot donar un valor (inicialitzar) o posar una expressió en el mateix moment de definir-la.
Per assignar un valor s'utilitza el símbol =.

final int NOTA_MAX = 10;
char lletra;
float mitjana, preu = 18.50f, iva = preu * 21 / 100;

Si les variables o constants s'inicialitzen en el moment de definir-les i el compilador pot deduir de quin tipus són, es pot posar el tipus genèric var enlloc del tipus concret:

final var NOTA_MAX = 10;    // Per defecte assigna tipus int
var preu = 18.50;           // Per defecte assigna tipus double

En Java, les constants i variables s'han de definir i han de tenir un valor abans d'utilitzar-les. Si no es fa així, el compilador donarà un error. és recomanable definir-les al principi del bloc de codi on s'utilitzen.
Les variables es poden inicialitzar més endavant, però les constants s'han d'inicialitzar al declarar-les.

Els noms de les variables i les constants han de seguir els següents criteris:

  • Han de començar amb una lletra.
  • Poden contenir lletres, dígits, el símbol $ o el guió baix (_).
  • No es poden utilitzar paraules reservades de Java.
  • Els noms han de ser representatius de les dades que contindran.

Encara que no sigui imprescindible, es recomana posar els noms de les constants en majúscula i, si el nom d'una variable conté més d'una paraula, utilitzar la forma lowerCamelCase (començar amb minúscula i posar en majúscula la primera lletra de les següents paraules).

En el cas de les constants, les paraules se separen amb guió baix.

char lletraNif = 'A';        // estil lowerCamelCase
final int MAX_NIVELL = 10;   // estil per les CONSTANTS

Java és Case Sensitive (distingeix entre majúscules i minúscules):
les variables nom, Nom i NOM són variables diferents.
