Funcions parametritzades

Generar caràcter aleatori

Fes una funció que retorni un caràcter aleatori entre la 'A' i la 'Z' totes dues incloses.
Millora la funció anterior fent que se li pugui passar el caràcter inicial i el caràcter final.

Crear un array de N números enters inicialitzat amb un valor V

Fes una funció per crear un array amb N números enters, inicialitzar totes les posicions amb un valor concret (V) i retornar aquest array.
Paràmetres d'entrada: N (nombre d'elements de l'array: número enter) i V (valor per inicialitzar els elements de l'array: número enter).

Mostrar els valors d'un array

Fes una funció per mostrar els valors d'un array de números enters, un en cada línia.
Crea també una funció per arrays amb Strings.
Paràmetre d'entrada: array amb valors enters o Strings.

Modifica les funcions anteriors afegint un paràmetre per indicar si es vol mostrar cada dada afegint un salt de línia o tots en una línia separats per un espai.

Afegeix un paràmetre per indicar quin separador es vol utilitzar en lloc de l'espai si s'han de mostrar en una sola línia.

Mostrar els valors d'un array bidimensional

Fes una funció per mostrar els valors d'un array bidimensional de números enters.
Paràmetre d'entrada: array bidimensional amb valors enters.

Per escriure cada una de les files de l'array es pot utilitzar la funció per mostrar els valors d'un array.

Afegeix un paràmetre per indicar quin separador es vol utilitzar per separar els elements de cada fila.
Si el separador és null o una cadena buida, utilitzar l'espai.

Introduir un caràcter verificant que sigui un caràcter d'una llista

Fes una funció que demani un caràcter (podria ser una opció d'un menú).
S'ha de demanar repetidament mentre el valor introduït no sigui un caràcter dels que es troba en un String (també es pot fer que la llista de caràcters permesos estigui en una llista de caràcters).
Paràmetre d'entrada: un Scanner amb el què llegir les dades introduïdes per teclat.
Paràmetre d'entrada: String o array de caràcters amb els caràcters permesos.
Valor de retorn: el caràcter introduït per l'usuari.

Introduir un número enter

Fes una funció que demani un número enter.
S'ha de demanar repetidament mentre el valor introduït no sigui un número enter, i avisar amb un missatge d'error. Es pot utilitzar la funció scan.hasNextInt() per comprovar si el valor introduït és un enter.
Paràmetre d'entrada: un Scanner amb el què llegir les dades introduïdes per teclat.
Valor de retorn: el número enter introduït per l'usuari.

Crea també una funció que utilitzi l'anterior però que se li pugui indicar el valor mínim i màxim entre els quals s'ha de trobar el valor introduït.
Si el valor mínim és més gran que el màxim, cal intercanviar els valors.
S'ha de demanar repetidament mentre el valor introduït no estigui entre els dos límits, i avisar amb un missatge d'error.

Crear array de N elements introduïts per l'usuari

Fes una funció per crear un array de N números enters demanant a l'usuari que introdueixi els valors i retornar aquest array. Pots utilitzar alguna de les funcions anteriors.
Crea també una funció per arrays amb Strings.
Paràmetre d'entrada: un Scanner amb el què llegir les dades introduïdes per teclat.
Paràmetre d'entrada: N (nombre d'elements de l'array: número enter).
Valor de retorn: l'array d'enters o Strings amb les dades introduïdes.

Invertir els elements d'un array

Fes una funció per invertir els elements d'un array (intercanviar el primer amb l'últim, el segon amb el penúltim...).
Fes-ho amb arrays de números enters i amb arrays de Strings.

Desplaçar els elements d'un array

Fes una funció per desplaçar els elements cap a l'esquerra (el primer al final, el segon al primer...).
Fes una funció per desplaçar els elements cap a la dreta (l'últim a principi, el primer al segon...).
Fes-ho amb arrays de números enters i amb arrays de Strings.
Fes també una funció que permeti desplaçar a la dreta o a l'esquerra utilitzant un paràmetre booleà per indicar la direcció i que aprofiti les funcions creades anteriorment.
Aprofitant la funció anterior, fes una funció que permeti desplaçar un número determinat de posicions a la dreta o a l'esquerra.

Barrejar els elements d'un array

Fes una funció per barrejar els elements d'un array d'enters.
Fes una funció per barrejar els elements d'un array de Strings.

Una possible forma és, per cada element de l'array (element[i]):

  1. Generar un número aleatori entre 0 i el nombre d'elements de l'array (r).
  2. Intercanviar l'element[i] amb l'element[r].

Fes una funció per ordenar un array de Strings. Pots trobar la solució en l'exercici Arrays 2: Ordenar i cercar paraules.

Cerca binària en arrays ordenats

Fes una funció per cercar en un array ordenat la posició d'un element determinat.
Si no es troba, ha de retonar -1.

Fes una funció per números enters i una altra per a Strings.
També tens el codi en els mateixos apunts i solució de l'exercici anterior.
