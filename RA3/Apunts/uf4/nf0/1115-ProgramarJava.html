Programar amb Java

Primer programa

El primer programa que es recomana fer quan es comença a aprendre un llenguatge és "Hola món!" (o "Hello world!" en anglès).
Aquest programa es limita a escriure en pantalla el missatge "Hola món!".

No importa que encara no es conegui res del llenguatge, només cal copiar el codi font i seguir unes poques instruccions per comprovar que l'entorn que s'ha instal·lat funciona correctament.
També serveix com a plantilla per fer els primers programes.

Plantilla mínima

Tot programa Java ha de tenir una classe principal.
El nom de les classes ha de començar amb una lletra majúscula.

El llenguatge Java distingeix majúscules i minúscules: les variables nom, Nom i NOM són tres variables diferents.

Tota classe ha de tenir una funció main() definida com es mostra en l'exemple.

Per fer un programa que pugui escriure en el terminal, no cal importar cap classe.
Les possibles comandes són:

  • System.out.print(): escriu el text o la variable que es posa com a paràmetre.
  • System.out.println(): igual que l'anterior però afegeix un salt de línia.

public class Hello {
    public static void main(final String[] args) {
        // Codi del programa
        System.out.println("Hello world!");
    }
}

El nom de l'arxiu on es guardi el programa ha de coincidir amb el nom de la classe, i l'extensió ha de ser .java. En l'exemple anterior, el nom de l'arxiu hauria de ser Hello.java.

Editar, compilar i executar

  1. Escriure (o copiar) el codi en un editor de text pla.
  2. Guardar l'arxiu amb el mateix nom que se li ha donat a la classe principal i afegir l'extensió .java.
  3. Obrir un terminal i navegar fins la carpeta on s'ha guardat l'arxiu amb el codi font.
  4. Compilar el codi font amb la comanda javac NomArxiu.java (es crearà l'arxiu NomArxiu.class).
  5. Executar el programa amb la comanda java NomArxiu (no cal afegir l'extensió .class).
