"Calculadora" d'expressions regulars

Les expressions regulars són una forma de crear un plantilla que pot servir per:

  • Comprovar si un text compleix un format determinat:
    • el NIF ha de tenir 8 dígits i una lletra.
    • una matrícula de cotxe ha de tenir 4 dígits i 3 lletres.
    • un número de telèfon ha de tenir 3 dígits, un punt, 3 dígits, un punt i 3 dígits.
  • Buscar si existeix una subcadena (amb un format determinat) dins d'un text.
  • Buscar i canviar una subcadena per una altra dins d'un text, només una vegada o totes les que aparegui.

Per fer proves es pot utilitzar el següent codi:

let pattern = /^[AEIOUaeiou]$/;    // Posar aquí el patró a comprovar
let s = prompt("Introdueix un text");
while (s && s.toUpperCase() !== "FI") {
    if (pattern.test(s)) alert(s + " COINCIDEIX amb " + pattern);
    else alert(s + " NO coincideix amb " + pattern);
    s = prompt("Introdueix un text");
}

Patrons

En JavaScript, els patrons es tanquen entre / i /

Després de la segona barra (la de tancament) es pot posar un dels següents modificadors:

  • g: coïncidència global (totes les vegades que aparegui el patró)
  • i: coïncidència insensitiva (sense diferenciar majúscules i minúscules)
  • m: cerca multilínia (no ve limitada pels salts de linia)

Caràcters especials

Els següents caràcters tenen un significat especial.

[ ] ( ) { } \ ^ $ | ? * + .

Si es volen utilitzar com a caràcters a detectar, cal posar \ al davant (\*   \.   \+   \(   \\...).

  • [ ]: per especificar un conjunt de caràcters.
  • ( ): per agrupar.
  • { }: per indicar un nombre de repeticions.
  • \: per poder utilitzar caràcters especials, per representar caràcters especials o per conjunts de caràcters.
  • ^: té dos possibles significats:
    • indicar que la coincidència ha d'estar al principi de la línia.
    • si es posa com a primer caràcter dins de [ ], implica negació ([^AEIOUaeiou] detectarà qualsevol caràcter que no sigui una vocal).
  • $: indica que la coincidència ha d'estar al final de la línia.
  • |: per triar entre diferents possibilitats.
  • ?: indica que el caràcter o grup anterior pot aparèixer una o cap vegada.
  • +: indica que el caràcter o grup anterior ha d'aparèixer una o més vegades.
  • *: indica que el caràcter o grup anterior pot aparèixer zero, una o més vegades.
  • .: equival a qualsevol caràcter.

Les següents expressions tenen un significat especial (caràcters especials o conjunt de caràcters).

\t   \n   \s   \S   \d   \D   \w   \W

  • \t: representa un tabulador.
  • \n: representa un salt de línia.
  • \s: representa qualsevol caràcter que sigui un separador. És equivalent a [ \t\n\x0B\f\r].
  • \S: representa qualsevol caràcter que no sigui un separador. És equivalent a [^\s].
  • \d: representa qualsevol caràcter que sigui un dígit. És equivalent a [0-9].
  • \D: representa qualsevol caràcter que no sigui un dígit. És equivalent a [^0-9].
  • \w: representa qualsevol caràcter que pot formar una paraula. És equivalent a [a-zA-Z_0-9].
  • \W: representa qualsevol caràcter que no formi part d'una paraula. És equivalent a [^\w].

Expressions regulars bàsiques

Coïncidència exacta dins del text, tot el text, al principi o al final

Cal posar el text directament entre / i /.

El patró /hola/ detectarà si el text conté la paraula hola tal qual està escrita.
/hola/.test(text) seria equivalent a text.includes("hola").

Si es vol que comprovi que tot el text sigui igual a hola cal posar el patró /^hola$/.
/^hola$/.test(text) seria equivalent a text === "hola".

Per comprovar si un text comença o acaba amb uns caràcters concrets:
/^hola/.test(text) o /hola$/.test(text) respectivament.
Seria equivalent a text.startsWith("hola") o text.endsWith("hola").

Comprovar si un caràcter pertany a un conjunt de caràcters

S'han de posar els caràcters que es volen detectar entre [ i ].
El patró /[AEIOUaeiou]/ detectarà si el text conté una vocal majúscula o minúscula.
Exemple: /[PB]ala/ detectarà Pala o Bala, però no Mala.

També es poden utilitzar rangs de caràcters: /[A-Za-z0-9]/.

Si el primer caràcter és ^, l'efecte és el contrari:
El patró /[^AEIOUaeiou]/ detectarà qualsevol caràcter que no sigui una vocal.
Exemple: /[^PB]ala/ detectarà Mala, Cala, Gala... però no Pala ni Bala.

Comprovar rang de caràcters

Exemple: /[A-Z]ala/ detectarà si conté Cala, Gala, Mala, Sala, Pala, Bala...

Comprovar rang de caràcters excloent alguns (avançat)

Exemple: /^[A-Z&&[^PB]]ala$/ detectarà Cala, Gala, Mala, Sala, ...,  però no Pala ni Bala.

Comprovar si un caràcter, conjunt de caràcters o grup es repeteix

S'ha de posar ?, + o * just a continuació:

  • ?: Comprovar si apareix una o cap vegada.
  • +: Comprovar si apareix una o més vegades.
  • *: Comprovar si apareix zero, una o més vegades.

També es pot posar just a continuació {N} o {N,M} (N i M han de ser números enters):

  • {5}: El què hi ha al davant s'ha de repetir 5 vegades.
  • {2,4}: El què hi ha al davant s'ha de repetir 2, 3 o 4 vegades.
  • {3,}: El què hi ha al davant s'ha de repetir 3 o més vegades.

Agrupaments i alternança

Per indicar que es vol detectar una expressió o una altra, s'han d'agrupar les expressions posant-les entre parèntesis i posar el símbol | entre elles:

L'expressió /([Hh]ola|[Aa]deu) pot detectar les paraules Hola, hola, Adeu o adeu:

let pattern = /^([Hh]ola|[Aa]deu)$/;
let s = "hola";
console.log(pattern.test(s));    // true
s = "Adeu";
console.log(pattern.test(s));    // true
s = "HolaAdeu";
console.log(pattern.test(s));    // false

Comandes de la classe String que utilitzen expressions regulars

  • string.match(regex): retorna un array amb les coïnciències que ha trobat.
  • string.split(regex): divideix el text creant un array de strings utilitzant com a separador l'expressió regular.
  • regex.test(string): retorna true si troba l'expressió regular dins del string.

Normalment s'utilitza split amb l'espai, coma, punt i coma... com a separadors.
Però, com s'hauria de posar si es vol utilitzar el punt o el signe més com a separador???

Buscar i substituir dins d'un String

  • replace(regex, text): substitueix la primera vegada que apareix regex per text.
  • replaceAll(regex, text): substitueix totes les vegades que apareix regex per text.

Utilitzar els agrupaments en les substitucions (avançat)

En el text de substitució es poden incloure els grups d'expressions detectades.

A cada agrupació (...) se li assigna un número de 1 a N segons l'ordre en què es troba.
Llavors, en el text de substitució es pot incloure $1, $2... per incloure el grup detectat:

let s = "Hola i adeu";
console.log(s.replace(/([Hh]ola)(.*)([Aa]deu)/, "$3$2$1"));  // adeu i Hola

Mode non-greedy (no avariciós) (avançat)

Per defecte, les expressions regulars intenten trobar la cadena més llarga que compleixi el patró.
Això pot provocar que es detectin coïncidències no desitjades.

El patró /if *\(.*\)/ en el text if (i % 2 == 0) i = (i + 1) * 2; detectarà if (i % 2 == 0) i = (i + 1), quan segurament només es volia detectar if (i % 2 == 0).

Una forma de solucionar-ho seria utilitzar el patró /if *\([^)]*\)/.

O es pot utilitzar el mode non-greedy que consisteix en afegir un interrogant després de l'indicador de repetició: /if *\(.*?\)/ .
