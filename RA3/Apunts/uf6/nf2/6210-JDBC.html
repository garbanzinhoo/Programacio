JDBC

Aquesta API consisteix en unes interfícies i classes que permeten accedir a SGBD.

Cada SGBD necessita un driver (llibreria) específic que implementa les funcions definides en la API.

A més d'afegir la llibreria del SGBD al projecte, també cal importar les classes de la API (java.sql.*).

Les interfícies i classes més importants són:

java.sql.Connection

java.sql.Statement

java.sql.PreparedStatement

java.sql.ResultSet

java.sql.ResultSetMetaData

Connectar amb una BD i desconnectar

Plantilles de connexió i desconnexió

/**
 * Connectar amb una BD indicada en el paràmetre 'url'.
 * @param url Protocol i ruta cap a la BD<br>Exemple: "jdbc:sqlite:prova.db"
 * @return Connexió amb la BD o 'null' si no s'ha pogut connectar
 */
private static Connection openCon(String url) {
    Connection con = null;

    try {
        con = DriverManager.getConnection(url);
        System.out.println("Connexió establerta");
    } catch (SQLException e) {
        System.out.println(e.getMessage());
    }

    return con;
}

/**
 * Desconnectar d'una BD.
 * @param con Connexió amb la BD
 */
private static void closeCon(Connection con) {
    try {
        if (con != null) con.close();
    } catch (SQLException e) {
        System.out.println(e.getMessage());
    }
}

En un cas real convé posar la URL en un arxiu de configuració per evitar haver de modificar i recompilar el programa si la base de dades canvia de lloc.
També s'hauria de demanar un identificador d'usuari i contrasenya per accedir a una BD protegida.

Si s'han d'executar moltes sentències seguides (processos automàtics), és preferible establir la connexió, executar-les totes i tancar la connexió.
Si s'executa una de tant en tant (accions d'usuari) , és preferible obrir i tancar la connexió per cada una.

Executar sentències SQL

Un cop s'ha establert la connexió amb el SGBD, cal crear un objecte de la classe Statement per poder executar les sentències SQL.
Aquest objecte es crea a partir de l'objecte Connection creat per connectar amb la BD:

Statement stmt = con.createStatement();
int r = stmt.executeUpdate("DELETE FROM alumnes WHERE id=285");
ResultSet rs = stmt.executeQuery("SELECT * FROM profes");

Quan s'utilitzen les comandes SELECT i INSERT, és convenient especificar els camps (no posar *).
Si s'afegeixen columnes a la taula, podem obtenir resultats erronis o diferents dels esperats!

PreparedStatement

Aquesta subclasse de Statement permet executar consultes parametritzades, que són consultes predefinides però amb algun/s paràmetre/s que s'ha/n de passar abans d'executar-la.

L'avantatge de PreparedStatement és la seva eficiència, sobretot quan s'ha d'executar moltes vegades.
Un altre avantatge és que són immunes als atacs de sql injection.

Primer cal crear i guardar PreparedStatement per poder-lo utilitzar més endavant.
En la sentència SQL cal indicar els paràmetres posant un interrogant (?).
Després, quan s'hagi d'utilitzar, cal donar valor als paràmetres i executar-lo:

PreparedStatement ps = con.preparedStatement("SELECT * FROM alumnes WHERE nif=?");
ps.setString(1, "12345678Z");
ResultSet rs = ps.executeQuery();

Els paràmetres comencen en l'índex 1.
