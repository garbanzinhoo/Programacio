Comunicació entre ordinadors: sockets

Sockets

Una forma de comunicar ordinadors a través de la xarxa és utilitzant sockets.

Un socket representa un canal de comunicació permanent bidireccional entre dues màquines:

  • "servidor" és la màquina que engega el procés que acceptarà connexions amb altres màquines.
    Aquest procés (servei) necessita un port lliure en una de les interfícies de xarxa del servidor.
  • "client" és cada una de les màquines que es connectaran amb el "servidor".
    El client necessita saber l'adreça IP i el port on el servidor està esperant les connexions.
    També reservarà automàticament un port lliure per realitzar la connexió.

Servidor

Engegar el servei per acceptar connexions

Java té la classe ServerSocket per posar en marxa el servei.

S'ha de crear un objecte passant-li el número d'un port lliure (també es pot incloure la IP d'una interfície).
Si se li passa el port 0, triarà automàticament un que estigui lliure.

ServerSocket servidor = new ServerSocket(port);

Si s'especifica un port que no sigui 0, és convenient assegurar-se que està lliure.

Si no s'especifica, s'ha de conèixer l'adreça IP amb la que el servidor es connecta amb l'"exterior".
La següent pot ser una forma senzilla d'obtenir-la:

  1. Connectem el servidor amb un altre servidor conegut.
  2. Mirem quina adreça local ha utilitzat per connectar-se.
  3. Tanquem la connexió.

//Socket s = new Socket("8.8.8.8", 53);
Socket s = new Socket("www.google.com", 80);
String serverIP = s.getLocalAddress().getHostAddress();
s.close();

Acceptar connexions

Amb l'objecte ServerSocket creat, la comanda accept() fa que esperi una sol·licitud de connexió.

Quan es rep una sol·licitud, retorna un objecte de tipus Socket.
Aquesta classe representa una connexió amb una altra màquina.

Socket connexio = servidor.accept();

Convertir les dades per enviar i rebre pels canals de sortida i d'entrada

Per poder enviar i rebre correctament objectes, cal utilitzar algunes classes extra:

  • ObjectOutputStream: "serialitza" un objecte (el converteix en bytes) per poder-lo enviar.
  • ObjectInputStream: converteix a objecte les dades rebudes.

ObjectOutputStream out = new ObjectOutputStream(connexio.getOutputStream());
ObjectInputStream in = new ObjectInputStream(new BufferedInputStream(connexio.getInputStream()));

Per poder enviar i rebre objectes per aquests canals cal que la classe implementi la interfície Serializable:

public class Missatge implements Serializable { ... }

Enviar i rebre dades

Les classes anteriors tenen els següents metodes per enviar i rebre objectes:

out.writeObject(missatge);
obj = in.readObject();

L'objecte rebut és de tipus Object, per tant caldrà convertir-lo:

missatge = (Missatge)in.readObject();

Client

Connectar amb el servidor

Per establir una connexió cal crear un socket indicant l'adreça IP del servidor i el port en que està escoltant:

Socket connexio = new Socket(IP, port);

Convertir i enviar i rebre dades

Es fa de la mateixa forma que en el servidor.
