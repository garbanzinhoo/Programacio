Gestió dels esdeveniments

Tutorial sobre gestors d'esdeveniments en Java

Gestionar esdeveniments de dos components de la mateixa forma

Implementar la gestió d'esdeveniments

Els passos per implementar la gestió d'esdeveniments són els següents:

  1. Crear una classe que implementi un listener o un adapter per gestionar els esdeveniments (opcional).
  2. Crear un objecte listener a partir de la interfície o de la classe anterior.
  3. Connectar el component al listener.

Crear la classe per crear listeners

Hi ha diverses formes d'implementar aquesta classe.

Crear objectes listener a partir de classes anònimes dins de la Vista

Aquest és el mètode mès ràpid. S'utilitza per comoditat en exemples i codis senzills.
Avantage: pot accedir directament als atributs de la Vista.
Inconvenient: no hi separació entre Vista i Controlador, i no es pot escalar fàcilment ni reaprofitar (cal crear un listener per cada objecte, encara que el codi per gestionar l'esdeveniment sigui el mateix o semblant).

static int n = 0;

// Botons per incrementar/decrementar el comptador
JButton iButton = new JButton("Inc");
JButton dButton = new JButton("Dec");

// Crear i assignar listener a cada botó
iButton.addActionListener(new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent e) {
        comptador.setText("" + (++n));
    }
});

dButton.addActionListener(new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent e) {
        comptador.setText("" + (--n));
    }
});

Crear classes privades dins de la Vista

És similar a l'anterior però, al crear una classe no anònima, es pot reutilitzar per crear més d'un listener.

// Assignar listener a cada botó
iButton.addActionListener(new ButtonListener());
dButton.addActionListener(new ButtonListener());

// Classe per implementar listeners per botons
private static class ButtonListener implements ActionListener {
    @Override
    public void actionPerformed(ActionEvent e) {
        JButton b = (JButton) e.getSource();
        switch (b.getText()) {
            case "Inc" -> ++n;
            case "Dec" -> --n;
        }
        comptador.setText("" + n);
    }
}

També es podria crear un objecte listener i assignar-lo a cada botó (per no crear dos objectes iguals):

// Assignar listener a cada botó
ActionListener buttonListener = new ButtonListener();
iButton.addActionListener(buttonListener);
dButton.addActionListener(buttonListener);

Crear classes externes a la Vista

És similar a l'anterior però amb els següents inconvenients:

  • Cal crear un arxiu per cada classe de listener.
  • No es pot accedir directament als atributs de la Vista (cal crear mètodes auxiliars a la Vista).

public class ButtonListener implements ActionListener {
    @Override
    public void actionPerformed(ActionEvent e) {
        JButton b = (JButton) e.getSource();
        switch (b.getText()) {
            case "Inc" -> Vista.incCounter();
            case "Dec" -> Vista.decCounter();
        }
        Vista.setCounterText();
    }
}

public class Vista {
    ...
    public static void incCounter() { ++n; }
    public static void decCounter() { --n; }
    public static void setCounterText() { comptador.setText("" + n); }
}

Crear objectes listener amb classes anònimes dins del Controlador

És similar a l'anterior però sense haver de crear classes externes per cada listener.

És una foma més adequada per separar Vista i Controlador.

public class Controlador {
    public static final ActionListener buttonListener = new ActionListener() {
        @Override
        public void actionPerformed(ActionEvent e) {
            JButton b = (JButton) e.getSource();
            switch (b.getText()) {
                case "Inc" -> Vista.incCounter();
                case "Dec" -> Vista.decCounter();
            }
            Vista.setCounterText();
        }
    });
}

public class Vista {
    ...
    iButton.addActionListener(Control.buttonListener);
    dButton.addActionListener(Control.buttonListener);
    ...
}

Si en lloc de crear una classe Vista amb mètodes estàtics es crea un objecte JFrame amb mètodes per accedir als seus components, només caldrà passar-li aquest objecte al Controlador.

Funcionament de la gestió d'esdeveniments

  • Quan s'engega el programa:
    • A partir de la classe Listener o Adapter es crea un objecte listener.
    • Es connecte l'objecte de la Vista amb el listener.
  • Quan l'usuari realitza una acció sobre un component:
    • Si l'acció NO es correspon a un listener associat al component, la ignora.
    • Si es correspon:
      • Envia un objecte del tipus corresponent (MouseEvent, KeyEvent...) al listener amb informació sobre l'esdeveniment (posició del ratolí, botó premut, tecla premuda...).
      • El listener crida el mètode corresponent (mouseClicked()...), passant-li l'objecte rebut.
      • El mètode s'encarrega de cridar el Model per modificar les dades i/o la Vista per actualitzar-la.
