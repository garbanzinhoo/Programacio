Programació modular

Crear i provar una llibreria pròpia

Crea el projecte TestFuncions utilitzant com a paquet base cat.sapa.uf2

Crea els subpaquets cat.sapa.uf2.arrays i cat.sapa.uf2.altres

Dins del primer, crea les classes IntegerArrays i StringArrays i posa dins de cada una les funcions que has creat en l'exercici de funcions parametritzades genèriques (Mostrar els valors d'un array, Invertir els elements d'un array, Desplaçar els elements d'un array, Barrejar els elements d'un array, ...).

Dins del segon, crea la classe AltresFuncions i posa a dins la resta de funcions (Retornar un caràcter aleatori, Introduir un número enter, ...).
Crea en aquesta classe un objecte Scanner global de forma que no calgui passar un objecte d'aquest tipus a les funcions que serveixen per introduir dades.

La classe principal s'ha de dir TestFuncions i ha de contenir el codi necessari per provar els mètodes de les classes anteriors.

Treballar amb l'API de Java

Busca en la documentació oficial de Java SE 17 les classes Math i String.
De cada classe, busca al menys 3 funcions que no hagis utilitzat fins ara i que et sembli que poden ser útils.
Fixa't en els paràmetres d'entrada i valor de retorn, i escriu un petit codi per provar-les.

Busca en la documentació oficial de Java SE 17 les classes Random i Arrays.
Escriu un petit codi utilitzant la classe Random per generar números aleatoris entre dos valors determinats.
Escriu un petit codi per comprovar els mètodes de la classe Arrays que serveixen per inicialitzar, ordenar, buscar un element utilitzant la cerca binària, comprovar si dos arrays són iguals i convertir l'array a String.

Documentar projecte i generar JAR

Documenta totes les classes i funcions del paquet cat.sapa.uf2 i dels seus subpaquets.

A més de documentar utilitzant el format adequat, genera la documentació utilitzant JavaDoc.

Finalment, empaqueta el projecte en un arxiu JAR, intercanvia'l amb un altre company i comproveu que el podeu executar.
