Comunicació entre ordinadors: sockets

Exemple de comunicació síncrona bidireccional

El següent és un exemple molt simplificat de comunicació bidireccional entre un client i un servidor.

En aquest cas, el client fa peticions al servidor i el servidor només respon.

Esquema bàsic en el servidor
  1. Crear un ServerSocket per atendre connexions.
  2. Esperar que es connecti el client i crear un Socket per a ell.
  3. Crear els canals d'entrada i sortida del Socket per poder enviar i rebre missatges.
  4. Repetir fins que el client tanqui la connexió.
    1. Esperar el missatge del client.
    2. Processar la petició.
    3. Respondre al client.

package uf4.exemples.sockets1;

import java.io.BufferedInputStream;
import java.io.IOException;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.net.*;

public class Servidor {

    public static void main(String[] args) throws IOException, ClassNotFoundException {
        // Crear servei per atendre connexion
        ServerSocket ss = new ServerSocket(5000);
        System.out.println("Servidor engegat...");

        // Esperar connexió d'un client i crear socket per a ell
        Socket s = ss.accept();
        System.out.println("S'ha connectat un client...");

        // Crear els canals de sortida i entrada per enviar i rebre missatges
        ObjectOutputStream out = new ObjectOutputStream(s.getOutputStream());
        ObjectInputStream in = new ObjectInputStream(new BufferedInputStream(s.getInputStream()));
        System.out.println("Canals de comunicació oberts...");

        // Repetir per sempre
        while (true) {
            // Esperar i mostrar missatge
            System.out.println("\nEsperant missatge del client...");
            Object obj = in.readObject();
            System.out.println("Missatge rebut del client: " + obj);

            // Respondre al client
            out.writeObject("He rebut el missatge ---> " + obj);
        }
    }

}

Esquema bàsic en el client
  1. Crear un Socket per connectar-se amb el servidor.
  2. Crear els canals d'entrada i sortida del Socket per poder enviar i rebre missatges.
  3. Repetir fins que l'usuari decideixi finalitzar la connexió.
    1. Preguntar a l'usuari.
    2. Enviar la petició al servidor.
    3. Esperar la resposta del servidor.
    4. Mostrar la resposta.

package uf4.exemples.sockets1;

import java.io.BufferedInputStream;
import java.io.IOException;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.net.Socket;
import java.util.Scanner;

public class Client {
    static Scanner scan = new Scanner(System.in);

    public static void main(String[] args) throws IOException, ClassNotFoundException {
        // Crear connexió amb el servidor
        Socket s = new Socket("localhost", 5000);
        System.out.println("S'ha connectat amb el servidor...");

        // Crear els canals de sortida i entrada per enviar i rebre missatges
        ObjectOutputStream out = new ObjectOutputStream(s.getOutputStream());
        ObjectInputStream in = new ObjectInputStream(new BufferedInputStream(s.getInputStream()));
        System.out.println("Canals de comunicació oberts...");

        // Repetir per sempre
        while (true) {
            // Demanar i enviar missatge
            System.out.print("\nEscriu un misatge per al servidor: ");
            String missatge = scan.nextLine();
            out.writeObject(missatge);

            // Esperar i mostrar resposta
            Object obj = in.readObject();
            System.out.println("Resposta del servidor: " + obj);
        }
    }
}

Exemple de comunicació síncrona amb més d'un client

En aquest cas, és el servidor qui fa les peticions als clients seguint un ordre establert.

Els clients han d'esperar que els toqui el torn.

Esquema bàsic en el servidor
  1. Crear un ServerSocket.
  2. Esperar que es connectin els clients i crear un Socket per a cada un.
    D'alguna forma, s'ha de conèixer o establir quants clients es connectaran.
  3. Crear els canals d'entrada i sortida de cada Socket per poder enviar i rebre missatges.
  4. Repetir fins que el servidor decideixi que s'ha de finalitzar.
    1. Per cada client...
      1. Enviar la petició al client (pot incloure informació necessària).
      2. Esperar la resposta del client.
      3. Processar la resposta.
Esquema bàsic en el client
  1. Crear un Socket per connectar-se amb el servidor.
  2. Crear els canals d'entrada i sortida del Socket per poder enviar i rebre missatges.
  3. Repetir fins que el servidor decideixi finalitzar la connexió.
    1. Esperar el missatge del servidor.
    2. Mostrar la informació, si cal.
    3. Demanar les dades a l'usuari.
    4. Respondre al servidor.
