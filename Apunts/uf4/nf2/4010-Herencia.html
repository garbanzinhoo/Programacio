Introducció a la programació orientada a objectes

Herència

En el mon real, s'acostumen a fer generalitzacions i especialitzacions per facilitar la organització dels coneixements.
Per exemple, es pot subdividir el concepte Animal (generalització) en Mamifer, Peix i Ocell (especialitzacions).
Animal conté les característiques comunes a tots, mentre que les altres contenen les que són úniques de cada un.

La classe Animal és la superclasse (o classe "mare") de les altres, que són les subclasses (o classes "filles") de la primera.
Les subclasses hereten les característiques de la superclasse (atributs i mètodes públics i protegits).

Una jerarquia de classes pot tenir molts nivells, no només dos.

Fer un bon disseny de la jerarquia de classes facilita la ampliació de l'aplicació evitant la duplicació d'atributs i mètodes si més endavant cal crear altres tipus d'objectes semblants als que ja n'hi ha.

Classe Object

En Java, la classe Object és la classe base principal.

Totes les classes hereten d'aquesta encara que no es posi extends Object.

Aquesta classe conté mètodes que pot utilitzar qualsevol altra classe:

  • toString(): retorna un string amb informació sobre l'objecte.
    Per defecte, retorna l'identificador intern de l'objecte:

    • sardina.toString() --> uf4.animals.Peix@5ca881b5

  • equals(Object o): retorna true si un objecte és igual al que se li passa per paràmetre.
    Per defecte, retorna true si les dues referències apunten al mateix objecte:

    • Peix peix1 = new Peix("Sardina");
    Peix peix2 = new Peix("Sardina");
    peix1.equals(peix2) --> false
    peix2 = peix1;
    peix1.equals(peix2) --> true

  • getClass(): retorna la classe de l'objecte (no el nom de la classe!).
    A partir de la classe es pot obtenir el nom curt amb el mètode getSimpleName().

Alguns d'aquests mètodes, es poden sobreescriure en les altres classes per modificar la seva funcionalitat.

Per exemple, es pot fer que toString() retorni els atributs de l'objecte concatenats en un string o fer que equals() retorni true si determinats atributs dels dos objectes són iguals.
