Guardar i recuperar informació

Arxius de configuració

És habitual utilitzar arxius per guardar configuracions de programes.
Aquests arxius consisteixen en un conjunt d'elements format per una clau i un valor en format text.

Java proporciona la classe Properties per gestionar un conjunt de propietats:

Properties ref. (Java SE 17)

Crear un objecte Properties i gestionar propietats

Properties config = new Properties();
config.setProperty("clau1", "valor1");
config.setProperty("clau2", "valor2");
config.setProperty("clau2", "valor modificat de la clau 2");
System.out.println("clau1 = " + config.getProperty("clau1"));
System.out.println("clau2 = " + config.getProperty("clau2"));

Guardar les propietats en un arxiu

FileOutputStream fos;
try {
    fos = new FileOutputStream("src/uf5/exemples/config/config.cfg");
    config.store(fos, "Informacio sobre l'arxiu");
} catch (FileNotFoundException e) {
    e.printStackTrace();
} catch (IOException e) {
    e.printStackTrace();
}

Recuperar les propietats guardades en un arxiu

FileInputStream fis;
try {
    fis = new FileInputStream("src/uf5/exemples/config/config.cfg");
    config.load(fis);
} catch (FileNotFoundException e) {
    e.printStackTrace();
} catch (IOException e) {
    e.printStackTrace();
}

Les línies en blanc o que comencen amb #, s'ignoren completament.
Encara que es pugui fer, no és aconsellable editar manualment els arxius de configuració!

Guardar i recuperar dades comprimides

Es fa igual que per guardar o recuperar dades binàries en un arxiu però utilitzant les classes GZIPOutputStream i GZIPInputStream.

FileInputStream fis = null;
FileOutputStream fos = null;
GZIPInputStream gzipin;
GZIPOutputStream gzipout;

// Comprimir
try {
    fis = new FileInputStream("src/uf5/exemples/zip/arxiu.xml");
    fos = new FileOutputStream("src/uf5/exemples/zip/arxiu.xml.gz");
    gzipout = new GZIPOutputStream(fos);

    byte[] dades = new byte[1024];
    int llegits = 0;

    // Llegir de l'arxiu comprimit i guardar descomprimit
    while ((llegits = fis.read(dades)) != -1) gzipout.write(dades,0,llegits);

    gzipout.close();
    fis.close();
} catch (FileNotFoundException e) {
    e.printStackTrace();
} catch (IOException e) {
    e.printStackTrace();
}

// Descomprimir
try {
    fis = new FileInputStream("src/uf5/exemples/zip/arxiu.xml.gz");
    fos = new FileOutputStream("src/uf5/exemples/zip/arxiu.xml");
    gzipin = new GZIPInputStream(fis);

    byte[] dades = new byte[1024];
    int llegits = 0;

    // Llegir de l'arxiu comprimit i guardar descomprimit
    while ((llegits = gzipin.read(dades)) != -1) fos.write(dades,0,llegits);

    gzipin.close();
    fos.close();
} catch (FileNotFoundException e) {
    e.printStackTrace();
} catch (IOException e) {
    e.printStackTrace();
}

Guardar i recuperar objectes

Una altra forma de guardar informació és enviar els atributs d'un objecte a un arxiu.
Per poder-ho fer, cal convertir les dades de l'objecte a una sèrie de bytes (serialitzar).

Es fa de forma similar a com s'envia un objecte a través de la xarxa, serialitzant les dades que conté:

  • Els atributs estàtics no es guarden.
  • Cal que l'objecte i tots els objectes que conté implementin la interfície Serializable.
  • Crear una ruta (File) cap a l'arxiu on es vol guardar l'objecte.
  • Crear un objecte de tipus FileOutputStream amb la ruta cap a l'arxiu.
  • Crear un objecte de tipus ObjectOutputStream amb l'objecte FileOutputStream.
  • Escriure l'objecte amb la comanda writeObject(objecte).

Per recuperar-lo es fa de forma similar però substituïnt Output per Input i write per read.
Al llegir l'objecte cal transformar-lo a la classe adequada (s'ha de fer un cast).

Exemple

public class ObjecteSerial implements Serializable {
    String text;

    public ObjecteSerial(String t) {
        text = t;
    }

    public String toString() {
        return text;
    }

    public static void main(String[] args) throws IOException {
        ObjecteSerial os = new ObjecteSerial("Text de prova");
        File f = new File("src/uf5/exemples/serial/objecte.ser");

        // Guardar objecte
        FileOutputStream fos;
        ObjectOutputStream out = null;
        try {
            fos = new FileOutputStream(f);
            out = new ObjectOutputStream(fos);
            out.writeObject(os);
        } finally {
            out.close();
        }

        // Recuperar objecte
        FileInputStream fis;
        ObjectInputStream in = null;
        try {
            fis = new FileInputStream(f);
            in = new ObjectInputStream(fis);
            os = (ObjecteSerial)in.readObject();
            // Mostrar l'objecte
            System.out.println(os);
        } catch (ClassNotFoundException e) {
            e.printStackTrace();
        } finally {
            in.close();
        }
    }
}

Els atributs estàtics NO se serialitzen, per tant no es guarden.
Cal que l'objecte i tots els objectes que conté implementin la interfície Serializable.
Si s'ha guardat més d'un objecte, s'han de recuperar en el mateix ordre.
