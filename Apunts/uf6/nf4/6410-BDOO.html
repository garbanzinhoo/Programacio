BDOO

Bases de dades orientades a objectes (BDOO)

Les BDOO pretenen solventar el problema de l'adaptació entre objectes i registres que tenen les aplicacions orientades a objectes al guardar i recuperar les dades en base de dades relacionals (BDR).

En les BDOO, els objectes es guarden i es recuperen sense necessitat de fer cap transformació.

El principal inconvenient és que, al contrari que passa amb JDBC, no hi ha un estàndar consolidat per gestionar aquestes bases de dades: cada fabricant ho implementa a la seva manera.

Introducció a db4o

Aquest és un gestor de BDOO molt simple i que es pot utilitzar localment o de forma remota.

Es pot descarregar el projecte complet a GitHub db4o, però per utilitzar-lo a Java només cal extreure la llibreria db4o-8.0.249.16098-all-java5.jar i afegir-la al nostre projecte.

Connexió i desconnexió amb una base de dades db4o

Cada base de dades es guarda en un arxiu.

Per fer la connexió cal indicar la ruta de l'arxiu.
No cal crear l'arxiu prèviament: si no existeix, es crea automàticament.

import com.db4o.*;

ObjectContainer db = Db4oEmbedded.openFile("persones.db4o");
// Comandes per gestionar la base de dades
db.close();

Afegir objectes

public class Persona {
    private String nom;
    private int edat;
    private float pes;
    private float altura;

    public Persona(String nom, int edat, float pes, float altura) {
        set(nom, edat, pes, altura);
    }
}

db.store(new Persona("Peter Parker", 30, 73, 1.73f));

Si en una execució posterior es torna a crear i afegir aquesta persona, la base de dades en contindrà 2, a no ser que, abans d'afegir-la, es comprovi si ja existeix:

db.store(new Persona("Peter Parker", 30, 73, 1.73f));  // S'afegeix a la BDOO
db.store(new Persona("Peter Parker", 30, 73, 1.73f));  // Es torna a afegir a la BDOO

Si s'intenta guardar el mateix objecte, aquest no s'afegeix:

Persona p1 = new Persona("Peter Parker", 30, 73, 1.73f);
Persona p2 = p1;
db.store(p1);    // S'afegeix a la BDOO
db.store(p2);    // NO s'afegeix a la BDOO

Buscar i llegir objectes

Una forma senzilla d'obtenir un objecte és buscar-lo utilitzant un consulta senzilla (Query By Example).

  1. Crear un objecte plantilla del tipus que es vol buscar inicialitzant només els atributs necessaris (la resta s'han de posar a null o 0).
  2. Obtenir tots els objectes que coïncideixen amb l'objecte plantilla (comanda queryByExample passant-li l'objecte plantilla).
  3. Llegir els objectes utilitzant un bucle.

ObjectSet<Persona> result = db.queryByExample(new Persona("Peter Parker", 0, 0, 0));
Persona p;

while (result.hasNext()) {
    p = result.next();
    System.out.println(p);
}

Si no es poden crear objectes amb atributs nuls o algun dels paràmetres per fer la cerca és 0, s'hauran d'utilitzar altres tipus de consultes que es veuran més endavant.

Modificar objectes

Un cop s'ha llegit l'objecte de la base de dades, només cal modificar els seus atributs i tornar-lo a guardar:

p = result.next();        // Llegir
p.setNom("Peter Punk");   // Modificar
db.store(p);              // Guardar

Eliminar objectes

Primer s'ha de llegir l'objecte de la base de dades i després eliminar-lo:

p = result.next();    // Llegir
db.delete(p);         // Esborrar
