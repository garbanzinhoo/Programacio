Introducció a la programació orientada a objectes

Classes abstractes

De vegades, cal que totes les subclasses defineixin el comportament d'un mètode i que no hi hagi cap comportament per defecte.
En aquest cas, cal definir la superclasse i el mètode com abstractes, i no escriure-hi cap codi en el mètode:

public abstract class Animal {
    ...
    // S'ha de crear en totes les subclasses
    public abstract void moure();
}

public class Mamifer extends Animal {
    String moviment;

    public Mamifer(String nom, String moviment) {
        super(nom);
        this.moviment = moviment;
    }

    // Mètode sobreescrit
    public void moure() {
        System.out.println(moviment);
    }
}

public class TestAnimal {
    public static void main(String[] args) {
        Animal cabra = new Mamifer("Cabra", "Estic saltant");
        Animal lleo = new Mamifer("Lleó", "Estic corrent");
        Animal sardina = new Peix("Sardina", 100);
        ...

        cabra.moure();   // Escriu Estic saltant (crida el mètode de la subclasse Mamifer)
        lleo.moure();    // Escriu Estic corrent (crida el mètode de la subclasse Mamifer)
        sardina.moure(); // Escriu Estic nedant (crida el mètode de la subclasse Peix)
        ...
    }
}

No es poden instanciar objectes d'una classe abstracta.
