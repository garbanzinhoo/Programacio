Arrays i Strings

Diferències entre Strings i Arrays

Els strings es processen de forma similar als arrays, però no exactament igual:

  • a.length: longitud d'un array.
  • s.length(): longitud d'un string.
  • a[n]: element enèsim d'un array.
  • s.charAt(n): caràcter enèsim d'un string.

Arrays de strings

Igual que es poden crear arrays de números, caràcters o booleans, també es poden crear arrays de strings:

String[] colors = {"Vermell", "Verd", "Blau"};
for (int i = 0; i < colors.length; ++i) {
  System.out.println(colors[i]);
}

Convertir strings a arrays

Per convertir un string en un array de caràcters:

String s = "En un lugar de la mancha...";
char[] caracters = s.toCharArray();
for (int i = 0; i < caracters.length; ++i) {
  System.out.print(caracters[i] + " ");
}
System.out.println();

Per separar un string en un array de strings indicant un substring com a separador:

String s = "En un lugar de la mancha...";
String[] paraules = s.split(" ");
for (int i = 0; i < paraules.length; ++i) {
  System.out.println(paraules[i]);
}

El separador pot tenir més d'un caràcter.
Cal vigilar si el separador conté caràcters especials que s'utilitzen en expressions regulars.

Convertir arrays a strings

En el cas d'arrays de strings, la forma més senzilla és:

String[] colors = {"Vermell", "Verd", "Blau"};
String s = String.join(", ", colors);
System.out.println(s);    // Escriurà Vermell, Verd, Blau

La classe Arrays també serveix per altres tipus, però cal importar-la i el resultat no és el mateix:

import java.util.Arrays;

int[] numeros = {1, 2, 3};
String s = Arrays.toString(numeros);
System.out.println(s);    // Escriurà [1, 2, 3]
