Temporitzadors a JavaScript

Temporitzadors

Referència temporitzadors (MDN)

En les pestanyes inactives, els temporitzadors no es disparen més d'una vegada per segon.

Executar codi passat un temps

Referència setTimeout()

Referència clearTimeout()

Serveix per executar una sentència, un bloc de codi o un mètode al cap d'un temps.

La comanda setTimeout() utilitza dos paràmetres:

  • Comanda o funció que serà cridada quan passi un temps determinat.
  • Mil·lisegons que han de passar abans d'executar la comanda o funció anterior.

Si es vol cancel·lar l'execució abans que s'acabi el temps, es pot cridar la funció clearTimeout().
Aquesta funció necessita l'identificador del temporitzador, que és un valor que retorna la comanda setTimeout().

En el següent exemple, un segon després de que s'executi setTimeout(), es cridarà la funció missatge(), si no s'ha cridat abans clearTimeout():

function missatge() {
    console.log("Hola");
}
var idTimeout = setTimeout(missatge, 1000);
...
clearTimeout(idTimeout);

Si en el retard es posa 0 mil·lisegons, el codi s'executarà tan aviat com es pugui, però sempre després que finalitzi el bloc de codi on està la comanda setTimeout().

Paràmetres en la funció de callback

A més de la funció a executar i el temps de retard, també es poden afegir altres arguments.
Tots els arguments extra, es passaran a la funció de callback:

function hora(data) {
    console.log("Son les " + data.getHours() + ":" + data.getMinutes());
}
setTimeout(hora, 60000, new Date());

Executar codi cada cert temps

setInterval()

Referència setInterval()

Referència clearInterval()

Serveix per executar una sentència, un bloc de codi o un mètode a intervals regulars.

La comanda setInterval() utilitza dos paràmetres:

  • Comanda o funció que serà cridada cada cert temps.
  • Mil·lisegons que han de passar entre una execució i la següent.

Si es vol cancel·lar l'execució abans que s'acabi el temps, es pot cridar la funció clearInterval().
Aquesta funció necessita l'identificador del temporitzador, que és un valor que retorna la comanda setInterval().

En el següent exemple, un segon després de que s'executi setInterval(), es cridarà la funció missatge(), i es continuarà repetint cada segon fins que es cride a clearInterval():

function missatge() {
    console.log("Hola");
}
var idInterval = setInterval(missatge, 1000);
...
clearInterval(idInterval);

Paràmetres en la funció de callback

També s'accepten paràmetres extra en la funció setInterval():

function hora(data) {
    console.log("Son les " + data.getHours() + ":" + data.getMinutes());
}
setInterval(hora, 60000, new Date());

requestAnimationFrame()

Referència requestAnimationFrame()

Referència cancelAnimationFrame()

La principal diferència d'aquest mètode amb setInterval() és que el mètode callback es crida just abans de redibuixar la finesta del navegador.
A més, a la funció de callback se li passa un paràmetre que permet saber quant de temps ha passat des de l'última crida a aquesta funció.
Per això s'utilitza principalment per realitzar animacions que depenguin de l'intèrval entre una imatge de l'animació i la següent.
