Evolució de la programació

Primer de tot cal tenir en compte que la CPU llegeix les instruccions de la memòria en forma de voltatges: quan hi ha tensió, ho interpretem com un 1; si no hi ha tensió, ho interpretem com un 0.
Per tant, es pot dir que el llenguatge dels ordinadors està format per uns i zeros.

Aquest era el "llenguatge" que s'utilitzava al principi per programar ordinadors, però a mesura que la tecnologia va anar avançant, es van poder crear llenguatges més fàcils pels humans.

Codi màquina

Al principi, els programes s'havien d'escriure en el mateix llenguatge del processador, que està format pels bits 0 i 1.
Aquest llenguatge és molt difícil, es triga molt a fer un programa i es molt fàcil cometre errades.

Assemblador

En Assemblador, cada instrucció equival directament a una instrucció en codi màquina i només fa falta un compilador que les tradueixi per generar el programa en codi màquina.

El mateix programa anterior, en Assemblador s'escriuria així:

section .text

    global  _start

_start:

    mov     edx,len
    mov     ecx,msg
    mov     ebx,1
    mov     eax,4
    int     0x80

    mov     ebx,0
    mov     eax,1
    int     0x80

section .data

msg db      "Hello, world!",0xa
len equ     $ - msg

Llenguatges estructurats

Al ser una mica més fàcil fer programes, es van inventar altres llenguatges i els seus corresponents traductors, per exemple, el llenguatge C.

En aquest llenguatge, el programa anterior té menys comandes i és més fàcil d'entendre:

#include <stdio.h>
 
int main()  {
    char string[] = "Hello, world!";
    printf("%s\n", string);
    return 0;
}

Llenguatges orientats a objectes

Per facilitar encara més la programació van aparèixer altres mètodes, per exemple la programació orientada a objectes.

Un exemple de llenguatge orientat a objectes és Java:

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}

Llenguatges interpretats

Els llenguatges interpretats van traduïnt les instruccions del programa a codi màquina cada cop que s'executa el programa.

Un exemple de llenguatge interpretat és Python:

print("Hello, world!")

Altres llenguatges

També es poden trobar molts altres llenguatges de programació.

Alguns es van crear en el seu moment per intentar facilitar la feina de programació: Logo (precursor de Scratch), Basic...

Altres per utilitzar metodologies de programació diferents de les habituals o destinades a aplicacions concretes: Lisp (intel·ligència artificial), SQL (bases de dades)...

I també per fer aplicacions per a Internet: JavaScript, PHP...

Programació per entorns gràfics

Si bé en un principi els programes només permetien treballar en mode text, actualment la majoria d'aplicacions es fan per funcionar en mode gràfic (entorns d'escriptori, navegadors web...).

Això fa que siguin més fàcils d'utilitzar per a usuaris sense gaires coneixements informàtics, però el desenvolupament pot ser més complicat.

Entorns de desenvolupament (IDEs)

Antigament s'havien d'utilitzar editors de text per fer els programes i un compilador per convertir-los al llenguatge màquina o un intèrpret per executar-los.

Actualment s'utilitzen entorns de desenvolupament que faciliten totes aquestes tasques proporcionant eines i llibreries que estalvien molta feina.

Alguns permeten programar en diferents llenguatges (C, Java, Python...) i generar programes per a diferents plataformes (ordinadors, mòbils, webs...) i sistemes operatius (Windows, Linux...).

IntelliJ, Visual Studio i Eclipse són només alguns dels entorns de desenvolupament per programació general, però també hi ha de més específics, per exemple per programar jocs (Unity).

També existeixen editors i depuradors online que poden servir per provar petits programes.

IA i assistents de codi

Els entorns de desenvolupament ajuden cada cop més en el procés de desenvolupament d'aplicacions, amb extensions que generen o completen codi a partir del què el programador escriu, però la revolució més important dels últims anys ha sigut l'aparició de la intel·ligència artificial generativa.

Les IA generatives poden resultat una ajuda inestimable per:

  • aprendre a programar (o aprendre qualsevol altre cosa)
  • resoldre problemes simples
  • obtenir una primera aproximació a la solució que es busca
  • explorar diferents opcions

Però les IA actuals també tenen limitacions:

  • sembla que encara falta bastant per poder crear projectes sencers
  • de vegades generen codi incorrecte (alguns parlen d'un 50% de codi erroni)
  • el codi generat pot ser de poca qualitat i acostuma a incloure control d'errors
  • pot "generar" codi protegit per llicències privatives

El que no s'ha de fer mai és:

  • confiar cegament en les respostes (heu sentit parlar de les "al·lucinacions" de les IA?)
  • utilitzar el codi proporcionat sense comprovar-lo a fons
  • copiar i enganxar el codi generat sense entendre com funciona
