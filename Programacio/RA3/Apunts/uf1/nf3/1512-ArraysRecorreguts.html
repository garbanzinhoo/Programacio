Arrays: recorreguts

Consultar o modificar tots els elements d'un array (fer un recorregut)

La millor forma de processar tots els elements d'un array és fer un bucle for que recorri tots els elements:

int[] notes = {5, 8, 7};
int total = 0;

for (int i = 0; i < notes.length; ++i) {
  total += notes[i];
}
System.out.printf("Mitjana: %.1f\n", ((float)total / notes.length));

Recorregut complet d'un array utilitzant un bucle for-each

Si es vol fer un recorregut complet, es pot simplificar amb la següent versió del bucle for:

int[] array = {5, 3, 4, 7, 2};
for (int n: array) {
    System.out.println(n);
}

La variable n ha de ser del mateix tipus que els elements de l'array.
En cada iteració del bucle, n agafarà el valor d'un element de l'array: en la primera iteració, n serà array[0], en la segona, array[1], etc...

Aquest bucle és equivalent a:

int[] array = {5, 3, 4, 7, 2};
int n;
for (int i = 0; i < array.length; i++) {
    n = array[i];
    System.out.println(n);
}

Utilitat de recòrrer tot l'array

Inicialitzar tots els elements d'un array (inicialització procedural)

Consisteix en crear un algorisme que doni valors a tots els elements de l'array.
Es pot fer que aquest valor sigui el mateix per cada element (inicialitzar-los tots a 10) o posar un valor diferent per cada un (inicialitzar cada posició amb múltiples d'un número).

int n[] = new int[10];

// Copiar els elements al nou array
for (int i = 0; i < n.length; i++) {
  n[i] = (i + 1) * 5;
}

Copiar els valors d'un array en un altre

Al contrari que passa amb les variables que contenen dades primitives (números, caràcters i booleans), no es pot copiar un array assignant-lo a un altre:

int n1 = 5;
int n2 = n1;           // OK: si es modifica n2 no es modifica n1 (són independents)
char[] c1 = {'a', 'b', 'c'};
char[] c2 = c1;        // Possible ERROR: si es modifica c2, es modifica c1

El què cal fer és crear un nou array amb la mateixa mida (o superior) i copiar els valors un a un.

int n[] = {9,4,6,3};
int m[] = new int[n.length];    // Crear un array de la mateixa mida

// Copiar els elements al nou array
for (int i = 0; i < n.length; i++) {
  m[i] = n[i];
}

Comparar arrays

Igual que passa amb els strings, no es pot saber si dos arrays són iguals utilitzant l'operador ==.

La forma de fer-ho és recórrer tots els elements dels dos arrays i comparar-los un a un (els dos arrays han de tenir la mateixa mida):

int[] a1 = {1, 2, 3};
int[] a2 = {1, 2, 3};
System.out.println("Son iguals? " + (a1 == a2));    // ERROR: dirà false

boolean sonIguals = true;
for (int i = 0; i < a1.length; ++i) {
  if (a1[i] != a2[i]) {
    sonIguals = false;
    break;
  }
}
System.out.println("Son iguals? " + sonIguals);    // OK
