Comandes o arxius de configuració

Executa les següents comandes per instal·lar el servei LDAP:

sudo apt update
sudo apt install slapd

Edita l'arxiu /etc/hosts:

127.0.0.1    localhost
127.0.1.1    usxxx.ldapxxx.local    usxxx

Comandes amb la consola

usuari@usxxx:~$ ldapsearch -x -LLL dn
dn: dc=ldapxxx,dc=local
dn: cn=admin,dc=ldapxxx,dc=local
