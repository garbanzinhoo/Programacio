Arrays ordenats

De vegades és necessari presentar les dades de forma ordenada (de més petites a més grans o al revès).
A més, cercar informació en un conjunt de dades ordenades és més eficient.

En aquests casos cal disposar d'algun mètode per ordenar les dades d'un array o per trobar de forma ràpida les dades en un l'array ordenat.

Algorisme de cerca binària

Si l'array està ordenat, una forma ràpida de trobar un element determinat és comparar amb l'element del mig. Si l'element que es vol trobar és més gran, es compara amb l'element que està entre el del mig i el del final. I així successivament fins que ja no es pot dividir més l'array o fins que es troba l'element.

int n[] = {3,4,6,9};      // Llista de valors
int valor = 6;            // Valor buscat
int min = 0;              // Primera posició de la llista
int max = n.length - 1;   // Última posició de la llista
int mid = 0;              // Posició central (inicialitzar per evitar error)

while (min <= max) {
  mid = (min + max) / 2;  // Calcular la posició central del tram entre min i max
  if (n[mid] < valor) {
    min = mid + 1;        // Agafar la meitat superior
  } else if (n[mid] > valor) {
    max = mid - 1;        // Agafar la meitat inferior
  } else {
    break;                // Valor trobat
  }
}

if (n.length > 0 && n[mid] == valor) {
  System.out.println("S'ha trobat el valor en la posició " + mid);
} else {
  System.out.println("NO s'ha trobat el valor en la llista");
}

Fent petites modificacions en aquest algorisme es poden tractar casos especials com quan hi ha més d'un element igual (trobar el primer) o trobar el més proper si no hi ha el valor exacte.

Algorisme senzill (i lent) d'ordenació

El mètode d'intercanvi és bastant ineficient, però és relativament senzill d'entendre.

Consisteix en comparar el primer element amb tots els altres i intercambiar-los si el primer és més gran que l'altre. Després es repeteix amb el segon, i així successivament fins al penúltim element.

int n[] = {9,4,6,3};
int t;

// Agafa el primer valor entre el primer i el penúltim
for (int i = 0; i < n.length - 1; i++) {
  // Agafa el segon valor entre el següent al primer i l'últim
  for (int j = i + 1; j < n.length; j++) {
    // Intercanviar si el primer és més gran que el segon
    if (n[i] > n[j]) {
      t = n[i];
      n[i] = n[j];
      n[j] = t;
    }
  }
}

// Mostrar els valors ja ordenats: 3, 4, 6 i 9
for (int i = 0; i < n.length; i++) {
  System.out.println(n[i]);
}       

Altres mètodes senzills però lents: el mètode de la bombolla, el mètode d'inserció i el de selecció.
Altres mètodes més eficients: quick sort, merge sort i heap sort.
