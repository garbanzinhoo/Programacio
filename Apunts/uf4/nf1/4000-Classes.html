Introducció a la programació orientada a objectes

Classes amb mètodes i atributs estàtics

En programació estructurada i disseny modular, les classes s'utilitzen simplement per agrupar funcions.

En aquest cas, les funcions i variables globals es poden declarar com:

  • static (estàtiques) si només es volen utilitzar des d'altres funcions de la mateixa classe.
  • public static (públiques i estàtiques) si es volen utilitzar des d'altres classes.

package uf4.exemples;

public class Estils {
    // Atributs de la classes (estàtics)
    static final String DEFAULT = "\u001b[0m";
    static final String RED = "\u001b[31m";

    // Mètode privat de la classe (estàtic)
    static String errorColor() {
        return RED;
    }

    // Mètode públic de la classe (públic i estàtic)
    public static void printError(String missatge) {
        System.out.println(errorColor() + missatge + DEFAULT);
    }
}

Per cridar una funció des d'una altre classe (ha de ser pública i estàtica), cal importar la classe i afegir al davant el nom de la classe que la conté:

package uf4;

import uf4.exemples.Estils;

public class Main {
    public static void main(String[] args) {
        Estils.printError("ERROR!");
    }
}

En la llibreria Java, un exemple de classe que només conté mètodes i atributs estàtics és la classe Math:

  • Math.PI és un atribut estàtic i públic
  • Math.pow() és un mètode estàtic i públic

double areaCercleRadi10 = Math.PI * Math.pow(10, 2);
