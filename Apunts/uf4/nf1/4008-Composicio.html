Introducció a la programació orientada a objectes

Objectes compostos

Sovint, en el mon real, hi ha objectes que estan formats per altres objectes.
Per exemple, un cotxe està format pel motor, l'habitacle...

La POO també permet crear classes (i objectes) que estiguin formats per altres objectes.
En la classe composta cal incloure un o més atributs que siguin objectes d'altres classes.
Al constructor se li passaran els objectes de les classes que el componen.

public class Motor {
    int nCilindres;
    int cilindrada;
    float potència;
    ...
}

public class Habitacle {
    int nPlaces;
    boolean aireCondicionat;
    ...
}

// Classe composta
public class Cotxe {
    float preu;
    Motor motor;
    Habitacle habitacle;
    ...
   
    // Constructor
    public Cotxe(Motor m, Habitacle h, float p) {
        motor = m;
        habitacle h;
        preu = p;
    }
}

Crear objectes compostos

Per crear un cotxe, abans s'hauran de crear uns quants objectes dels tipus que el componen:

public static void main(String[] args) {
    // Crear diferents components
    Motor m1 = new Motor(8, 1600, 120);
    Motor m2 = new Motor(8, 1200, 85);
    ...
    Habitacle h1 = new Habitacle(3, false);
    Habitacle h2 = new Habitacle(5, true);
    ...

    // Crear cotxes combinant components
    Cotxe c1 = new Cotxe(m1, h1, 25000);
    Cotxe c2 = new Cotxe(m1, h2, 30000);
    Cotxe c3 = new Cotxe(m2, h2, 35000);
    ...
}

Conjunts d'objectes

També es poden trobar objectes formats per un o més conjunts d'objectes del mateix tipus.
Per exemple, un institut està format per un conjunt de professors i un conjunt d'alumnes.

Aquests casos es resolen creant un array (o qualsevol conjunt de dades) amb elements del mateix tipus.
Aquests arrays es poden inicialitzar de forma global o passant paràmetres en el constructor.
També acostumen a tenir mètodes per guardar objectes del tipus corresponent en els arrays.

public Alumne {
    String idAlu;
    String nom;
    ...
}

public Professor {
    String nom;
    String departament;
    ...
}

// Classe composta amb atributs que són conjunts de dades
public class Institut {
    String nom;
    Alumne[] alumnes;
    Professor[] professors;
    ...

    // Constructor
    public Institut(String n, int nAlumnes, int nProfessors) {
        nom = n;
        alumnes = new Alumne[nAlumnes];
        professors = new Professor[nProfessors];
    }

    // Mètodes
    public void afegirAlumne(Alumne a, int ndx) {
        alumnes[ndx] = a;
    }

    public void afegirProfessor(Professor p, int ndx) {
        professors[ndx] = p;
    }
}

En el següent exemple, es crea un institut per 800 alumnes i 85 professors, i s'afegeixen alumnes i  profes:

public static void main(String[] args) {
    Institut sapa = new Institut("Ins. Sa Palomera", 800, 85);
    sapa.afegirAlumne(new Alumne("1234", "Joanet de Culestret"), 0);
    sapa.afegirProfessor(new Professor("Perico Chico", "Cicles d'informàtica"), 0);
}
