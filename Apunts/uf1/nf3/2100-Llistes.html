Llistes en JavaScript

Arrays

Referència

Si es vol utilitzar un conjunt de dades relativament gran per processar-les més endavant de diferents formes, no és útil tenir-les guardades en variables independents, especialment si no es coneix el nombre de dades.

Per exemple, si tenim les notes de 30 alumnes, no és pràctic utilitzar les variables n1, n2, n3, ... , n30.
Per això s'han inventat els arrays.

Un array és una llista ordenada d'elements.
Cada element està identificat amb un índex (un número).
Es pot saber la mida d'un array amb l'atribut length (llista.length).

El primer element d'una llista té l'índex 0.
L'últim element d'una llista està a la posició llista.length - 1.

En JavaScript, els elements d'un array no tenen perquè ser tots del mateix tipus.
A més, els elements poden ser valors primitius (booleans, números i strings), però també altres llistes o objectes complexos.

No és obligatori, però és molt recomanable, que tots els elements d'una llista siguin del mateix tipus.
D'aquesta forma es faciliten el processos que habitualment s'han de fer amb tots els elements.

Un array es representa amb claudàtors (parèntesis quadrats) i separant els elements amb una coma:

  • [] és un array buit.
  • ["SMX", "ASX", "DAW"] és un array amb 3 elements.

Crear, inicialitzar i eliminar llistes

let cicles = ["SMX", "ASX", "DAW"];  // Creem una llista i l'assignem a una variable
cicles = [];                         // Assignem a la variable una llista buida
                                     // També es pot fer: cicles = undefined;

Obtenir i modificar un element d'un array

Es pot accedir als elements d'un array utilitzant un índex (posició de l'element dins de l'array).
La primera posició és la 0.

L'índex es posa entre [ i ]:

let cicles = ["SMX", "DAW"];
let cicle = cicles[0];    // cicle = "SMX";
cicles[1] = "DAM";        // cicles = ["SMX", "DAM"];

Afegir i eliminar elements

En JavaScript, els arrays no tenen una mida fixa: es poden afegir o eliminar elements en qualsevol moment.

A més, es poden afegir elements deixant espais buits:

let cicles = ["SMX", "ASX", "DAW"];
cicles[5] = "DAM";   // Els elements cicles[3] i cicles[4] quedaran buits (empty)

IMPORTANT: més endevant es veuran mètodes per recórrer o tractar tota la llista.
Algunes funcions poden donar resultats inesperats quan hi ha valors buits, undefined, null, NaN...
Per això el més recomanable és inicialitzar tots els elements de les llistes amb valors concrets.

Algunes funcions que permeten afegir o eliminar un element a un array són:

  • push(element): afegeix l'element al final de la llista.
  • pop(): retorna l'últim element de la llista i l'elimina.
  • unshift(element): afegeix l'element al principi de la llista.
  • shift(): retorna el primer element de la llista i l'elimina.

També es poden afegir els elements d'una o vàries llistes a una altra amb la comanda concat():

let cicles = ["SMX", "ASIX"];
let c2 = ["DAM", "DAW"];
cicles.concat(c2);   // Ara cicles conté ["SMX", "ASIX", "DAM", "DAW"]

Arrays constants

El significat del modificador const davant d'un array pot ser confús: evita que es modifiqui l'apuntador cap a l'array però no impedeix que es modifiqui l'array.

const numeros = [1, 2, 3];
numeros[0] = 0;             // OK: [0, 2, 3]
console.log(numeros);
numeros.push(5);            // OK: [0, 2, 3, 5]
console.log(numeros);
numeros = [4, 5, 6];        // error

Assignació d'arrays

Al contrari que passa amb les variables primitives, al assignar a una variable una altra que conté un array, no es fa una còpia del contingut, sinó que totes dues variables apunten al mateix array.

Això implica que si es modifica algun element en alguna de les variables, també es modifica en l'altra:

let cicles1 = ["SMX", "ASX", "DAW"];
let cicles2 = cicles1;   // Totes dues variables apunten al mateix array

cicles1[1] = "ASIX";     // 'cicles2[1]' també serà "ASIX"
cicles2 = {};            // Ara l'array només està assignat a la variable 'cicles1'
cicles1 = undefined;     // Una altra forma de treure un array d'una variable

Quan un array no té cap variable assignada, s'envia a la recollida d'escombraries per ser eliminat.
