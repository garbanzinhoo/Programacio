Estructures condicionals (III)

... ? ... : ... (operador condicional ternari)

Aquesta estructura s'utilitza habitualment per fer assignacions amb condicions i expressions senzilles.

Només s'ha d'utilitzar si ens permet reduir l'expressió resultant a una línia curta que es llegeixi fàcilment.
En cas contrari (si acaba sortint una línia llarga i complicada), perd tota la seva utilitat.

La condició es posa abans de ?.
Entre ? i : es posa el valor que s'ha d'assignar si la condició és certa.
Després de : es posa el valor que s'ha d'assignar si la condició és falsa.

let menor = (a < b) ? a : b;

Serveix per simplificar una estructura if com la següent:

let menor;

if (a < b)
  menor = a;
else
  menor = b;

També es pot utilitzar per triar entre tres o més valors, però la sentència resulta complicada de llegir:

let q = n < 5 ? "Suspès" : (n < 7 ? "Aprovat" : (n < 9 ? "Notable" : "Excel·lent"));

En un cas com aquest, seria  preferible la versió llarga amb condicionals encadenats:

let q = "";

if (n < 5) q = "Suspès";
else if (n < 7) q = "Aprovat";
else if (n < 9) q = "Notable";
else q = "Excel·lent";

Recomanacions per triar entre els diferents tipus de condicionals

  • S'ha d'utilitzar blocs condicionals independents quan les condicions per executar un bloc o un altre no estan relacionades entre elles.
  • Els blocs condicionals encadenats són útils quan les condicions per executar un dels blocs són mutuament exclusives (si es compleix una condició, s'executa el bloc de codi corresponent i no s'analitzen les altres condicions ni s'executa cap dels altres blocs de codi).
    També són la millor opció quan s'ha de triar entre diferents rangs de valors contigus.
  • Els blocs condicionals niuats s'utilitzen quan s'ha de triar entre diferents blocs de codi amb condicions complexes en què algunes de les condicions més específiques depenen d'altres més generals.
  • L'operador ternari només s'hauria d'utilitzar per assignar a una variable un valor o un altre en funció d'una condició simple. Si el resultat és una sentència difícil de llegir, serà preferible utilitzar altres tipus de condicionals.
