# Programació (DAW)

Exercicis del mòdul de **Programació** del cicle de Desenvolupament d'Aplicacions Web (DAW), a l'Institut Sa Palomera (Blanes).

Tot el codi és JavaScript i s'executa al navegador. Cada exercici té el seu `index.html` i `index.js`, i es prova amb l'extensió **Live Server** de VS Code.

## Estructura

| Carpeta | Contingut |
|---|---|
| `01_Exercicis` | Primers exercicis |
| `02_Exercicis Strings` | Exercicis amb cadenes de text |
| `03_Introduir dades` | Entrada de dades amb `prompt` |
| `04_IF` | Condicionals (`if`, `else`, `switch`) |
| `05_Acces restringit` | Exercicis d'accés restringit |
| `06_While` | Bucles `while` |
| `07_For` | Bucles `for` |
| `08_Funcions` | Funcions |
| `09_Repàs_string` | Repàs de strings |
| `10_Exercicis_funcions_amb_parametres` | Funcions amb paràmetres, mòduls (`import`/`export`) i JSDoc |
| `Menu` | Menú que reuneix diversos exercicis |
| `Examen 1` | Examen |
| `Apunts` | Apunts |
| `utils` | Funcions reutilitzables (validacions) importades des dels exercicis |

## Com executar-ho

1. Obre la carpeta amb VS Code.
2. Instal·la l'extensió **Live Server**.
3. Fes clic dret a l'`index.html` de l'exercici i tria **Open with Live Server**.

Els exercicis que fan servir mòduls (`<script type="module">`) no funcionen si s'obre l'HTML amb doble clic: cal Live Server.
