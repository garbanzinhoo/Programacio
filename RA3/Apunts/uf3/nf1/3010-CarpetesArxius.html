Gestió del sistema de fitxers

Pels exemples s'ha utilitzat la següent estructura d'arxius i carpetes:

─ Proves
   ├─ arxiu.txt
   └─ Subcarpeta

La gestió del sistema de fitxers permet localitzar arxius i carpetes indicant la seva ruta, crear, esborrar copiar i moure arxius i carpetes, obtenir informació sobre els arxius i les carpetes...

La principal classe que ens permet fer això i més, es troba en el mòdul java.base, paquet java.io i es diu File, i cal importar-la abans de poder-la utilitzar:

import java.io.File

File: referència oficial

Per utilitzar les seves funcionalitats cal crear un objecte d'aquesta classe indicant la ruta.
Aquesta ruta pot ser tant d'una carpeta com d'un arxiu:

File carpeta = new File("Proves");
File arxiu = new File("Proves/arxiu.txt");

No es pot posar un String buit. Per indicar la carpeta de treball actual cal posar ".".

Exemples de rutes

File arxiu = new File("Proves");                           // Ruta Relativa
arxiu = new File("C:/Users/usuari/IdeaProjects/Arxius");   // Windows Absoluta
arxiu = new File("/home/usuari/IdeaProjects/Arxius");      // Linux Absoluta

Una ruta relativa té com a base la carpeta des de la que s'executa el programa.
Si es vol crear la carpeta o l'arxiu en un directori base diferent, al crear el File se li ha de passar aquest directori base com a primer paràmetre:

String baseDir = "C:/Users/usuari";
File arxiu = new File(baseDir, "Proves");

El . representa la carpeta actual.
Els .. representen la carpeta pare.

Encara que en Windows el separador és la contrabarra (\), en Java es pot utilitzar la barra (/).
Si es vol utilitzar la contrabarra, cal escriure-la dos cops (\\).

Funcions per obtenir informació sobre arxius i carpetes

  • exists(): per saber si la ruta existeix.
  • isHidden(): per saber si l'arxiu o carpeta està amagat.
  • canRead(): per saber si l'arxiu o carpeta es pot llegir.
  • canWrite(): per saber si l'arxiu o carpeta es pot modificar.
  • canExecute(): per saber si l'arxiu es pot executar.
  • isFile(): per saber si és un arxiu.
  • isDirectory(): per saber si és una carpeta.
  • length(): per saber la mida.
  • lastModified(): per saber la data de l'última modificació. Retorna els mil·lisegons des de les 0:00 hores del 1/1/1970.

També hi ha els mètodes equivalents per modificar aquests atributs: setReadable(), setWritable(), setExecutable(), setLastModified()...

Exemples

File f = new File("./Proves/arxiu.txt");

System.out.println("\nPath:       " + f);
System.out.println("Exists:       " + f.exists());
if (!f.exists()) return;

System.out.println("Hidden:       " + f.isHidden());
System.out.println("Read:         " + f.canRead());
System.out.println("Write:        " + f.canWrite());
System.out.println("Execute:      " + f.canExecute());
System.out.println("File:         " + f.isFile());
System.out.println("Directory:    " + f.isDirectory());
System.out.println("Length:       " + f.length());
System.out.println("LastModified: " + f.lastModified());
Date d = new Date(f.lastModified());
System.out.println("LastModified: " + d.toString());

Funcions per obtenir informació sobre la ruta

  • getName(): retorna el nom de l'arxiu o la carpeta.
  • getParent() o getParentFile(): retorna la carpeta pare on es troba l'arxiu o carpeta.
    Si la ruta amb la que s'ha creat el File és relativa, pot retornar null.
  • getAbsolutePath() o getAbsoluteFile(): retorna la ruta absoluta.
  • getCanonicalPath() o getCanonicalFile(): retorna la ruta absoluta eliminant símbols redundants com . o ...

La diferència entre get...Path i get...File és que les primeres retornen un String mentre que les segones retornen un File.

File f = new File("./Proves/arxiu.txt");

System.out.println("Name:          " + f.getName());
System.out.println("Parent:        " + f.getParent());
System.out.println("ParentFile:    " + f.getParentFile());
System.out.println("Path:          " + f.getPath());
System.out.println("AbsolutePath:  " + f.getAbsolutePath());
System.out.println("AbsoluteFile:  " + f.getAbsoluteFile());
try {
    System.out.println("CanonicalPath: " + f.getCanonicalPath());
    System.out.println("CanonicalFile: " + f.getCanonicalFile());
} catch (IOException e) {
    e.printStackTrace();
}

Funcions per crear, esborrar, renombrar i moure

  • mkdir(): crea un directori (cal que la ruta fins al pare existeixi).
  • mkdirs(): crea un directori i, si cal, els pares.
  • createNewFile(): crea un arxiu buit excepte si ja existeix.
  • renameTo(): canvia el nom d'un arxiu o el mou a una altra ruta.
  • delete(): esborra un arxiu o directori. Si es tracta d'un directori, cal que estigui buit.

Aquests mètodes no llancen una excepció si no poden realitzar l'acció que se'ls ha demanat.
Per saber si l'han fet o no, s'ha de comprovar el valor de retorn, que serà true o false.

Exemples

File directori2 = new File("Proves/Subcarpeta2");
boolean created = directori2.mkdir();
if (created) System.out.println("Directori creat correctament");
else System.out.println("El directori no s'ha creat");

File arxiu2 = new File("Proves/arxiu2.txt");
try {
    arxiu2.createNewFile();
} catch (IOException e) {
    System.out.println("Error al crear l'arxiu");
}

File arxiu3 = new File("Proves/Subcarpeta2/arxiu3.txt");
arxiu2.renameTo(arxiu3);

arxiu3.delete();

boolean deleted = directori2.delete();
if (deleted) System.out.println("Directori esborrat correctament");
else System.out.println("El directori no s'ha esborrat");

Altres funcions interessants

  • list() o listFiles(): si l'objecte File és una carpeta, obté un array de Strings o de File amb els arxius i carpetes que conté.
  • listRoots(): retorna un array de File amb els sistemes d'arxius de la màquina.
    En Windows podria ser C:\, E:\... En Linux podria ser / (el directori arrel).
  • getTotalSpace(): obté la mida en bytes de la partició on es troba el File.
  • getFreeSpace(): obté l'espai lliure en bytes de la partició on es troba el File.
  • getUsableSpace(): obté l'espai que pot utilitzar la màquina virtual de la partició on es troba el File.
Exemples

File carpeta = new File("Proves");

System.out.println("\nLlistat d'arxius i carpetes");
File[] f = carpeta.listFiles();
for (int i = 0; i < f.length; ++i) {
    System.out.printf("%s   %6d bytes   %s\n", (f[i].isFile() ? "A   " : "D   "), f[i].length(), f[i].getName());
}

System.out.println("\nLlistat de sistemes de fitxers");
File[] roots = File.listRoots();
for (int i = 0; i < roots.length; ++i) {
    System.out.println(roots[i].getAbsolutePath());
}

System.out.println("\nEspai en el SF de la carpeta");
System.out.printf("\nTotalSpace: %4d GiB\n", carpeta.getTotalSpace() / 1024 / 1024 / 1024);
System.out.printf("FreeSpace:  %4d GiB\n", carpeta.getFreeSpace() / 1024 / 1024 / 1024);
System.out.printf("UsableSpace:%4d GiB\n", carpeta.getUsableSpace() / 1024 / 1024 / 1024);

Sistemes d'arxius en Linux (avançat)

En Linux, la comanda File.listRoots() no serveix per obtenir els sistemes d'arxius muntats.

Els objectes de la classe FileStore permeten obtenir l'espai total i lliure, entre altres dades, i aquests objectes es poden obtenir de la següent forma:

for (FileStore store : FileSystems.getDefault().getFileStores()) {
    long espai = store.getUsableSpace();
    String nom = store.toString();
    // (/dev per Linux; :) per Windows
    if (espai > 0 && (nom.contains("(/dev") || nom.contains(":)")))
        System.out.println(nom);
}

El problema d'aquest mètode és que, en Linux, pot retornar molts dispositius que en realitat no són particions, per això cal filtrar, per exemple, per l'espai utilitzable i pel nom.

Una altra diferència amb File.listRoots() és com es mostren els noms dels sistemes d'arxius:
en Windows, C:\ vs [Etiqueta] (C:)
en Linux, / vs / (/dev/hda1)

Classe System

Pot servir per consultar el directori des d'on s'executa l'aplicació.

  • System.getProperty("user.name"): obté un String amb l'identificador de l'usuari.
  • System.getProperty("user.home"): obté un String amb la ruta absoluta del directori de l'usuari.
  • System.getProperty("user.dir"): obté un String amb la ruta absoluta del directori de treball.

System.out.println(System.getProperty("user.name"));
System.out.println(System.getProperty("user.home"));
System.out.println(System.getProperty("user.dir"));

usuari
/home/usuari
/home/usuari/IdeaProjects/Arxius

També permet consultar el directori i la versió de Java (java.home i java.version) i el nom i la versió del sistema operatiu (os.name i os.version).

Utilitzar llibreries externes

Encara que la llibreria de Java és força extensa, es troben a faltar algunes funcions molt útils.
Per exemple, si es vol copiar una carpeta i el seu contingut, s'ha de fer recursivament.

Una de les llibreries més conegudes és la d'Apache.
Concretament, per la gestió d'arxius i carpetes, hi ha el paquet commons.io.

Es pot trobar la documentació i els arxius a descarregar en la web https://commons.apache.org/proper/commons-io/

Un cop descarregat, es pot descomprimir en qualsevol directori.
Si es vol fer accessible a tots els usuaris de la màquina, es pot fer a C:/Archivos de programa/Apache/Commons o /usr/lib/apache/commons.
Si no, es pot descomprimir dins del directori usuari/IdeaProjects/commons.

Per utilitzar-lo en un projecte de IntelliJ, dins de File → Project Structure... → Libraries, afegir l'arxiu commons-io-x.xx.x.jar.

Finalment, en l'arxiu de la classe on es vol utilitzar, cal importar org.apache.commons.io.FileUtils.

Una de les funcions més interessants és la de copiar una carpeta i tot el seu contingut:

File fo = new File(dirOrigen);
File fd = new File(dirDesti);
try {
    FileUtils.copyDirectory(fo, fd);
} catch (IOException e) {
    e.printStackTrace();
}

Un altre mètode útil per obtenir la mida total dels arxius d'una carpeta i de les seves subcarpetes:

File dir = new File(directori);
try {
    long mida = FileUtils.sizeOfDirectory(dir);
} catch (IOException e) {
    e.printStackTrace();
}

Si s'havia creat el JAR, cal anar a File → Project Structure... → Artifacts, buscar en Available Elements la llibreria commons-io-x.xx.x i seleccionar Extract Into Output Root del menú contextual.
