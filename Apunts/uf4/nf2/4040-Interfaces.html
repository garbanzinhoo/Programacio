Introducció a la programació orientada a objectes

Interfícies

Java no permet que una subclasse hereti de més d'una superclasse.
La solució està en utilitzar interfícies.

Amb les interfícies es poden afegir noves funcionalitats a una classe definint els mètodes de les interfícies que es vulguin implementar.

Les interfícies són similars a les classes però sense atributs i amb tots els mètodes abstractes.
Una classe pot implementar més d'una interfície.

Definir una interfície

Es fa de forma similar a una classe però canviant la paraula class per interface.

En els mètodes no cal posar el modificador d'accés (públic, private...).
Tampoc s'ha posar cap codi: després de definir el mètode i paràmetres, s'acaba la línia amb ;.

interface Jugador {
    void caminar();
    boolean buscar(Object o);
    void atacar(Object o);
}

Implementar una interfície

class Guerrer implements Jugador {
    public void caminar() {
        posicio += 10;
    }

    public boolean buscar(Object o) {
        if (this.distancia(o) < 30) return true;
        return false;
    }

    public void atacar(Objecte o) {
        if (this.distancia(o) < 20) {
            o.energia -= 50;
            this.energia += 50;
        }
    }
}

Els mètodes que implementen una interfície només poden ser públics!

Interfícies de Java

La llibreria de Java inclou moltes interfícies.

interface Comparable

Aquesta interfície serveix per poder comparar objectes indicant l'ordre de dos elements (si un és més petit, més gran o igual que l'altre).
Els objectes que implementin aquesta interfície podran ser ordenats utilitzant mètodes d'ordenació dels conjunts de dades (arrays i altres que es veuran més endavant).

L'únic mètode que cal implementar en les classes que vulguin utilitzar aquesta interfície és compareTo().

Per poder-la utilitzar amb un tipus d'objecte específic, cal indicar el tipus de la següent forma:

class Persona implements Comparable<Persona> {
    public int compareTo(Persona p) {
        if (this.edat < p.edat) return -1;
        else if (this.edat > p.edat) return 1;
        else return 0;
    }
}

Per ordenar un array de persones, seria tan fàcil com fer:

Persona[] persones = new Persona[10];
// ... crear persones i afegir-les a l'array ...
Arrays.sort(persones);
