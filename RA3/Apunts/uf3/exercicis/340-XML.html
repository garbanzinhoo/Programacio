XML

Per fer els exercicis necessitaràs els segúents arxius:

  • menu.xml
  • llibres.xml
  • musica.xml
  • plantes.xml

Mostrar arbre d'elements

Fes un programa que mostri en forma d'arbre els elements d'un arxiu XML.
Opcionalment, també pots fer que es mostrin els atributs de cada element, si en té.

Per exemple, amb l'arxiu menu.xml hauria de sortir una cosa semblant a la següent (el text destacat correspon als nodes de tipus text; la resta són nodes de tipus element):

esmorzar
    tipus
        nom
            Lleuger
        preu
            5.95€
        descripcio
            Café i Croissant
        calories
            650
    tipus
        nom
            Normal
        preu
            7.95€
        descripcio
            Suc de taronja i tostades amb mantega i melmelada
        calories
            900
...

Filtrar elements

Amb l'arxiu llibres.xml:

  • mostra la informació dels llibres del gènere Fantasy.
  • mostra la informació dels llibres que tinguin la paraula Microsoft en la seva descripció.
  • mostra la informació dels llibres amb un preu inferior a 5 €uros.
  • mostra la informació del llibre amb l'identificador bk106.
  • guarda els llibres en un HashMap utilitzant com a clau el seu identificador.
    • busca en el HashMap el llibre amb l'identificador bk106 i mostra la seva informació.
    • busca en el HashMap el llibre amb l'identificador bk107 i esborra'l del document i del HashMap.
      Mostra tots els llibres del document (no del HashMap) per comprovar que realment s'ha esborrat.

Amb l'arxiu musica.xml:

  • mostra els discos que costen entre 8€ i 9€.
  • mostra agrupats els discos que tenen el mateix preu (només cal mostrar el títol).
    Opcionalment, mostra'ls ordenats de més barats a més cars.

Processar dades

Amb l'arxiu plantes.html:

  • incrementa un 20% el preu de totes les plantes.
  • tradueix els que tenen tipus de llum Shade per Ombra.
  • afegeix un element WATHERING a totes les plantes i posa-hi el text Every day.
  • afegeix una planta (per exemple una rosa) amb totes les seves dades.

Crea un nou document en memòria per guardar dades sobre les teves aficions.

Convé que, després de cada modificació, mostris les dades per comprovar que s'ha fet correctament.

Guardar document

Guarda l'arxiu plantes.xml després de fer les modificacions de l'exercici anterior.

Guarda en l'arxiu aficions.xml el document creat amb les teves aficions.
