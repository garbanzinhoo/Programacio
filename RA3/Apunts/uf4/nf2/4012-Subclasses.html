Introducció a la programació orientada a objectes

Creació de subclasses

Cada subclasse ha d'anar en un arxiu propi (no s'han de juntar amb altres classes o subclasses).

Per crear subclasses, cal afegir extends ClasseMare a la definició de la subclasse:

// Classe "mare"
public class Animal { ... }

// Classe "filla"
public class Mamifer extends Animal { ... }

// Classe "filla"
public class Peix extends Animal { ... }

// Classe "filla"
public class Ocell extends Animal { ... }

Constructors de subclasse i mètode super()

Per no haver d'inicialitzar els atributs que té la classe "mare", es pot utilitzar el mètode super() amb els atributs que tingui algun dels constructors de la superclasse.

public class Peix extends Animal {
    int profunditat;

    public Peix(String nom, int profunditat) {
        super(nom);
        this.profunditat = profunditat;
    }

    public int getProfunditat() {
        return profunditat
    }
}

Aquesta funció s'ha de posar la primera dins del constructor de la subclasse.

Creació i utilització d'objectes d'una subclasse

Una forma és crear una variable del mateix tipus que la subclasse:

Peix sardina = new Peix("Sardina");

Utilitzar variables de superclasse amb objectes de subclasse

També es pot crear una variable de la superclasse i assignar-li un objecte de la subclasse.
De fet, és el més recomanable quan es volen crear conjunts amb diferents tipus d'objectes.

Animal sardina = new Peix("Sardina", 100);

L'avantatge de fer-ho així és que després es pot afegir qualsevol tipus d'animal a un array genèric:

Animal[] animals = new Animal[5];
Animal ovella = new Mamifer("Ovella");
animals[0] = ovella;
animals[1] = new Peix("Sardina", 100);

El cas més extrem seria crear un array de tipus Object per guardar qualsevol tipus d'objecte.
Però això no és recomanable (té més inconvenients que avantatges).

Si es necessita saber de quin tipus concret és un dels animals de la llista, es pot fer:

String classe = animals[1].getClass().getSimpleName();    // classe = "Peix"

O també comprovar si pertany a una classe concreta utilitzant l'operació instanceof:

if (animals[1] instanceof Peix)    // Comprovar si l'animal és de la classe Peix

Problemes al crear una subclasse utilitzant una variable d'una superclasse

Si una subclasse té un mètode que no està sobreescrit en la superclasse, el compilador indicarà que l'objecte no disposa d'aquest mètode.

System.out.println("Profunditat: " + animals[1].getProfunditat());   // ERROR

En canvi, si li diem al compilador que l'animal és de la classe Peix fent un cast, ja no hi haurà problema:

System.out.println("Profunditat: " + ((Peix)animals[1]).getProfunditat());   // OK

El problema pot venir durant l'execució si resulta que l'animal en realitat no és un Peix:

System.out.println("Profunditat: " + ((Peix)animals[0]).getProfunditat());   // ERROR

Abans de fer una conversió, cal assegurar-se que aquesta és correcta:

if (animals[0] instanceof Peix)    // Comprovar si l'animal és de la classe Peix
    System.out.println("Profunditat: " + ((Peix)animals[0]).getProfunditat());
else
    System.out.println("No es pot saber la profunditat perquè no és un peix!");
