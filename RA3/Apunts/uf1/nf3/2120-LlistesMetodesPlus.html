Mètodes de les llistes en JavaScript

Mètodes dels arrays

Alguns mètodes modifiquen la mateixa llista; altres no la modifiquen però retornen una llista nova; alguns modifiquen la llista i retornen una llista nova.

Convé evitar que un array contingui elements undefined o empty.

Mostrar tots els elements de l'array

Si és necessari, un array es converteix automàticament a un string separant els elements amb una coma:

document.write(["SMX", "DAW"]);    // Escriu 'SMX,DAW'

Si es vol un altre tipus de separador, es pot utilitzar la comanda join():

let cicles = ["SMX", "DAW"];
document.write(cicles.join(" - "));    // Escriu 'SMX - DAW'

Ordenar l'array

La comanda sort() ordena l'array alfabèticament de més petit a més gran.

La comanda reverse() inverteix la posició de tots els elements: si es vol ordenar un array inversament, primer s'utilitza la comanda sort() i després reverse().

Si l'array conté números, l'ordre pot ser incorrecte: el número 2 es posaria abans del 10.
En aquest cas (o si tenim objectes més complexos) es pot ordenar utilitzant una funció personalitzada que indiqui si un element és més gran, més petit o igual que un altre.
Aquesta funció ha de retornar:

  • Un número negatiu (< 0) si el primer element és menor que el segon.
  • Un número positiu (> 0) si el primer element és més gran que el segon.
  • 0 (zero) si els dos elements són iguals.

let edats = [35, 9, 18];

function ordreXY(x, y) {
  return x - y;
}

edats.sort(ordreXY);   // edats = [9, 18, 35];
edats.reverse();       // edats = [35, 18, 9];

Recórrer tots els elements d'un array

Es pot accedir a tots els elements utilitzant bucles (for, while...).

Si es fa així cal saber quants elements té l'array.
Aquest valor es troba a la propietat length:

let cicles = ["SMX", "ASX", "DAW"];

for (let i = 0; i < cicles.length; i++) {
  console.log("\n" + cicles[i]);
}

for ... of

També es pot utilitzar for ... of (no confondre amb for ... in).

En aquest cas cal utilitzar una variable (en aquest cas c) a la qual s'assigna un element diferent de la llista (en aquest cas cicles) en cada iteració del bucle:

let cicles = ["SMX", "ASX", "DAW"];

for (let c of cicles) {
  console.log("\n" + c);
}

Funció map()

Retorna una nova llista després de realitzar alguna operació determinada amb cada element.
L'acció que s'ha de realitzar ve determinada per una funció personalitzada:

let numeros = [1, 2, 3];

function doble(valor, index, array) {   // Funció personalitzada
  return 2 * valor;
}

let n2 = cicles.map(doble);   // n2 = [2, 4, 6]

Funció filter()

Retorna una nova llista amb els elements de la llista que compleixen una condició.
La funció personalitzada ha de retornar true si l'element que se li passa compleix la condició:

let edats = [10, 20, 30];

function major(valor, index, array) {   // Funció personalitzada
  return valor >= 18;
}

let m18 = edats.filter(major);   // m18 = [20, 30]

Funcions reduce() i reduceRight()

Retorna un valor (no necessàriament numèric) després de realitzar alguna operació determinada amb tots els elements.
L'acció que s'ha de realitzar ve determinada per una funció personalitzada que, a partir d'un valor inicial, realitza una operació amb un element i retorna el resultat d'aquesta operació. Aquest resultat serà el valor inicial per fer la operació amb el següent element:

let numeros = [1, 2, 3];

function suma(anterior, actual) {   // Funció personalitzada
  return anterior + actual;
}

let t = numeros.reduce(suma, 0);   // t = 6

La diferència entre reduce() i reduceRight() és que en el primer cas es comença pel primer element de la llista i en el segon cas es comença pel final.

Si no es posa el valor inicial, el valor anterior i l'actual seran el primer i el segon respectivament.

let t = numeros.reduce(suma);   // t = 6

Funcions every() i some()

Retornen true o false si tots o algun element de la llista compleixen una condició.
La funció personalitzada ha de retornar true o false si l'element que se li passa compleix o no la condició:

let numeros = [1, 2, 3];

function imparell(valor) {   // Funció personalitzada
  return valor % 2;
}

let i = numeros.every(imparell);   // i = false
i = numeros.some(imparell);        // i = true

Buscar elements dins d'un array

  • includes(v): retorna true si existeix el valor v dins de l'array.
  • indexOf(v): retorna l'index del primer element amb el valor v.
    Opcionalment es pot indicar a partir de quin índex s'ha de començar a buscar.
  • lastIndexOf(v): igual que l'anterior, però comença a buscar pel final.
  • find(func): retorna el primer element que fa que la funció func retorni true.
  • findIndex(func): retorna l'índex del primer element que fa que la funció func retorni true.

Altres funcions

  • slice(ini, fi): genera una nova llista amb els elements entre ini (inclòs) i fi (no inclòs).
    Tots dos paràmetres són opcionals i també poden tenir valors negatius.
  • splice(): permet afegir o eliminar elements a una llista.
