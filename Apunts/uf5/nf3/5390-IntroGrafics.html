Introducció als gràfics

Pots provar el codi complet dels exemples descomprimint l'arxiu Grafics.zip dins la carpeta src d'un projecte de IntelliJ.

Abans de treballar amb gràfics, convé conèixer les classes Image i ImageIcon, que s'utilitzaran sovint.

Image i ImageIcon

Image ref. (Java SE 17)

ImageIcon ref. (Java SE 17)

Per utilitzar una imatge guardada en un arxiu, primer cal carregar-la en un objecte d'un d'aquests tipus.
Els tipus d'imatges que es poden utilitzar són JPG, GIF, PNG, BMP i WBMP.

Image s'utilitza per posar la imatge en un component genèric (JPanel, Canvas...).
IconImage s'utilitza per afegir la imatge a un botó, menú o etiqueta (JButton, JMenuItem o JLabel).

Es poden utilitzar els següents mètodes per carregar una imatge.
És convenient posar-los en una llibreria per poder-los utilitzar fàcilment quan calgui.

/**
 * Carrega una icona i la redimensiona.
 * @param path Ruta on es troba la imatge
 * @return La icona creada o null si no l'ha trobada
 */

public static ImageIcon carregarIcona(String path, int width, int height) {
    Image imatge = carregarImatge(path);
    if (imatge == null) return null;

    imatge = imatge.getScaledInstance(width, height, java.awt.Image.SCALE_SMOOTH);
    return new ImageIcon(imatge);
}

/**
 * Carrega una imatge i la redimensiona.
 * @param path Ruta on es troba la imatge
 * @return La imatge creada o null si no l'ha trobada
 */
public static Image carregarImatge(String path, int width, int height) {
    Image imatge = carregarImatge(path);
    if (imatge == null) return null;

    imatge = imatge.getScaledInstance(width, height, Image.SCALE_SMOOTH);
    return imatge;
}

/**
 * Carrega una imatge.
 * @param path Ruta on es troba la imatge
 * @return La imatge creada o null si no l'ha trobada
 */
public static Image carregarImatge(String path) {
    java.net.URL imgURL = ClassLoader.getSystemResource(path);
    if (imgURL != null) {
        ImageIcon icona = new ImageIcon(imgURL);
        return icona.getImage();
    } else {
        System.err.println("No s'ha trobat l'arxiu: " + path);
        return null;
    }
}

Utilitzar MediaTracker per carregar imatges

El problema amb la càrrega d'imatges (mètode getImage() i alguns altres) és que Java ho fa de forma asíncrona: el programa no espera a que s'hagi carregat la imatge per continuar, sinò que segueix endavant i carrega la imatge quan el sistema està lliure.
Això pot provocar que, si es vol utilitzar la imatge immediatament, aquesta no estigui encara disponible.

Per fer que el programa esperi a tenir les imatges carregades es pot utilitzar un objecte MediaTracker.

// Directori per les imatges
String RES = "uf5/exemples/resources/";

MediaTracker tracker = new MediaTracker(new Container());

Image imatge = LlibreriaGrafica.carregarImatge(RES + "java.png", 48, 48);
if (imatge != null) tracker.addImage(imatge, 0);

try {
    tracker.waitForAll();
} catch (InterruptedException e) {
    System.err.println("No s'han pogut carregar les imatges");
}
