Funcions en Java

Paràmetres d'entrada i valor de retorn d'una funció

Les funcions més senzilles, com les vistes fins ara, tenen una utilitat força limitada.

Per augmentar la reusabilitat i llegibilitat del codi es poden afegir dues característiques importants:

  • A una funció se li poden passar diverses dades per generalitzar el seu funcionament.
    Aquestes dades poden ser primitives (enters, caràcters...), Strings, arrays o altres objectes.
  • Una funció pot retornar un valor que es podrà assignar a una variable o utilitzar-lo en una expressió.
    Aquest valor pot ser una dada primitiva (enter, caràcter...), un String, un array o un altre objecte.

Això també reduirà la utilització de variables globals que només s'utilitzen en un bloc de codi.

Si una funció es dissenya correctament, no caldrà que altres programadors sàpiguen com funciona internament: només hauran de saber quines dades se li han de passar per que faci la seva tasca.

Funcions que retornen un valor

Configurar el tipus de valor de retorn

Per fer que una funció retorni un valor, en la seva definició s'ha de canviar la paraula void pel tipus de dada que ha de retornar (int, float, char, boolean, String...).

També cal que, per sortir de la funció, s'utilitzi la paraula return i una dada del mateix tipus que el tipus de retorn que s'ha definit al principi.
La instrucció return es pot utilitzar en més d'un lloc dins de la funció.

static boolean verificarDades() {
    if (edat < 0) return false;
    else return true;
}

Si s'ha definit una funció per retornar un valor d'un tipus determinat, no pot retornar un valor d'un tipus diferent o no retornar cap valor:

static boolean verificarDades() {
    if (edat < 0) return false;    // OK
    else if (edat == 0) return;    // ERROR: ha de retornar true o false
    else return "Edat OK";         // ERROR: ha de retornar true o false
}

Utilitzar el valor de retorn

El valor de retorn de la funció anterior es podria utilitzar de la següent forma:

public static void main(final String[] args) {
    do {
        // Introduir dades
    } while (!verificarDades());
}

Com es veurà més endavant, el valor de retorn també es pot utilitzar en altres expressions més complexes per completar altres càlculs matemàtics, en expressions lògiques, per assignar un valor a una variable, etc.

Funcions amb paràmetres d'entrada

Reutilització del codi

Una funció pot realitzar sempre la mateixa tasca amb les mateixes dades i proporcionar sempre el mateix resultat, però serà molt més útil si pot adaptar el seu funcionament partint de dades diferents.

Si les funcions es programen pensant en un cas general en lloc del cas concret que es pretén resoldre, es pot estalviar molta feina aprofitant el codi en diverses parts del programa.

Encara que es pot aconseguir el mateix efecte utilitzant dades globals per adaptar el seu funcionament, el més recomanable és passar les dades necessàries directament a la funció.
Això es pot fer utilitzant paràmetres d'entrada:

// Mostrar les dades d'un array de números enters separats per comes
static void mostrarArrayEnters(int[] array) {
    int l = array.length - 1;

    for (int i = 0; i < l; ++i) {
        System.out.print(array[i] + ", ");
    }
    System.out.println(array[l]);
}

Es pot cridar aquesta funció des de la funció main per visualitzar les dades de diferents arrays:

public static void main(final String[] args) {
    int[] numerosParells = {0, 2, 4, 6, 8};
    int[] numerosPrimers = {2, 3, 5, 7, 11, 13, 17, 19};

    mostrarArrayEnters(numerosParells);
    mostrarArrayEnters(numerosPrimers);
}

Paràmetres i arguments

Els paràmetres d'entrada es poden considerar i utilitzar com si fossin variables locals.

Els paràmetres no tenen perquè tenir el mateix nom que els arguments que s'utilitzen al cridar la funció.

Els arguments que s'utilitzen al cridar la funció han de ser del mateix tipus que els paràmetres d'aquesta.

Si un paràmetre és una dada primitiva, encara que es modifiqui el seu valor dins de la funció, no farà que es modifiqui la variable passada com a argument al cridar a la funció:

public static void main(final String[] args) {
    int x = 5;
    doblarEnter(x);
    System.out.println(x);        // Mostrarà 5
}

static void doblarEnter(int x) {
    x *= 2;
    System.out.println(x);    // Mostrarà 10
}

Si un paràmetre és un objecte (per exemple, un array), sí que es modificarà l'objecte que s'ha utilitzat al cridar la funció:

public static void main(final String[] args) {
    int[] numeros = {1, 2, 3, 4, 5};
    doblarArray(numeros);
    mostrarArrayEnters(numeros);      // Mostrarà 2, 4, 6, 8, 10
}

static void doblarArray(int[] array) {
    for (int i = 0; i < array.length; ++i) {
        array[i] *= 2;
    }
    mostrarArrayEnters(array);    // Mostrarà 2, 4, 6, 8, 10
}

ATENCIÓ: els Strings són objectes immutables, per tant es comporten com si fossin dades primitives (encara que es modifiquin dins d'una funció, la variable externa no es modifica):

public static void main(final String[] args) {
    String text = "Text original";
    System.out.println(text);    // Escriu Text original
    modificarString(text);
    System.out.println(text);    // Escriu Text original (no s'ha modificat)
}

static void modificarString(String s) {
    s += " mes text afegit";
    System.out.println(s);        // Escriu Text original mes text afegit
}

Si es vol modificar la variable externa text, cal que la funció retorni l'string modificat:

public static void main(final String[] args) {
    String text = "Text original";
    System.out.println(text);        // Escriu Text original
    text = modificarString(text);
    System.out.println(text);        // Escriu Text original mes text afegit
}

static String modificarString(String s) {
    s += " mes text afegit";
    System.out.println(s);
    return s;
}

Funcions amb el mateix nom però diferents paràmetres

Aquesta característica s'anomena sobrecàrrega de funcions o funcions sobrecarregades.

Dos funcions (o més) poden tenir el mateix nom sempre que el nombre de paràmetres o els tipus dels paràmetres siguin diferents:

void f1(char c) {
}

void f1(int n) {           // OK: mateix nom però diferent tipus de paràmetre
}

void f1(char c, int n) {   // OK: mateix nom però diferent nombre de paràmetres
}

void f1(int n, char c) {   // OK: mateix nom però diferent tipus de paràmetres
}

El tipus de retorn no es té en compte: no s'accepten funcions que tinguin el mateix nom i el mateix tipus i nombre de paràmetres encara que tinguin diferent tipus de retorn:

void f1(int a) {
}

int f1(int b) {    // ERROR: mateix nom i tipus de paràmetres
}

Funcions amb paràmetres d'entrada i valor de retorn

El cas més genèric són les funcions que retornen un valor a partir d'uns paràmetres d'entrada.

S'acostumen a utilitzar per realitzar càlculs o processar dades i retornar el valor o les dades obtingudes.

Generar caràcter aleatori

public static void main(final String[] args) {
    char c = caracterAleatori('A', 'Z');
}

static char caracterAleatori(char caracterIni, char caracterFi) {
    return (char)(Math.random() * (caracterFi - caracterIni + 1) + caracterIni);
}

Calcular l'àrea del cercle i el perímetre d'un triangle rctangle

public static void main(final String[] args) {
    double area = areaCercle(10);

    double base = 3, altura = 4;
    double perimetre = base + altura + hipotenusa(base, altura);
}

static double areaCercle(double radi) {
    return Math.PI * radi * radi;
}

static double hipotenusa(double b, double a) {
    return Math.sqrt(b * b + a * a);
}

Què es pot conduir a certa edat?

public static void main(final String[] args) {
    int edat = scan.nextInt();
    System.out.println(conduir(edat));
}

static String conduir(int edat) {
    if (edat < 12) return "Pots conduir un patinet";
    if (edat < 18) return "Pots conduir una moto";
    if (edat > 75) return "Més val que no condueixis";
    return "Pots conduir cotxe i moto";
}

Crear i inicialitzar un array d'enters amb un valor determinat

public static void main(final String[] args) {
    int[] a = omplirArrayEnters(10, 5);  // Crea un array de 10 elements inicialitzats a 5
    mostrarArrayEnters(a);
}

static int[] omplirArrayEnters(int elements, int valor) {
    int[] array = new int[elements];
    for (int i = 0; i < elements; ++i) {
        array[i] = valor;
    }
    return array;
}

Funcions amb un nombre indeterminat de paràmetres

De vegades pot ser útil tenir una funció a la que se li puguin passar N arguments sense saber prèviament quants seran.

Aquesta característica s'anomena varargs (nombre d'arguments variables).

Una funció d'aquest tipus que ja s'ha utilitzat és la funció printf().
La seva definició és printf(String format, Object... arguments).
El primer argument que se li passa ha de ser un String per indicar el format.
Després se li pot passar qualsevol nombre d'arguments.

Per accedir a cada argument, es fa igual que si el paràmetre arguments fos un array: arguments.length és la quantitat d'arguments, arguments[0] és el primer argument, etc...

Condicions d'ús dels varargs:

  • Aquest paràmetre sempre ha d'anar al final de la declaració de la funció.
  • Només pot haver-hi un paràmetre d'aquest tipus.
  • Tots els arguments han de ser del mateix tipus (o que es puguin transformar a aquest tipus), però si es posa el tipus Object, poden ser de qualsevol tipus, perquè qualsevol valor es pot convertir a Object.
Exemple

mostrarValors(1, 2, 3);
mostrarValors(2, 4, 6, 8, 10, 12);

static void mostrarValors(int... numeros) {
    for (int i = 0; i < numeros.length; i++)
        System.out.println(numeros[i]);
}
