Separar paraules i escriure-les al revés

Fes un programa que demani una frase, la converteixi en un array de paraules separant-les a partir dels espais i mostri cada paraula en una línia.

Modifica el programa de forma que separi els trossos quan trobi una coma i un espai.

Modifica el programa perquè mostri les paraules en una línia però en ordre invers.

Exemple de sortida per consola

Escriu una frase: Desenvolupament, Aplicacions, Web
Web Aplicacions Desenvolupament

El xifrat del Cèsar

Fes un programa que demani una frase i l’encripti utilitzant el xifrat del Cèsar.

Fes-ho convertint primer l’string en un array de caràcters, fent la conversió de cada caràcter en el mateix array, convertint l’array a string i mostrant-lo.

Opcionalment, fes que el programa demani el desplaçament.

Busca a Internet alguna forma de convertir l’array a string directament (sense utilitzar un bucle).

Exemple de sortida per consola

Escriu una frase: ABCDE ... VWXYZ
Quin desplaçament vols? 3
Frase encriptada: DEFGH ... YZABC

Escriu una frase: Nota de M6: 7 (Notable)
Quin desplaçament vols? 1
Frase encriptada: OPUB EF N6: 7 (OPUBCMF)

Ordenar i cercar paraules

Fes un programa que demani 10 paraules i les vagi guardant en un array.

Després les ha d’ordenar en ordre ascendent en el mateix array i mostrar-les.

Finalment, el programa ha de demanar paraules de forma continuada, ha de buscar la paraula en l’array utilitzant la cerca binària i ha d’indicar en quina posició l'ha trobat o si no l’ha trobat i quantes comparacions ha hagut de fer.

El programa acabarà quan l’usuari introdueixi la paraula FI.
