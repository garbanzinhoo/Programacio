Components

Tipus de components: guia visual

Un component és qualsevol element individual de la interfície gràfica: text (etiquetes), botons, llistes...

Tots aquests elements hereten de la classe JComponent o d'altres subclasses seves (AbstractButton, JTextComponent...), per tant, també poden utilitzar els mètodes de les classes "pare" per modificar la seva mida i els seu aspecte:

  • setBackgroud(Color)
  • setBorder(Border)
  • setSize(int width, int height)
  • setSize(Dimension)
  • setPreferredSize(Dimension)
  • setMinimumSize(Dimension)
  • setMaximumSize(Dimension)
  • ... i molts altres!

AVANÇAT: els components tenen un parell de funcions que ens permeten guardar valors i recuperar-los.

El mètode putClientProperty(Object key, Object value) serveix per guardar un valor.
El mètode getClientProperty(Object key) serveix per recuperar-lo.

key sol ser un String que indica el nom de l'atribut.
El valor es guarda com a Object, per tant, al recuperar-lo, caldrà transformar-lo fent un cast.

JLabel etiquetaF2C5 = new JLabel("2,5");
etiquetaF2C5.putClientProperty("fila", 2);
etiquetaF2C5.putClientProperty("columna", 5);
...
int fila = (int)getClientProperty("fila");
int columna = (int)getClientProperty("columna");

Els components més utilitzats són els que es detallen a continuació.

JLabel

JLabel ref. (Java SE 17)

Tutorial JLabel

Una etiqueta pot contenir una imatge (normalment petita) i/o un text (normalment curt).

Una etiqueta no pot rebre el focus i, per tant, no pot respondre a accions amb el teclat, però sí amb el ratolí.

Per defecte, el contingut es mostra centrat en l'etiqueta, però es pot configurar l'alineació vertical i horitzontal.
Si hi ha imatge i text, també es pot configurar la posició relativa i la separació del text respecte de la imatge.

Constructors bàsics:

  • JLabel()
  • JLabel(String)
  • JLabel(Icon)

Mètodes bàsics:

  • disable()
  • enable()
  • setText(String)
  • setIcon(Icon)
  • setDisabledIcon(Icon): icona quan l'etiqueta es mostra deshabilitada.
  • setHorizontalAlignement(int)
  • setVerticalAlignement(int)
  • setHorizontalTextPosition(int)
  • setVerticalTextPosition(int)
  • setIconTextGap(int)
  • setFont(Font)
  • setForegroundColor(Color)

Tutorial JButton, JCheckBox i JRadioButton

Un botó pot contenir una imatge (normalment petita) i/o un text (normalment curt).

A diferència de les etiquetes, pot rebre el focus i respondre a accions amb el teclat i amb el ratolí.

Per defecte, el contingut es mostra centrat en el botó, però es pot configurar l'alineació vertical i horitzontal.
Si hi ha imatge i text, també es pot configurar la posició relativa i la separació del text respecte de la imatge.

Els components relacionats amb menús (JMenuItem, JMenu, JCheckBoxMenuItem i JRadioButtomMenuItem) també hereten de AbstractButton, per això tenen un funcionament i uns mètodes similars als de qualsevol botó.

Constructors bàsics:

  • JButton()
  • JButton(String)
  • JButton(Icon)
  • JButton(String, Icon)

Mètodes bàsics (la majoria els hereta de AbstractButton i són els mateixos que els de JLabel)

  • isDefaultButton(): botó per defecte de l'aplicació (s'activarà al prémer la tecla Intro).
    Es pot indicar quin és el botó per defecte amb el mètode setDefaultbutton() d'un JRootPane.

JCheckBox i JRadioButtom

Tots dos hereten de JToogleButton.

Aquest tipus de botons tenen dos estats: premut i deixat anar.
En el constructor es pot poser un paràmetre per indicar si el botó estarà premut o no quan es creï.

Per consultar o canviar l'estat es poden utilitzar els mètodes:

  • isSelected()
  • setSelected(boolean)

En el cas dels botons de ràdio, per fer que només un estigui premut, cal afegir els botons a un objecte de la classe ButtonGroup.

Tutorial components de text

Tots tres hereten de JTextComponent.

Serveixen tant per mostrar text com per què l'usuari l'editi.

  • JTextField: text en una línia
  • JTextArea: text en una o més línies
  • JTextPane: igual que JTextArea però permet text amb format (negreta, cursiva...) i imatges

JTextArea i JTextPane no inclouen scrollers, per això s'han de posar dins d'un JScrollPane si es preveu que puguin contenir un text que no hi càpiga.

Constructors bàsics:

  • Constructor buit, amb el text i/o amb nombre de columnes (caràcters per línia).
  • En el cas de JTextArea i JTextPane, també pot incloure el nombre de files.

Mètodes bàsics:

  • setText(String)
  • getText()
  • setEditable(boolean)
  • selectAll()
  • setFont(Font)
  • setLineWrap(boolean): només per JTextArea i JTextPane.
  • setWrapStyleWord(boolean): només per JTextArea i JTextPane.

JFormatedTextField i JPasswordField són subclasses de JTextField que permeten, respectivament, donar un format específic al contingut (per exemple, dates) o evitar que es mostri el text que l'usuari escriu.
