Classe Character

Aquesta classe conté mètodes útils per treballar amb caràcters.
Alguns dels més utilitzats són els següents:

  • Character.isDigit(char ch): retorna true si el caràcter és un dígit ('0' a '9').
  • Character.isLetter(char ch): retorna true si el caràcter és una lletra ('a' a 'z' o 'A' a 'Z').
  • Character.isUpperCase(char ch): retorna true si el caràcter és una lletra majúscula.
  • Character.isLowerCase(char ch): retorna true si el caràcter és una lletra minúscula.
  • Character.toUpperCase(char ch): retorna el caràcter convertit a majúscula.
  • Character.toLowerCase(char ch): retorna el caràcter convertit a minúscula.

El cas de les cadenes de caràcters (String) és diferent.
De moment, el més important és que l'operador + serveix per concatenar.
També permet concatenar una cadena de caràcters amb qualsevol altre tipus de dada (el compilador s'encarrega de fer la conversió a cadena de caràcters quan sigui necessari).

String s1 = "Hello";
String s2 = "world!";
String s3 = s1 + " " + s2;
System.out.println(s3);    // Mostrarà Hello world! per pantalla
float preu = 125.4;
System.out.println("El preu és " + preu + " €");    // Mostrarà El preu és 125.4 €

Compte al barrejar text i números!

System.out.println("Preu: " + 5 + 3 + " €");    // Mostrarà Preu: 53 €
System.out.println("Preu: " + (5 + 3) + " €");   // Mostrarà Preu: 8 €

Obtenir el valor numèric d'un dígit

Com s'ha vist anteriorment, els dígits (caràcters de '0' a '9') tenen un codi ASCII que no es correspon amb el seu valor numèric ('0' = 48, '1' = 49...).

Una forma d'obtenir el seu valor numèric és restar 48 (o restar el caràcter '0'):

char digit = '5';         // digit és equivalent a 53 (codi ASCII)
int valor = digit - 48;   // valor conté el valor 5
int valor = digit - '0';  // valor conté el valor 5

Però la classe Character té un mètode per fer-ho:

char digit = '5';                        // digit és equivalent a 53 (codi ASCII)
int valor = Character.digit(digit, 10);  // valor conté el valor 5

Convertir els valors 0 a 9 en dígits (caràcters)

Una forma seria sumar 48 (o sumar el caràcter '0') al valor i convertir a char:

int valor = 5;
char digit = (char)(valor + 48);    // digit conté '5'
char digit = (char)(valor + '0');   // digit conté '5'

Però la classe Character té un mètode per fer-ho:

int valor = 5;
char digit = Character.forDigit(valor, 10);    // digit conté '5'
