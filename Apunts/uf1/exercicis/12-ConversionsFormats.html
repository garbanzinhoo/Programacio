Caràcters i codis

Segueix pas a pas el següent codi i pensa quin valor tindran les diferents variables.
Executa'l pas a pas i comprova si el què havies calculat és correcte.

char lletra = '0';
char lletra2 = 0;
boolean sonIguals = lletra == lletra2;
lletra = 'A';
lletra2 = 65;
sonIguals = lletra == lletra2;
++lletra;
lletra = '0' + '1';

Tipus de caràcter

Fes un programa que, donada una variable de tipus char, mostri amb un valor booleà (true o false) depenent de si pertany o no a cada un dels següents conjunts: lletra, dígit, majúscula i minúscula.

Per exemple, si la variable conté el caràcter 'c', ha d'escriure:

És lletra? true
És dígit? false
És majúscula? false
És minúscula? true

Deduir el format

Pensa com es mostraran els següents números.
Després comprova-ho executant el codi:

System.out.printf("|%20d|\n", 53);
System.out.printf("|%-20d|\n", 53);
System.out.printf("|%020d|\n", 53);
System.out.printf("%,d\n", 10000000);
System.out.printf("%.2f\n", 12.9f);
System.out.printf("%,.2f\n", 54999.99789f);
