Repàs Strings

Fes els següents exercicis utilitzant el mínim possible de bucles i aprofitant les funcions de la classe String.

Hora correcta

Fes un programa que comprovi si l'hora que hi ha en un string té el format correcte: HH:MM:SS

Opcionalment, els minuts hores i segons poden tenir un dígit o dos: 5:24:3

Opcionalment, poden faltar els segons: 20:5

Comprova també si les hores minuts i segons són correctes (positius entre 0 i 23 o entre 0 i 59).
Mostra la hora amb dos dígits per cada valor i separats per :.
Exemple de sortida per consola

5:24:3 --> 05:24:03

Data correcta

Fes un programa que comprovi si la data que hi ha en un string té el format correcte: DD/MM/AA

Opcionalment, el dia i el mes poden tenir només un o dos dígits, i l'any pot tenir 2 o 4: 5/10/2022

Comprova també si el dia i el mes són correctes (positius entre 1 i 31 o entre 1 i 12).
Comprova si el dia és correcte en funció del mes (i també en funció de l'any, si és any de traspàs).
Mostra la data completa: dos dígits pel dia i més, i quatre per l'any, separats per /.
Si l'any té només dos dígits, suma-li 2000.
Exemple de sortida per consola

5/10/20 --> 05/10/2020

Matrícula correcta

Fes un programa que comprovi si la matrícula d'un cotxe que hi ha en un string té el format correcte: XXXX-AAA (X = dígits, A = lletres).

NIF correcte

Fes un programa que comprovi si el NIF d'una persona té el format correcte: NNNNNNNNA (N = dígits, A = lletra).

Opcionalment, comprova que la lletra es correspon amb els dígits.
