Classes en Java

Classes amb funcions estàtiques

El següent pas per tractar amb programes grans és agafar funcions que tenen alguna cosa en comú i traslladar-les dins d'una nova classe.

Per exemple, es poden agrupar els mètodes que serveixen per introduir dades o els que serveixen per tractar arrays d'enters o d'strings.

Pensant en el següent pas (crear llibreries de classes), es poden crear classes amb funcions genèriques i classes amb funcions pròpies del programa.

Les noves classes es poden afegir en el mateix arxiu de la classe principal, però és més recomanable posar cada classe en un arxiu separat.
De moment, els arxius de les noves classes es crearan en la mateixa carpeta que la classe principal.

Recordeu que l'arxiu ha de tenir el mateix nom que la classe!

Definició de les noves classes

L'estructura serà la mateixa que s'ha utilitzat fins ara:

public class NomClasse {
    // Dades globals de la classe (si cal)
    // Mètodes de la classe (estàtics)
    public static void f1() {
        // Codi de la funció f1
    }
}

L'única diferència és que les noves classes no tindran la funció main().

De moment, els mètodes seran estàtics, com els què s'han utilitzat fins ara, però també han de ser públics, per poder accedir des d'altres classes.

Utilització de les funcions d'una classe des d'altres classes

Quan es crida un mètode estàtic des d'una classes diferent, caldrà afegir al davant del nom de la funció el nom de la classe que conté la funció i un punt:

public class Main {
    public static void main(final String[] args) {
        NomClasse.f1();
    }
}

Canviar el nom d'una classe

La majoria d'IDEs tenen alguna opció que serveix per fer canvis que afecten a diverses parts d'un projecte, per exemple, canviar el nom d'una variable, d'una funció o d'una classe.

Aquesta opció s'anomena refactoritzar.

En el cas d'IntelliJ, es pot fer seleccionant el nom de la variable, funció o classe, i amb la combinació de tecles Shift + F6 o amb l'opció Refactor → Rename del menú contextual.
Després només cal escriure el nou nom i prémer la tecla Intro.

Per exemple, si es vol canviar el nom de la classe principal Main, al seguir aquests passos es pot comprovar que també canvia el nom de l'arxiu.
