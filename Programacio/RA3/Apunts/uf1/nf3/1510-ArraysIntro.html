Arrays: introducció

Utilitat dels arrays

Referència arrays

Si es vol utilitzar un conjunt de dades relativament gran per processar-les després de diferents formes, no és útil tenir-les guardades en variables independents, especialment si no es coneix el nombre de dades.

Per exemple, si tenim les notes de 30 alumnes, no és pràctic utilitzar les variables n1, n2, n3, ... , n30.

Per això s'han inventat els arrays.

Aquest tipus d'objectes permeten emmagatzemar un conjunt de dades utilitzant una única variable.

En java, tots els elements d'un array han de ser del mateix tipus.

Definir i inicialitzar arrays

Per definir una variable de tipus array cal indicar el tipus de dades que contindrà (int, String...), afegir claudàtors ([]) i el nom de la variable.
També es poden posar els claudàtors després del nom de la variable.

Els array tenen una mida fixa (nombre d'elements que pot contenir) i s'ha d'indicar en el moment de definir-los. Després ja no es podrà modificar aquesta mida.

Inicialitzar amb valors literals

Els valors, siguin números, caràcters, Strings..., s'han de posar entre claus i separats per comes:

int[] notes = {5, 8, 7};
String colors[] = {"Vermell", "Verd", "Blau"};

Inicialitzar amb mida i valor per defecte

S'ha d'utilitzar la paraula new, afegir el tipus i, entre claudàtors, la mida de l'array.
La mida de l'array es posar amb un literal (un número) o amb una variable o constant.

En el cas de dades primitives (números, caràcters i booleans), cada element s'inicialitza a 0 o false.
En el cas dels strings o altres objectes, s'inicialitza amb el valor null.

final int mida = 3;
char[] lletres = new char[mida];
int[] notes = new int[3];
String colors[] = new String[3];

Per saber la mida d'un array es pot consultar l'atribut length:

int mida = notes.length;

Guardar i recuperar el valor d'una posició de l'array

Per accedir a cada element de l'array s'ha de posar el nom de l'array i, entre claudàtors, la posició de l'element:

int nota = notes[2];   // Afaga la nota que hi ha en la posició 2 i la guarda en 'nota'
notes[1] = nota;       // Guarda la 'nota' en la posició 1 de l'array

La primera posició d'un array és la posició 0 i l'última és mida - 1.
Si s'intenta accedir a una posició fora d'aquests límits, es produirà l'excepció Index out of bounds.
