Operadors lògics

Pensa quin resultat (true o false) donen les següents operacions lògiques.
Comprova després el resultat printant aquestes expressions.

false && true
true && true
false || false
false || true
!true
!(true || false)
!true && !false
!(true && false)
!true || !false
!((true && true) || (false && false))

Combinar operadors lògics

Fes un programa que mostri el resultat de totes les combinacions possibles amb els operadors lògics.
El resultat ha de tenir un format semblant a aquest:

Operador AND (&&)
false && false --> false
false && true --> ...
...

Operador OR (||)
false || false --> ...

Comparacions

Escriu amb operadors de comparació les següents expressions (x i y són variables):

  • x és igual a 0
  • x no és igual a 10
  • x és positiu
  • x és positiu o negatiu
  • x és més gran o igual que 10
  • x és més petit que y
  • x és més gran que el doble de y
  • x està entre -5 i +5 (tots dos inclosos)
  • x no està entre -5 i +5 (tots dos inclosos)
  • x és més gran que 4 i y és més gran que 5
  • x és més gran que 4 però y no és més gran que 5
  • ni x ni y són iguals a 10
