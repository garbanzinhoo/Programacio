Plantilla per introduir dades, processar i mostrar resultats

Un programa d'ordinador agafa unes dades, les processa i genera un resultat.
Les dades poden ser números, text, accions amb el ratolí... i el resultat pot ser un valor numèric, un altre text, una línia...

Per començar a practicar amb dades bàsiques i operacions senzilles, es pot utilitzar una plantilla que ens permetrà:

  • Introduir les dades que es volen processar
  • Executar l'aplicació
  • Mostrar el resultat

Igual que en l'exemple Hello World, cal crear una carpeta (PLANTILLA) i tres arxius.

A part d'això, també és convenient que crear o buscar un logo, preferiblement en format ICO i amb el nom favicon.ico. Aquest arxiu s'ha de guardar dins de la carpeta PLANTILLA.
Si es vol utilitzar altres formats o noms, s'ha de canviar el nom de l'arxiu dins de plantilla.html.

Document HTML (plantilla.html):

<!doctype html>
<html lang="ca">
    <head>
        <title>Plantilla</title>
        <meta charset="UTF-8" />
        <link rel="icon" type="image/x-icon" href="favicon.ico">
        <link rel="stylesheet" href="plantilla.css" type="text/css">
        <script defer src="plantilla.js"></script>
    </head>

    <body>
        <h1>Plantilla</h1>
        <label for="d1">Dada 1</label>
        <input id="d1">
        <label for="d2">Dada 2</label>
        <input id="d2">
        <button id="executar">Executar</button>
    </body>
</html>

Document JavaScript (plantilla.js):

"use strict";

function executar() {
    // Obtenir els 'inputs' del document i guardar-los en variables
    const d1 = document.getElementById("d1");
    const d2 = document.getElementById("d2");

    // Agafar el contingut dels 'inputs' i guardar-los en variables
    let v1 = d1.value;
    let v2 = d2.value;

    // Processar les dades i guardar el resultat en la variable 'r'
    let r = v1 + v2;

    // Mostrar el resultat
    alert(r);
}

// Quan es faci clic en l'element 'exec', cridar el mètode 'executar'
const exec = document.getElementById("executar");
exec.addEventListener("click", executar);
