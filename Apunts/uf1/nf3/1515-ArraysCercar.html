Arrays: cercar

Cercar elements dins d'un array

Buscar tots els elements amb un valor determinat

Es pot utilitzar per comptar els elements que tenen un valor determinat.

En aquest cas, s'ha de recórrer tota la llista (fer un recorregut) i utilitzar un comptador.

int suspesos = 0;
int[] notes = {5, 3, 8, 4, 7};

for (int i = 0; i < notes.length; ++i) {
  if (notes[i] < 5) ++suspesos;
}
System.out.println("Suspesos: " + suspesos);

Buscar el primer element (o l'últim) que conté un valor determinat

Si els elements d'una llista no estan ordenats, l'única forma de trobar un element concret serà recórrer tota la llista però sortint del bucle quan es trobi l'element.

Es pot utiiltzar un semàfor per detectar si s'ha sortit del bucle perquè s'ha trobat l'element o perquè s'ha arribat al final sense trobar l'element.

String[] frase = {"M'encanta", "programar", "en", "Java"};

boolean trobada = false;
int i = 0;

while (i < frase.length && !trobada) {
  if (frase[i].equals("programar")) trobada = true;
  ++i;
}
if (trobada) System.out.println("Paraula trobada en la posició " + (i - 1));
else System.out.println("No s'ha trobat la paraula");

També es pot fer utilitzant un bucle for amb un break.

String[] frase = {"M'encanta", "programar", "en", "Java"};

boolean trobada = false;
int i;

for (i = 0; i < frase.length; ++i) {
  if (frase[i].equals("programar")) {
    trobada = true;
    break;
  }
}
if (trobada) System.out.println("Paraula trobada en la posició " + i);
else System.out.println("No s'ha trobat la paraula");

Per trobar l'últim element amb un valor determinat, només s''ha de començar a llegir la llista pel final:

String[] frase = {"No", "m'agrada", "programar", "en", "Java",
                  "però", "no", "sé", "programar", "en", "Python"};

boolean trobada = false;
int i;

for (i = frase.length - 1; i >= 0 ; i--) {
  if (frase[i].equals("programar")) {
    trobada = true;
    break;
  }
}
if (trobada) System.out.println("Paraula trobada en la posició " + i);
else System.out.println("No s'ha trobat la paraula");
