Documents JSON

Els documents JSON estan formats per diferents tipus d'elements.

Elements simples
  • Strings: "X", "Peter", "Frase amb unes quantes paraules"
  • Números: 5, 12.3, 0.97562965587
  • Booleans: true o false
  • Valor null: null
Elements compostos
  • Arrays: ["Peter", 35, true]
  • Objectes: {"nom":"Peter", "edat":35, "profe":true}

Els element que formen un array o els valors dels atributs d'un objecte poden ser de qualsevol tipus vàlid en JSON, inclós altres arrays o altres objectes.
Per millorar la llegibilitat, s'acostuma a escriure de forma tabulada:

[
    [
        "Peter",
        35,
        true
    ],
    {
        "nom": "Peter",
        "edat": 35,
        "profe": true
    }
]

{
    "dades": {
        "nom": "Peter",
        "edat": 35,
        "profe": true
    },
    "notes": [
        5,
        8,
        3.5
    ]
}

Crear un objecte JSON a partir d'un text JSON

json-simple.jar és una llibreria que permet transformar un text que conté dades en format JSON en un objecte JSON.

Un cop afegida la llibreria al projecte, cal importar algunes classes:

import org.json.simple.JSONObject;         // Per crear objectes JSON
import org.json.simple.JSONArray;          // Per crear arrays JSON
import org.json.simple.parser.JSONParser;  // Per transformar un text en un element JSON
import org.json.simple.parser.ParseException;
import java.io.FileReader;
import java.io.IOException;

Llegir un arxiu de text amb dades JSON i transformar-lo a un objecte JSON

JSONParser parser = new JSONParser();

try {
    // Llegir arxiu JSON i transformar en objecte
    Object obj = parser.parse(new FileReader("./json/dades.json"));
    // TODO: codi per tractar les dades de l'objecte JSON
} catch (IOException | ParseException e) {
    e.printStackTrace();
}
