Més càlculs

Calcula quin valor tindran les variables a, b i c quan es mostrin per pantalla.
Comprova-ho executant el programa.
Si el resultat no és el mateix, executa el programa pas a pas (mode depuració) i comprova si el valor que pren cada variable en cada pas és el què tu havies calculat.

int a = 5;
int b = 7;
int c;

++b;
b = (b * 3) / 8;
a += 3;
a = a + 4 / 2;
c = a / 5 + b;

System.out.println("a = " + a + "\nb = "+ b + "\nc = "+ c);

a = 5;
b = 8;

++a;
a += 4;
b -= a / 2;
c = ++a + b;
c += a - b++;

System.out.println("a = " + a + "\nb = "+ b + "\nc = "+ c);

Comparacions

Escriu amb operadors de comparació les següents expressions (x i y són variables):

  • x és igual a 0
  • x no és igual a 10
  • x és positiu
  • x és positiu o negatiu
  • x és més gran o igual que 10
  • x és més petit que y
  • x és més gran que el doble de y
  • x està entre -5 i +5 (tots dos inclosos)
  • x no està entre -5 i +5 (tots dos inclosos)
  • x és més gran que 4 i y és més gran que 5
  • x és més gran que 4 però y no és més gran que 5
  • ni x ni y són iguals a 10

Calcular el preu final (PVP)

Fes un programa que, a partir del preu d'un article, calculi el preu final aplicant un descompte d'un 15% i un IVA del 21%.

Posa el preu inicial de l'article en una variable.
Pel valor del descompte, utilitza un literal.
Pel valor de l'IVA utilitza una constant entera.

ATENCIÓ: el preu amb IVA es calcula a partir del preu amb el descompte ja fet.
Si el preu inicial és 1000, el resultat hauria de ser 1028.5
