Arrays bidimensionals

Podem imaginar una array bidimensional com una taula de F x C caselles (files x columnes).

Definir i inicialitzar arrays bidimensionals

// Inicialitzar amb valors coneguts
let a = [
  [00, 01, 02, 03],
  [10, 11, 12, 13],
  [20, 21, 22, 23]
];

El nombre de files es pot obtenir amb la sentència let files = a.length;
Suposant que totes les files tenen el mateix nombre de caselles, el nombre de columnes es pot obtenir amb la sentència let columnes = a[0].length; (nombre de caselles de la primera fila).

Modificar o obtenir valors individuals

// Modificar la casella de la fila 1, columna 2
a[1][2] = 333;

// Obtenir el valor de la casella de la fila 1, columna 2
int v = a[1][2];

Modificar o obtenir tots els valors de l'array

Per inicialitzar proceduralment un array bidimensional o per recórrer tots els seus elements s'han d'utilitzar bucles niuats:

const F = 3;    // Nombre de files
const C = 4;    // Nombre de columnes
let a = [];

// Inicialitzar totes les cel·les
for (let i = 0; i < F; ++i) {
    a[i] = [];
    for (let j = 0; j < C; ++j) {
        a[i][j] = i * j;
    }
}

// Mostrar el valor de totes les cel·les
let resultat = "";
for (let i = 0; i < F; ++i) {
    for (let j = 0; j < C; ++j) {
        resultat += a[i][j] + " ";
    }
    resultat += "\n";
}
console.log(resultat);

Els algorismes anteriors recorren la taula igual que llegim un text: d'esquerra a dreta i de dalt a baix.
Si es vol llegir de dalt a baix i d'esquerra a dreta només cal canviar l'ordre dels bucles:

let resultat = "";
for (let j = 0; j < C; ++j) {
    for (let i = 0; i < F; ++i) {
        resultat += a[i][j] + " ";
    }
    resultat += "\n";
}
console.log(resultat);
