Operacions amb caràcters

Els caràcters són similars als enters curts (short) perquè també ocupen 2 bytes a la memòria i es poden realitzar les mateixes operacions que amb aquest tipus de números.

Però cal tenir en compte algunes característiques importants:

  • Els primers 256 caràcters i els seus valors equivalents es poden trobar en la taula de caràcters UTF-8.
  • Cada caràcter equival a un número entre 0 i 65535 (els short van de -32768 i 32767).
  • Les operacions matemàtiques poden donar resultats "inesperats" si no s'entén el funcionament.

Tenint en compte que els caràcters 'A', 'a' i '0' (dígit zero) tenen els valors 65, 97 i 48:

char lletra = '0';
char lletra2 = 0;     // lletra i lletra2 NO contenen el mateix caràcter
lletra = 'A';
lletra2 = 65;         // lletra i lletra2 contenen el mateix caràcter
++lletra;             // Ara lletra conté el caràcter 'B'
lletra = '0' + '1';   // Ara lletra conté el caràcter 'a'

Per fer comparacions entre caràcters s'agafa el valor Unicode de cada caràcter.

System.out.println('0' < 'a');    // mostrarà true: '0' (48) és més petit que 'a' (97)
System.out.println('a' < 'A');    // mostrarà false: 'a' (97) és més gran que 'A' (65)

Hi ha uns caràcters especials que representen accions en lloc de símbols.
Aquests caràcters s'anomenen codis d'escapament (escape codes).
S'entendrà millor la seva utilitat quan es vegin les cadenes de text.

  • '\n': salt de línia.
  • '\t': tabulador.
  • '\r': principi de línia.
  • '\\': barra invertida.
  • '\'': cometa simple.
  • '\"': cometa doble.
