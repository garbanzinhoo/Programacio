Instal·lació de l'IDE i extensions (plugins)

Instal·lació de Visual Studio Code (VSCode)

  1. Entrar a la web de descàrregues de Visual Studio Code i descarregar la versió corresponent al vostre sistema operatiu.
  2. Executar l'instal·lador i acceptar els termes de la llicència.
  3. Prémer el botó Siguiente (normalment no cal modificar les opcions) fins a finalitzar l'instal·lació.

Instal·lació de l'extensió (plugin) Live Server

Quan s'obri VSCode, l'última icona de la columna esquerra permet instal·lar extensions.

Cal buscar i instal·lar Live Server.

Primera aplicació web

El primer programa que es recomana fer quan es comença a aprendre un llenguatge és Hola Món (o Hello World).
Aquest programa es limita a escriure en pantalla el missatge Hello World.

No importa que encara no es conegui res del llenguatge, només cal copiar el codi i seguir unes poques instruccions per comprovar que l'entorn que s'ha instal·lat funciona correctament.
També pot servir com a plantilla per fer els primers programes.

En el cas de les aplicacions web, encara que tot el codi es pugui posar en un únic arxiu, és recomanable separar-ho per facilitar el mateniment quan l'aplicació vagi creixent.
De moment, la separació més simple és:

  • Un arxiu HTML on anirà el contingut del document (text, imatges, enllaços...).
  • Un arxiu CSS on posar els estils dels diferents tipus d'lements (tipus i mida de lletra general, dels títols...).
  • Un arxiu JS on escriurem el codi JavaScript per executar l'aplicació.

Codi HTML, CSS i JavaScript

Primer de tot cal crear una carpeta pel projecte.
Es recomana crear l'estructura PROG → INTRODUCCIÓ → HELLO dins de la carpeta de l'usuari.

Després, obrir VSCode i, en el menú principal, seleccionar File → Open Folder per obrir la carpeta HELLO que s'ha creat anteriorment.
Al obrir una carpeta per primer cop, demanarà si es confia en els autors de la carpeta i els arxius que conté: cal marcar la casella i clicar el botó Yes, I trust the authors.

Dins de la columna EXPLORER apareixerà la carpeta HELLO.
Fent clic amb el botó secundari a dins i triant l'opció New File... es crearà un nou arxiu i s'ha de posar un nom.

Cal crear els arxius: hello.html i hello.js (de moment no cal crear l'arxiu pels estils).
Al seleccionar un arxiu, s'obrirà en la finestra principal i s'ha de copiar el codi corresponent que hi ha a continuació.

Document HTML (hello.html):

<!doctype html>
<html lang="ca">
    <head>
        <title>Hello</title>
        <meta charset="UTF-8" />
        <script defer src="hello.js"></script>
    </head>

    <body>
    </body>
</html>

Document JavaScript (hello.js):

"use strict";

// El mètode alert() serveix per mostrar missatges i dades
alert("Hello World");

Executar l'aplicació

Per obrir l'aplicació en un navegador web cal fer clic amb el botó secundari sobre l'arxiu hello.html i seleccionar l'opció Open with Live Server.

Això farà que la'plicació s'obri en el navegdor per defecte i apareixi un missatge amb el text Hello World.
Si es modifica i es guarda el codi dels arxius de la pàgina (o al prémer la tecla F5) es tornarà a mostrar el missatge.
