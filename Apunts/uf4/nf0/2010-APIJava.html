La API de Java

Per desenvolupar un programa, no cal crear tot el codi partint de zero.
Hi ha disponibles moltes llibreries que ens poden estalviar molta feina.

Java disposa d'un conjunt molt ampli de classes agrupades en paquets.
Un bon programador ha de ser capaç de localitzar i saber utilitzar les classes que li poden ser útils.

API Java SE 17

Mòdul java.base

En Java, encara hi ha una forma d'agrupació superior als paquets: els mòduls.
Aquesta formar d'agrupar paquets es pot utilitzar a partir Java SE 9, però no es veurà aquí en detall.

El mòdul java.base inclou els paquets i classes més utilitzats.
Dins d'aquet mòdul hi ha el paquet java.lang que s'inclou automàticament en tots el programes.

Les classes que es troben en el paquet java.lang estan disponibles sense necessitat d'importar-les.
Algunes de les classes més útils d'aquest paquet són Math, String i System.
Aquestes classes disposen de mètodes estàtics que ja s'han utilitzat anteriorment.

Paquet java.utils

Es poden trobar altres classes interessants amb mètodes estàtics en el paquet java.util:

  • Random
  • Scanner
  • Arrays

Aquestes classes sí que cal importar-les per poder-les utilitzar.
