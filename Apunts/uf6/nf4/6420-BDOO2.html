Gestió avançada de db4o

Precaucions que cal tenir en compte

Modificació de classes
Si es modifiquen els atributs d'una classe que té objectes guardats a la base de dades, caldrà tornar a generar tot el contingut (no es podran recuperar els objectes d'aquesta classe).

Tractament d'excepcions
Cal posar el codi que gestiona la BD dins d'un try ... finally per garantir que la BD es tanca en cas d'error.

Guardar (afegir) i llegir objectes

Quan es guarda un objecte nou o es llegeix (no quan s'actualitza), també es guarden/llegeixen els objectes enllaçats: si un client conté una llista de factures, aquestes també es guarden/llegeixen, i si cada factura conté una llista de productes, aquests també es guarden/llegeixen.

El límit de recursivitat per defecte és 5 però, si es considera necessari, es pot modificar:

EmbeddedConfiguration conf = Db4oEmbedded.newConfiguration();
conf.common().activationDepth(10);

Cerca avançada

Per fer cerques més avançades es pot utilitzar el mètode query(Predicate<T> p).

Cal implementar la classe Predicate<T> amb el mètode boolean match(T t) per saber si un objecte compleix els criteris de la cerca.

Normalment, s'implementa creant una classe anònima a la vegada que es crea un objecte d'aquesta classe:

Predicate pred = new Predicate<Persona>() {
    @Override
    public boolean match(Persona p) {
        return p.calcularIMC() >= 40;
    }
};

ObjectSet<Persona> result = db.query(pred);

En l'exemple anterior es podria canviar el 40 per una variable definida dins del mateix àmbit:

float imcMin = 40;

Predicate pred = new Predicate<Persona>() {
    @Override
    public boolean match(Persona p) {
        return p.calcularIMC() >= imcMin;
    }
};

També es pot crear una classe personalitzada:

public class PredicatIMC extends Predicate<Persona> {
    float min;
    float max;

    public PredicatIMC(float min, float max) {
        setRang(min, max);
    }
   
    public void setRang(float min, float max) {
        this.min = min;
        this.max = max;
    }

    @Override
    public boolean match(Persona p) {
        float imc = p.calcularIMC();
        return imc >= min && imc < max;
    }
}

Predicate pred = new PredicatIMC(18.5f, 25);    // IMC normal
ObjectSet<Persona> result = db.query(pred);

pred.setRang(50, 100);                          // IMC obesitat extrema
ObjectSet<Persona> result = db.query(pred);

O crear una classe com a contenidor per a diferents consultes:

public class ConsultesIMC {
    static float min = 18.5f;
    static float max = 25;

    public static void setRang(float min, float max) {
        ConsultesIMC.min = min;
        ConsultesIMC.max = max;
    }

    public static Predicate obesitatGreu = new Predicate<Persona>() {
        @Override
        public boolean match(Persona p) {
            return p.calcularIMC() >= 40;
        }
    };

    public static Predicate rangIMC = new Predicate<Persona>() {
        @Override
        public boolean match(Persona p) {
            float imc = p.calcularIMC();
            return imc >= min && imc < max;
        }
    };
}

Predicate pred = ConsultesIMC.rangIMC;

ConsultesIMC.setRang(40, 100);                     // IMC obesitat extrema
ObjectSet<Persona> result = db.query(pred);

ConsultesIMC.setRang(18.5f, 25);                   // IMC normal
ObjectSet<Persona> result = db.query(pred);

Tant si es busquen objectes amb el mètode nadiu com si es fa amb Query By Example, es processen tots els objectes de la classe especificada.

Cerca ordenada

També es pot obtenir el resultat ordenat si s'inclou un Comparator:

Comparator<Persona> pCmp = new Comparator<Persona>() {
    public int compare(Persona p1, Persona p2) {
        return (p1.calcularIMC() - p2.calcularIMC());
    }
}
ObjectSet<Persona> result = db.query(pred, pCmp);

Actualització avançada

Per defecte, amb un objecte que conté relacions amb altres objectes (per exemple una llista), si es llegeix, es modifica (s'afegeixen objectes a la llista) i es torna a guardar, els nous objectes afegits a la llista no es guardaran, excepte que la BD s'obri amb un paràmetre de configuració especial:

EmbeddedConfiguration config = Db4oEmbedded.newConfiguration();
// Classes que cal actualitzar en cascada
config.common().objectClass(NomClasse1.class).cascadeOnUpdate(true);
config.common().objectClass(NomClasse2.class).cascadeOnUpdate(true);
// ...
ObjectContainer db = Db4oEmbedded.openFile(config, "persones.db4o");

Si només es vol actualitzar un objecte, cal comprovar que la cerca ha retornat un objecte, i només un.

Esborrat avançat (objectes que contenen altres objectes)

Quan s'esborra un objecte, els objectes enllaçats no s'esborren automàticament!
Si cal, s'hauran d'esborrar manualment o activar una configuració especial abans d'obrir la BD:

EmbeddedConfiguration config = Db4oEmbedded.newConfiguration();
// Classes que cal actualitzar en cascada
config.common().objectClass(NomClasse1.class).cascadeOnDelete(true);
config.common().objectClass(NomClasse2.class).cascadeOnDelete(true);
// ...
ObjectContainer db = Db4oEmbedded.openFile(config, "persones.db4o");

Si s'activa aquesta opció, els objectes enllaçats a l'objecte esborrat s'eliminaran sense tenir en compte si estan enllaçats a altres objectes.

Si s'esborra directament un objecte enllaçat, en l'objecte o objectes que el contenen apareixerà null!

Les llistes i altres conjunts de dades també són objectes.
Si s'esborra un objecte que conté un conjunt d'objectes i no està activat l'esborrat en cascada, aniran quedant aquests conjunts en la base de dades.

Herència

Suposant que la classe Persona tingui les subclasses Adult i Infant, hi ha dues possibilitats:

  • Si la superclasse (Persona) no és abstracta i té constructors, es pot crear un objecte plantilla d'aquesta classe per fer la consulta.
    En el resultat ObjectSet pot haver-hi objectes de Adult i de Infant.
  • Si la superclasse és abstracta o no té constructors, es pot utilitzar el nom de la classe directament per obtenir tots els objectes: ObjectSet resultat = db.get(Persona.class);

Es podrien obtenir tots els objectes de la BD amb una consulta com la següent:

ObjectSet<Object> result = db.queryByExample(new Object());
Object o;
while (result.hasNext()) {
    o = result.next();
    System.out.println(o.getClass().getSimpleName() + " --> " + o);
}

O es podrien esborrar tots els objectes afegint db.delete(o).

Accés remot a una BD db4o

Engegar i configurar el servidor

import java.util.Scanner;
import com.db4o.*;
import com.db4o.cs.Db4oClientServer;

public class ServerDB4O {
    public static final int PORT = 5000;
    public static final String DB = "agencia.db4o";
    public static final String USER = "db4o";
    public static final String PASS = "password";

    public static void main(String[] args) {
        ObjectServer sv = Db4oClientServer.openServer(
                Db4oClientServer.newServerConfiguration(), DB, PORT);
        Scanner scan = new Scanner (System.in);
        String comanda;

        sv.grantAccess(USER, PASS);
        System.out.println("\nServidor engegat en  el port " + PORT);
        System.out.println("Base de dades: " + DB);
        System.out.println("Usuari per accedir: " + USER);
        System.out.println("Contrasenya per accedir: " + PASS);
        System.out.println("Introdueix EXIT per tancar el servidor");

        do {
            comanda = scan.nextLine();
        } while (!comanda.equalsIgnoreCase("EXIT"));

        sv.close();
    }
}

Engegar el client i connectar amb la BD

import com.db4o.*;
import com.db4o.cs.Db4oClientServer;

public class ClientDB4O {
    public static void main(String[] args) {
        // Connexió local
        //ObjectContainer db = Db4oEmbedded.openFile("agencia.db4o");

        // Connexió remota (caldria canviar 'localhost' per la IP o domini)
        ObjectContainer db = Db4oClientServer.openClient(
                "localhost",
                ServerDB4O.PORT,
                ServerDB4O.USER,
                ServerDB4O.PASS);

        try {
            // Operacions amb la BD
        } finally {
            db.close();
        }
    }
}

Si s'ha obert una BD amb el servidor, queda bloquejada i no es pot obrir en local simultàniament.
