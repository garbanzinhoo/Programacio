Introducció a Java

Tres en ratlla

Crea un projecte amb el nom TresEnRatlla.

La classe principal també es dirà TresEnRatlla.

Ha de tenir les següents propietats globals (han de ser públiques):

  • Scanner scan (per llegir les dades que l'usuari introdueix amb el teclat)
  • char[][] joc (array de 3 x 3 que conté les caselles del joc i les peces que els jugadors van posant)

El mètode principal (main) ha de:

  • Inicialitzar l'array del joc (posar un '·' a totes les caselles).
  • Repetir fins que un dels jugadors aconsegueixi tres en ratlla o fins que no es puguin posar més peces.
    • Mostrar el joc
    • Demanar la jugada alternativament a cada jugador (fila i columna on vol posar la peça)
    • Verificar que la posició està buida i posar la peça (o tornar a demanar)
    • Verificar si ha aconseguit tres en ratlla o si s'ha omplert el tauler
  • Mostrar el joc i indicar qui ha guanyat

OPCIONAL: quan s'acabi el joc, demanar si es vol tornar a fer una altra partida.

Tres en ratlla MVC

Separa el joc anterior en diverses classes i paquets fent que tingui un esquema MVC (Model Vista Controlador).

Crear i provar una llibreria pròpia

Crea el projecte Llibreria.

Crea els subpaquets input, arrays i altres.

Dins del paquet input crea una classe amb mètodes per introduir diferents tipus de dades:

  • Introduir un número enter
  • Introduir un número verificant que estigui entre dos valors
  • Introduir un caràcter
  • Introduir un caràcter verificant que estigui entre els caràcters de un string o d'un array de caràcters.

A aquests mètodes se'ls hauria de passar la pregunta que s'ha de fer a l'usuari, els valors màxim i mínim, un string o un array amb els caràcters vàlids i haurien de retornar el valor o caràcter introduït per l'usuari.

Dins del paquet arrays crea les classes IntegerArrays i StringArrays i posa dins de cada funcions que serveixin per:

  • Crear un array de N elements
  • Crear un array bidimensional de N x M elements
  • Inicialitzar un array amb un valor determinat
  • Inicialitzar un array bidimensional amb un valor determinat
  • Mostrar els valors d'un array
  • Mostrar els valors d'un array bidimensional
  • Invertir els elements d'un array
  • Desplaçar els elements d'un array
  • Barrejar els elements d'un array,

Afegeix qualsevol altre mètode que pugui resultar útil.
Aquests mètodes han de tenir com a mínim un paràmetre: l'array que s'ha de tractar.
Exceptuant els dos primers mètodes, la resta no cal que retornin res.

Dins de altres pots crear altres mètodes, com per exemple:

  • Generar un número enter aleatori entre dos valors
  • Generar un caràcter aleatori entre dos caràcters

En l'arrel del projecte crea la classe TestFuncions amb el codi necessari per provar els mètodes de les classes anteriors.

Documentar projecte i generar JAR

Documenta totes les classes i funcions del projecte anterior.

A més de documentar utilitzant el format adequat, genera la documentació utilitzant JavaDoc.

Finalment, empaqueta el projecte en un arxiu JAR, intercanvia'l amb un altre company i comproveu que el podeu executar.
