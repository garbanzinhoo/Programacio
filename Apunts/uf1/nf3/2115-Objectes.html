Objectes en JavaScript

Objectes definits per l'usuari

Referència

Objectes bàsics

Un objecte, al contrari que les variables primitives, pot contenir més d'un valor (pot està format per diverses dades que, a més, poden ser de diferents tipus).

Les variables que formen un objecte se'n diuen propietats o atributs i poden ser de diferents tipus, fins i tot altres objectes compostos (arrays o objectes de qualsevol tipus).
Cada propietat té un nom i un valor associat.

Els objectes es representen amb claus i separant les propietats amb una coma:

  • {} és un objecte buit.
  • {nom: "Peter", cicle: "DAW"} és un objecte amb 2 propietats o atributs.

Es poden afegir propietats de forma dinàmica.

Si el nom d'una propietat ha de contenir espais (cosa no recomanable), cal posar-lo entre cometes.

Crear, inicialitzar i eliminar objectes senzills

let alumne = {nom: "Mary", curs: 1};  // Es crea un objecte i se l'assigna a una variable

alumne.curs = 2;                      // Es canvia la propietat 'curs' de l'objecte
alumne = {};                          // S'assigna a la variable un objecte buit
                                      // També es pot fer alumne = undefined;

Assignació d'objectes

Al contrari que passa amb les variables primitives, al assignar a una variable una altra que conté un objecte, no es fa una còpia del contingut, sinó que totes dues variables apunten al mateix objecte.

Això implica que si es modifica alguna propietat en alguna de les variables, també es modifica en l'altra:

let alumne1 = {nom:"Mary", curs:1};
let alumne2 = alumne1;   // Totes dues variables apunten al mateix objecte

alumne1.nom = "Peter";   // 'alumne2.nom' també serà "Peter"
alumne2 = {};            // Ara l'objecte només està assignat a la variable 'alumne1'
alumne1 = undefined;     // Una altra forma de treure un objecte d'una variable

Quan un objecte no està assignat a cap variable, s'envia a la recollida d'escombraries per ser eliminat.

Objectes complexos

Tenen propietats que són altres objectes o arrays.

let alumne = {
  DNI: 12345678,
  nom: "Peter",
  dicle: "DAW",
  dataNaixement: new Date("2000-12-31"),
  moduls: ["M01", "M02", "M03"],
  pagaments: {matricula:true, excursions:false}
};

alumne.moduls.push("M04");
alumne.pagaments.excursions = true;

Arrays d'objectes

let alumnes = [{nom:"Mary", curs:1}, {nom:"Peter", curs:2}];
