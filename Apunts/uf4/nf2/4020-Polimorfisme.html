Introducció a la programació orientada a objectes

Polimorfisme

Seguit amb l'exemple dels animals, tots es desplacen però uns caminen, altres neden i altres volen.
Per tant, hem de fer que tots es moguin, però cada un a la seva manera (polimorfisme).

Això s'aconsegueix definint un mètode en la superclasse i el mateix mètode però amb diferent codi per cada subclasse.

En el següent exemple, s'ha creat el mètode moure() en la superclasse.
Si en alguna de les subclasses (Mamifer) no es defineix aquest mètode, s'executarà el de la superclasse.
En les subclasses on es defeineixi (on se sobreescrigui), s'executarà el de la subclasse que correspongui.

public class Animal {
    // Mètode sobreescrit en algunes subclasses (polimorfisme)
    public void moure() {
        System.out.println("M'estic movent");
    }
}

public class Mamifer extends Animal {
    // No sobreescriu el mètode moure() en aquesta subclasse
    //  perquè hi ha mamífers que neden, volen, corren, salten, pugen als arbres...
}

public class Peix extends Animal {
    // Mètode sobreescrit (polimorfisme)
    public void moure() {
        System.out.println("Estic nedant");
    }
}

public class Ocell extends Animal {
    // Mètode sobreescrit (polimorfisme)
    public void moure() {
        System.out.println("Estic volant");
    }
}

public class TestAnimal {
    public static void main(String[] args) {
        Animal ovella = new Mamifer("Ovella");
        Animal sardina = new Peix("Sardina");
        Animal colom = new Ocell("Colom");

        ovella.moure();  // Escriu M'estic movent (crida el mètode de la superclasse)
        sardina.moure(); // Escriu Estic nedant (crida el mètode de la sublasse Peix)
        colom.moure();   // Escriu Estic volant (crida el mètode de la subclasse Ocell)
    }
}

Els mètodes sobreescrits en la subclasse no poden ser més restrictius que el de la superclasse:

  • private Animal.moure() i public Ocell.moure() → OK
  • public Animal.moure() i private Ocell.moure() → ERROR

La paraula reservada super

S'utilitza per cridar un mètode de la superclasse que està sobreescrit en la subclasse.
En l'exemple següent, si no es posa la paraula super, es cridaria el mateix mètode moure() de la classe Ocell. A més, en aquest cas concret, es crearia una crida recursiva infinita.

public class Ocell extends Animal {
    // Mètode sobreescrit (polimorfisme)
    public void moure() {
        super.moure();    // Escriu "M'estic movent"
        System.out.println("Estic volant");
    }
}
