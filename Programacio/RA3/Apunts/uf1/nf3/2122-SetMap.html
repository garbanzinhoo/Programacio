Set

Referència "Set"

Referència Set detallada (MDN)

Serveix per emmagatzemar un conjunt d'objectes únics (no es poden guardar dos objectes repetits).
Per saber si un objecte està repetit s'utilitza la comparació estricta (obj1 === obj2).
Els elements mantenen l'ordre en què s'han afegit al Set.
Cada objecte emmagatzemat pot ser d'un tipus diferent.

Crear un Set

const s = new Set();             // Crea un conjunt buit
const s = new Set([1, 2, 3, 4]); // Crea un conjunt amb els valors 1, 2, 3 i 4
const s = new Set([1, 1, 1, 1]); // Crea un conjunt amb l'element 1

Atributs i mètodes

  • size: conté la mida (quants elements té).
  • add(obj): afegeix un element.
  • has(obj): retorna true si obj està dins del Set.
  • delete(obj): elimina obj si el troba dins del Set.
  • clear(): elimina tots els objectes del Set.

Recòrrer un Set

Es pot fer de la mateixa forma que es fa amb un Array: amb un bucle for ... of

const s = new Set([1, 2, 3, 4]);
for (let o of s) {
    console.log(o);
}

Convertir Set en Array

Es pot obtenir un array amb els objectes del Set utilitzant const array = [...set].

Map

Referència "Map"

Referència Map detallada (MDN)

Serveix per emmagatzemar parelles clau-objecte (les claus no es poden repetir).
Els elements mantenen l'ordre què s'han afegit al Map.
Es pot utilitzar qualsevol tipus d'objecte o primitiva, tant per la clau com per l'objecte que s'ha d'emmagatzemar.

Crear un Map

const m = new Map();             // Crea un conjunt buit
const m = new Map([["pomes", 500], ["bananas", 300], ["taronges", 200]]);

Atributs i mètodes

  • size: conté la mida (quants elements té).
  • set(key, obj): afegeix una parella clau-objecte.
  • get(key): retorna l'objecte associat a la clau.
  • delete(key): elimina l'objecte associat a la clau.
  • clear(): elimina tots els objectes del Map.

És recomanable triar una clau que representi l'objecte.
Pot ser un dels atributs o un String que combini diversos atributs.

Recòrrer un Map

Es pot fer de la mateixa forma que es fa amb un Array: amb un bucle for ... of però cada objecte és un array amb una parella clau-objecte.

const m = new Map([["pomes", 500], ["bananas", 300], ["taronges", 200]]);
for (let a of m) {
    console.log(a[0] + " - " + a[1]);
}

Convertir Map en Array

Es pot obtenir un array amb les claus utilitzant const array = [...map.keys()].

Es pot obtenir un array amb els objectes utilitzant const array = [...map.values()].

També es pot crear un array d'arrays amb les parelles clau-objecte: const array = [...map].
