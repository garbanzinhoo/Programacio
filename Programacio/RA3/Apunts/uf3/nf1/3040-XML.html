Documents XML

Els documents XML estan formats per:

  • Text (fulles): conté la informació.
  • Elements: agrupen diferents continguts (altres elements) i la informació (text).
    També s'anomenen etiquetes i s'escriuen en la forma <nomElement>...</nomElement>.
  • Atributs: formats per un nom i un valor.
    S'inclouen dins dels elements en la forma nom="valor".
  • Pròleg (opcional): proporciona informació sobre el format de l'arxiu.

Llegir arxius amb format XML

Plantilla bàsica:

DocumentBuilderFactory dbf = DocumentBuilderFactory.newInstance();
DocumentBuilder db;    // Constructor d'objectes XML a partir d'arxius XML
Document doc;          // Document (objecte) XML
Node root;             // Node arrel del document XML
File f;                // Ruta cap a l'arxiu XML

try {
    f = new File("src/uf5/exemples/xml/menu.xml");
    db = dbf.newDocumentBuilder();
    doc = db.parse(f);
    root = doc.getDocumentElement();
    // TODO: codi per gestionar les dades
} catch (ParserConfigurationException e) {
    e.printStackTrace();
} catch (IOException e) {
    e.printStackTrace();
} catch (SAXException e) {
    e.printStackTrace();
}

Processar un document XML

Mètodes bàsics de la interfície Document

  • getDocumentElement(): retorna l'element arrel del document.
  • createElement(String nom): crea un element (etiqueta).
  • createTextNode(String nom): crea un node de text (contingut textual d'un element).
  • createAttribute(String nom): crea un node de tipus atribut (Attr).

Mètodes per afegir, modificar i eliminar nodes

  • appendChild(Node nou): afegeix un nou fill al final.
  • insertBefore(Node nou, Node ref): afegeix un nou fill abans d'un altre.
  • removeChild(Node n): elimina un fill.
  • replaceChild(Node nou, Node antic): substitueix un fill per un altre.
  • setTextContent(String text): afegeix un node de tipus text.

Mètodes bàsics de la interfície Node

  • getChildNodes(): obté una llista amb tots els fills, siguin del tipus que siguin.
  • getFirstChild(): obté el primer fill.
  • getNextSibling(): obté el següent germà.
  • getAttributes(): obté un conjunt amb els atributs del node (si és un Element).
  • getTextContent(): obté el contingut textual del node i tots els descendents.
  • getNodeType(): retorna el tipus de node (element, text, comentari...).
  • getParentNode(): retorna el pare del node.
  • getOwnerDocument(): retorna l'objecte de tipus Document que conté aquest node.
    Aquest objecte es pot utilitzar per crear nous nodes.

Mètodes bàsics de la interfície Element

  • getTagName(): retorna el nom (etiqueta) de l'element.
  • getElementsByTagName(String nomElement): obté tots els elements per sota d'aquest element (fills, nets...) que tinguin el nom nomElement.

Mètodes per afegir, modificar i esborrar atributs

  • hasAttribute(String nomAtribut): retorna true si l'element conté l'atribut nomAtribut.
  • getAttribute(String nomAtribut): obté el valor de l'atribut nomAtribut.
  • removeAttribute(String nomAtribut): elimina l'atribut nomAtribut.
  • setAttribute(String nomAtribut, String valor): afegeix un atribut o modifica el seu valor.

Mètodes bàsics de la interfície Attr

  • getName(): retorna un String amb el nom de l'atribut.
  • getValue(): retorna un String amb el valor de l'atribut.
  • setName(String valor): modifica el valor de l'atribut.

Mètodes bàsics de la interfície Text

  • getWholeText(): retorna un String amb tot el text.
    Pot ser necessari "netejar-lo" (si en el document hi ha salts de línia i espais al principi de les línies, aquests també apareixen). Es podria utilitzar la comanda t.replaceAll("\\s+", " ").trim() per fer-ho.
  • replaceWholeText(String nouText): substitueix el contingut d'un node de text.

Element, Text i Attr són subinterfícies de la interfície genèrica Node.
Alguns mètodes retornen un objecte de tipus Node en comptes de retornar el tipus específic.
Per poder utilitzar els mètodes específics de cada tipus, cal convertir el node al tipus correcte.

Llistes de nodes

Alguns mètodes retornen una llista de nodes (NodeList o NamedNodeMap).
Per recuperar processar els elements d'un NodeList es pot utilitzar un bucle com el següent:

NodeList l = doc.getElementsByTagName("llibre");
for (int i = 0; i < l.getLength(); ++i) {
    Node n = l.item(i);
    System.out.println(((Element)n).getTagName());
}

En el cas de NamedNodeMap, que pot contenir una llista d'atributs, es pot fer el mateix però també es pot obtenir directament un element a partir de l'identificador, sense haver de recórrer tota la llista:

Attr a = (Attr)l.getNamedItem("edat");
System.out.println(a.getName() + ": " + a.getValue());

Guardar informació amb format XML

Plantilla bàsica:

DocumentBuilderFactory dbf = DocumentBuilderFactory.newInstance();
DocumentBuilder db;
Document doc;
Node root;
File f;

try {
    f = new File("src/uf5/exercicis/xml/prova.xml");
    db = dbf.newDocumentBuilder();
    doc = db.newDocument();
    root = doc.createElement("arrel");
    doc.appendChild(root);
    // TODO: afegir elements dins de l'arrel
    TransformerFactory tf = TransformerFactory.newInstance();
    Transformer transformer = tf.newTransformer();
    DOMSource source = new DOMSource(doc);
    StreamResult result = new StreamResult(f);
    transformer.transform(source, result);
} catch (ParserConfigurationException e) {
    e.printStackTrace();
} catch (TransformerConfigurationException e) {
    e.printStackTrace();
} catch (TransformerException e) {
    e.printStackTrace();
}
