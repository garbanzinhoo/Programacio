Solució

  • L'edat d'una persona: byte, short o int
  • El preu d'un ordinador: float o double
  • Si ets major d'edat: boolean
  • El nombre d'alumnes de l'institut Sa Palomera (o similar): short o int
  • La lletra del DNI: char
  • El número PI: double
  • El nom d'una persona: String
  • El nombre d'habitants de Catalunya: int
  • El resultat de calcular l'area d'un cercle: float o double
  • La quantitat de bytes que hi caben en un disc d'un TB (terabyte): long

int a = 512343;
int b = 3431231;
System.out.println(a + b);    // 3943574
long c = 512343512343L;
long d = 34312313431231L;
System.out.println(c + d);    // 34824656943574
char e = 'e';
int f = 3431231;
System.out.println(e + e);    // 202
System.out.println(e + f);    // 3431332
int g = 512343;
String h = "h";
System.out.println(g + h);    // 512343h
float n = 3.5f;
float o = 1.5f;
System.out.println(n / o);    // 2.3333333
System.out.println(a / o);    // 341562.0
