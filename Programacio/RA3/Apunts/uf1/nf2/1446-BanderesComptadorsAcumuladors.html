Banderes

En programació, una bandera és una variable booleana (només pot tenir els valors true o false) que serveix per detectar si ha succeït alguna cosa.

Per exemple, en un bucle es pot utilitzar una bandera per saber si es donen les condicions per finalitzar-lo.
O també per saber si el bucle ha finalitzat d'una forma o una altra (per exemple, si s'ha trobat l'element que es buscaba o no).

La bandera cal inicialitzar-la amb un valor (true o false) que canviarà dins del bucle quan es doni una condició determinada. El canvi només s'ha de produir en un sentit: si el valor inicial era true, només ha de poder canviar a false. Si es canvia en sentit contrari no podrem saber si s'ha produït la situació que es volia controlar.
Cal pensar bé quin ha de ser el valor inicial i amb quines condicions s'haurà de canviar el seu valor.
Un cop hagi canviat el valor, la bandera no hauria de tornar al valor original.

Exemple

let nom;
let edat;
let altura;
let edatIncorrecta = false;

nom =  promt("Com et dius? ");
while (nom.toUpperCase() != "FI") {
    edat = prompt("Quina edat tens?");
    if (edat < 18 || edat > 65) {
        edatIncorrecta = true;
        break;
    }
    // Processar o guardar les dades
    // ...
    nom =  promt("Com et dius? ");
}

if (edatIncorrecta) alert("S'ha introduït una edat incorrecta");

Altres tipus de banderes

De vegades cal tenir en compte més de dos possibles estats, per exemple, un semàfor pot estar en verd, en groc o en vermell, i només pot passar de verd a groc, de groc a vermell i de vermell a verd.

En aquests casos es pot tenir una bandera amb diferents valors numèrics per indicar l'estat actual, per exemple, 1 per indicar que està en verd, 2 en groc i 3 en vermell.

Comptadors i acumuladors

Una de les utilitats dels bucles pot ser comptar quantes dades compleixen certes condicions, calcular un total a partir d'un conjunt de valors o juntar diferents trossos de text.

Normalment, els comptadors i acumuladors s'inicialitzen a 0.
Si es vol juntar trossos de text, es comença inicialitzant un text buit.

Un comptador també pot servir com a bandera: si el seu valor no es mou del 0, no s'ha produït l'edeveniment concret; si al final té un valor n superior a 0, l'esdeveniment s'haurà produït n vegades.

Exemple

let paraula;
let frase = "";      // Per juntar trossos de text
let paraules123 = 0;    // Comptador
let totalLletres = 0;   // Acumulador

paraula = prompt("Escriu una paraula (sense espais)");
while (paraula.toUpperCase() != "FI") {
    frase += paraula + " ";                    // Juntar text
    totalLletres += paraula.length();          // Acumulador
    if (paraula.length() < 4) ++paraules123;   // Comptador
    paraula = prompt("Escriu una paraula (sense espais)");
}

alert("Frase: " + frase);
alert("Lletres: " + totalLletres);
alert("Paraules de menys de 4 lletres: " + paraules123);
