Funcions: paràmetres i valor de retorn

Valor de retorn d'una funció

Si es vol que la funció retorni un valor, cal utilitzar la paraula reservada return:

function area(base, altura) {
    return base * altura;
}

Aquest valor es podrà assignar a una variable o ser utilitzat en una expressió:

let areaMetres = area(10, 5);
let areaCentimetres = area(10, 5) * 10000;

No s'indica de cap forma especial que una funció ha de retornar un valor ni de quin tipus ha de ser aquest.
De fet, una funció pot finalitzar retornant un valor en alguns casos i res en altres (però que es pugui fer no vol dir que sigui recomanable fer-ho!):

function missatge(m) {
    if (typeof m === "string") return "Atenció: " + m;   // Retorna string
    if (m == 1) return "Codi de missatge: 0x01";         // Retorna string
    if (m > 10) return m;                                // Retorna número
    // Si no és cap dels casos anterior, retorna undefined
}

Si una funció no retorna cap valor, és equivalent a retornar undefined:

let m = missatge();
if (m !== undefined) console.log(m);
else console.log("Missatge desconegut");

Paràmetres d'una funció

Al cridar una funció, se li poden passar arguments (valors que es podran utilitzar dins de la funció).
Aquests valors es guarden en els paràmetres de la funció (equivalen a variables locals de la funció).

Els arguments es guarden en els paràmetres seguint el mateix ordre.

En cas que el nombre d'arguments i de paràmetres no sigui el mateix:

  • Si hi ha més arguments que paràmetres, es descarten els últims arguments sobrants.
  • Si hi ha més paràmetres que arguments, s'assigna el valor undefined als últims paràmetres.

Paràmetres amb valor per defecte

Antigament es podia assignar un valor per defecte comprovant si l'argument tenia el valor undefined:

function error(m) {
    if (m == undefined) m = "Error desconegut";
    alert(m);
}

error();                        // Mostrarà 'Error desconegut'
error("El valor no és vàlid");  // Mostrarà 'El valor no és vàlid'

Actualment es poden assignar valors per defecte en la mateixa definició de paràmetres.
Si un argument no es passa o se li posa el valor undefined, se li assigna el valor per defecte.
Els paràmetres amb valor predefinit poden estar en qualsevol posició (no  cal que siguin els últims):

function error(m = "Error desconegut") {
    alert(m);
}

error();                        // Mostrarà 'Error desconegut'
error("El valor no és vàlid");  // Mostrarà 'El valor no és vàlid'

Paràmetres ocults

A part dels paràmetres explícits, també hi ha dos paràmetres ocults:

  • arguments: és un objecte similar a una llista amb els arguments que se li han passat i té la propietat length per saber quants arguments se li han passat.
    Es pot convertir a una llista real fent let llista = Array.prototype.slice.call(arguments).
  • this: indica el context on s'executa la funció (l'objecte propietari de la funció):
    • En una funció global, this representa l'objecte window.
    • En una funció que pertany a un objecte, this representa l'objecte.

En el següent exemple:

  • arguments ≈ [5, 6, 7]
  • this = alumne

let alumne = {
  nom: "Mary",
  mitjana: function() {
    let suma = 0;
    for (let i = 0; i < arguments.length; ++i) { suma += arguments[i]; }
    alert("Notes " + this.nom + ": " +  Array.prototype.slice.call(arguments) +
      "\nMitjana: " + (suma / arguments.length));
  }
}

alumne.mitjana(5, 6, 7);

En la funció mitjana no cal posar paràmetres i se li poden passar tants arguments com siguin necessaris.
Seria convenient comprovar que el nombre d'arguments (arguments.length) no és zero!
