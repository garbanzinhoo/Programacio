Disseny descendent

Quan els problemes que es volen resoldre creixen i es compliquen, no n'hi ha prou amb conèixer la programació estructurada.

Per tractar aquests casos, el disseny descendent és una de les tècniques més utilitzades.

Aquest mètode consisteix en dividir el problema en trossos més petits, i si aquests trossos encara són massa grans o complicats, es tornen a subdividir fins que s'arribi a un nivell abastable.

Per exemple, la majoria dels exercicis que s'han fet anteriorment es poden dividir en tres grans blocs: introducció de dades, processament de les dades i visualització dels resultats.
I cada un d'aquests blocs es pot subdividir si es considera necessari:

  • Introducció de dades.
    • Introduir les dades del client.
    • Introduir les dades de la comanda.
    • Comprovar les dades introduïdes.
  • Processament de dades.
    • Calcular subtotals.
    • Calcular descompte, IVA i import total.
  • Visualització de resultats.
    • Mostrar la factura detallada.
    • Demanar confirmació de la compra.
    • Realizar el procés de pagament.

També es poden considerar com a blocs de primer o segon nivell les diferents opcions en un programa que pot realitzar diferents accions a partir d'un menú:

  • Mostrar menú d'opcions.
  • Triar una opció.
    • Comprovar que l'opció sigui correcta.
    • Processar l'opció triada (cada opció tindrà el seu propi bloc).
      • Demanar les dades necessàries per aquesta opció.
      • Processar les dades.
      • Mostrar el resultat.

Descomposició bàsica en funcions

Una forma senzilla de descomposar un programa consisteix en crear funcions o mètodes i cridar-los des del mètode principal o des d'altres mètodes.

En el cas de JavaScript es poden definir funcions de la següent forma:

function nomDeLaFuncio() {
    // Codi de la funció
}

Per executar (cridar, invocar...) aquesta funció des de qualsevol punt del programa es fa així:

nomDeLaFuncio();

Quan el programa troba una crida a una funció, s'executa el codi d'aquesta i, quan acaba o troba una instrucció return, torna a la instrucció següent a on s'ha cridat la funció.

La instrucció return dins d'una funció és similar a la instrucció break dins d'un bucle.

Un exemple molt bàsic podria ser el següent:

introduirDades();
processarDades();
mostrarResultats();

function introduirDades() {
    // Codi per demanar les dades
}

function processarDades() {
    // Codi per processar les dades
}

function mostrarResultats() {
    // Codi per mostrar el resultat
}

Utilitzar el debugger amb funcions

Quan estem depurant pas a pas i trobem una crida a una funció, el depurador ens permet executar tota la funció i aturar-se en la següent línia o entrar dins de la funció per executar-la pas a pas.

Si entrem dins de la funció, en qualsevol moment podem fer que el depurador executi fins al final de la funció i s'aturi en la línia següent on s'ha cridat la funció.

Variables globals i locals

Les variables que es defineixen dins d'un bloc de codi, i per tant les que es defineixen dins d'una funció, són variables locals. Això vol dir que només es poden utilitzar dins d'aquest bloc de codi.

Per fer que una variable es pugui utilitzar des de qualsevol lloc, cal definir-la fora de qualsevol bloc (en el cos principal del programa). Això farà que sigui una variable global.

Exemple:

let radi, area;    // Variables globals

introduirDades();
processarDades();
mostrarResultats();

function introduirDades() {
    radi = parseFloat(prompt("Introdueix el radi del cercle"));
}

function processarDades() {
    let radi2 = radi * radi;    // Variable local
    area = Math.PI * radi2;
}

function mostrarResultats() {
    alert("L'àrea del cercle és " + area);
}
