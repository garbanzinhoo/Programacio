Modificacions i consultes a la BD

Tot i que els objectes Statement i PreparedStatement tenen el mètode execute() per executar sentències genèriques , és preferible utilitzar les següents:

  • executeUpdate(String sql_sentences) per sentències que modifiquin la base de dades:
    • CREATE TABLE
    • DROP TABLE
    • ALTER TABLE
    • INSERT INTO
    • DELETE FROM
    • UPDATE
  • executeQuery(String sql_sentence) per sentències que facin consultes a la base de dades:
    • SELECT

En el primer cas, només es retorna un valor enter que indica el nombre de registres afectats.
En el segon cas es retornen les dades de la consulta en un objecte de tipus ResultSet.

ResultSet

Aquest objecte conté les dades resultat de la consulta.

Conté un apuntador que, al principi, està situat just abans del primer registre retornat.
Per recórrer tots els registres cal utilitzar la comanda next() fins que retorni false (fila inexistent):

Per obtenir els camps de cada registre cal utilitzar els mètodes getXXX(nom_o_index_del_camp):

  • String getString()
  • int getInt()
  • int getDouble()
  • java.sql.Date getDate()
  • etc...

ResultSet rs = stmt.executeQuery("SELECT nif,nom,edat FROM alumnes");
while(rs.next()) {
    String nif = rs.getString("nif");
    String nom = rs.getString("nom");
    int edat = rs.getInt(3);   // És més eficient (no ha de buscar pel nom del camp)
}

Normalment no caldrà tenir en compte el tipus de la dada perquè es convetirà automàticament:
si s'utilitza getString() amb un camp numèric, retornarà el valor convertit a String;
si s'utilitza getInt() amb un camp de text, retornarà 0.

El paràmetre pot ser el nom del camp o l'índex.
Cal tenir en compte que, en aquest últim cas, la primera columna és la 1, no la 0!
Accedir utilitzant l'índex és més eficient però cal saber en quin ordre estan els camps retornats.

En una BD, els camps poden tenir valors nulls, però en el cas dels mètodes que retornen un valor, si el camp conté un valor null, retornen 0.
Per saber si realment és 0 o null cal cridar el mètode wasNull() just després de llegir el camp.

ResultSetMetaData

De vegades, especialment si cal executar sentències no predefinides, pot ser necessari conèixer quines dades hi ha en el ResultSet (quantes columnes, el nom i el tipus de cada columna...).

Per conèixer aquestes i altres dades, es pot utilitzar un ResultSetMetaData:

ResultSetMetaData rsmd = rs.getMetaData();
int nCols = rsmd.getColumnCount();
s = new String[nCols][2];
for (int i = 0; i < nCols; i++) {
    s[i][0] =  rsmd.getColumnName(i + 1);
    s[i][1] =  rsmd.getColumnTypeName(i + 1);
}

Camps de tipus DATE

En Java, quan es treballa amb dates que s'hauran de guardar en una base de dades, és recomanable crear-les en objectes java.sql.Date en lloc de java.util.Date, però en el moment de guardar-les és preferible convertir-les a text, i llegir-les com a text al recuperar-les:

import java.sql.*;
// Guardar (es guarda com "2000-01-01")
Date data = Date.valueOf("2000-01-01");
Statement stmt = con.createStatement();
stmt.executeUpdate("UPDATE taula SET naixement='" + data.toString() + "' WHERE id=5");
// Llegir
ResultSet rs = stmt.executeQuery("SELECT naixement FROM taula WHERE id=5");
rs.next();
data = Date.valueOf(rs.getString(1));

Si no, la data es pot guardar en un valor de tipus long equivalent als mil·lisegons des de 1970-01-01:

import java.sql.*;
// Guardar (es guarda com 946681200000)
Date data = Date.valueOf("2000-01-01");
Statement stmt = con.createStatement();
stmt.executeUpdate("UPDATE taula SET naixement=" + data.getTime() + " WHERE id=5");
// Llegir
ResultSet rs = stmt.executeQuery("SELECT naixement FROM taula WHERE id=5");
rs.next();
data = new Date(rs.getLong(1));

Exemples utilitzant PreparedStatement

Guardar i recuperar com a text:

import java.sql.*;
// Guardar (es guarda com "2000-01-01")
Date data = Date.valueOf("2000-01-01");
PreparedStatement stmt = con.prepareStatement("UPDATE taula SET naixement=? WHERE id=?");
stmt.setString(1, data.toString());
stmt.setInt(2, 10);
stmt.executeUpdate();
// Llegir
stmt = con.prepareStatement("SELECT naixement FROM taula WHERE id=?");
stmt.setInt(1, 10);
ResultSet rs = stmt.executeQuery();
rs.next();
data = Date.valueOf(rs.getString(1));

Guardar i recuperar com a data (valor long):

import java.sql.*;
// Guardar (es guarda com 946681200000)
Date data = Date.valueOf("2000-01-01");
PreparedStatement stmt = con.prepareStatement("UPDATE taula SET naixement=? WHERE id=?");
stmt.setDate(1, data);
stmt.setInt(2, 10);
stmt.executeUpdate();
// Llegir
stmt = con.prepareStatement("SELECT naixement FROM taula WHERE id=?");
stmt.setInt(1, 10);
ResultSet rs = stmt.executeQuery();
rs.next();
data = rs.getDate(1);

Funcions per convertir entre dates i mil·lisegons

Convertir a mil·lisegons

// d és el camp que conté la data en format AAAA-MM-DD
(strftime('%s',d) - strftime('%s','1970-01-01')) * 1000;

Convetir a data

// m és el camp que conté la data en mil·lisegons
strftime('%Y-%m-%d', m/1000, 'unixepoch')
