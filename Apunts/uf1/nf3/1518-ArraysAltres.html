Arrays: altres utilitats

Ampliar un array

Java no permet modificar la mida d'un array, però es pot ampliar fent els següents passos:

  1. Crear un array amb una mida més gran que l'original.
  2. Copiar els valors de l'array original al nou.
  3. Assignar la variable del nou array a la variable de l'array original.

int n[] = {9,4,6,3};
int m[] = new int[10];    // Crear un array més gran

// Copiar els elements al nou array
for (int i = 0; i < n.length; i++) {
  m[i] = n[i];
}
n = m;

Mostar els elements de l'array original ampliat
for (int i = 0; i < n.length; i++) {
  out.println(n[i]);
}

Aquest sistema és molt ineficient, per tant es recomana reservar l'espai necessari des del principi.
