Plantilla per introduir dades i mostrar resultats en la pàgina web

Un programa d'ordinador agafa unes dades, les processa i genera un resultat.
Les dades poden ser números, text, accions amb el ratolí... i el resultat pot ser un valor numèric, un altre text, una línia...

Per començar a practicar amb dades bàsiques i operacions senzilles, es pot utilitzar una plantilla que ens permetrà:

  • Introduir les dades que es volen processar
  • Executar l'aplicació
  • Mostrar el resultat

A part d'això, també és convenient que crear o buscar un logo, preferiblement en format ICO i amb el nom favicon.ico. Aquest arxiu s'ha de guardar dins de la carpeta del projecte.
Si es vol utilitzar altres formats o noms, s'ha de canviar el nom de l'arxiu dins de plantilla.html.

Document HTML (plantilla.html):

<!doctype html>
<html lang="ca">
    <head>
        <title>Plantilla</title>
        <meta charset="UTF-8" />
        <link rel="icon" type="image/x-icon" href="favicon.ico">
        <link rel="stylesheet" href="plantilla.css" type="text/css">
        <script defer src="plantilla.js"></script>
    </head>

    <body>
        <div class="inputs">
            <label for="nom">Nom</label>
            <input id="nom" type="text">
            <br>
            <label for="nom">Edat</label>
            <input id="edat" type="number">
        </div>
        <button id="exec">Executar</button>
        <div id="terminal" class="terminal"></div>
    </body>
</html>

Document JavaScript (plantilla.js):

"use strict";

// Inputs per introduir el nom i l'edat
const iNom = document.getElementById("nom");
const iEdat = document.getElementById("edat");
// Botó per executar l'aplicació
const bExec = document.getElementById("exec");
// Element on mostrar el resultat
const terminal = document.getElementById("terminal");

// Quan es fa clic en el botó 'exec' es crida la funció 'executar()'
bExec.addEventListener("click", executar);

// Funció que executa l'aplicació
function executar() {
    // Obtenir els 'inputs' del document i guardar-los en variables
    let nom = iNom.value;
    let edat = iEdat.value;

    // Processar les dades
    nom = nom.trim().toUpperCase();
    edat = parseInt(edat);

    // Mostrar el resultat
    terminal.innerHTML = "Hola " + nom + " tens " + edat + " anys";
}
