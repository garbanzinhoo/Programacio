Recursivitat

La recursivitat no és un concepte abstracte que hagi inventat la humanitat.
La natura te nombrosos exemples: les formes fractals.

Aquest és un concepte força complicat però molt útil per resoldre determinats problemes.

Un codi recursiu es pot convertir a codi iteratiu (bucles), i normalment serà més eficient, però en alguns casos pot complicar força el codi.
Quan s'enten com funciona, el codi recursiu pot ser la forma més simple de programar algunes tasques.

Utilitats de la recursivitat

Alguns casos en què pot ser útil la recursivitat:

  • Recórrer una estructura de dades amb diferents nivells i subnivells:
    • Mostrar l'arbre de carpetes d'un sistema de fitxers.
    • Buscar un arxiu dins d'un sistema de fitxers.
    • Llistar tots els elements d'un document HTML.
    • Trobar tots els antecessors d'un element HTML fins arribar a l'arrel del document.
  • Resoldre problemes complexos:
    • Qualsevol problema que es pugui descomposar en parts similars cada cop més petites:
      • Ordenar un gran nombre de paraules: primer separar les que comencen per cada lletra; després, dins de cada grup, separar les que tenen la segona lletra igual, etc...
      • Ordenar factures per data: agrupar les del mateix any; després, dins de cada any, agrupar les que són del mateix mes; finalment, dins de cada mes, agrupar les del mateix dia.
    • Jocs intel·ligents (o no): escacs, 4 en ratlla, Candy Crush....
    • Generar els horaris d'un institut.
    • Generar o resoldre "sudokus".
    • Generar o resoldre laberints.

Funcions recursives

Es diu que una funció és recursiva quan dins del seu codi es fa una crida a sí mateixa.

El problema és que, si una funció es crida a sí mateixa sense aturar-se mai, arribarà un moment que es produirà una excepció per falta de memòria (stack overflow).
Per tant, s'han de programar assegurant que en algun moment s'aturarà la recursivitat.

Esquema bàsic d'una funció recursiva

La forma general més simple (encara que pot variar una mica depenent del problema) és tenir una estructura condicional que aturi la recursivitat quan s'arribi a una condició determinada (cas base).
En cas contrari s'executarà el codi que torna a cridar la funció (cas recursiu).

Una bona forma de veure què fa la funció recursiva en cada iteració és escriure els arguments que rep.

Exemple 1: càlcul del factorial d'un número enter

Aquest és un cas que es pot resoldre fàcilment amb un bucle, però també és fàcil de fer-ho recursivament i entendre com funciona.

A més, es pot veure clarament que es tracta d'un càlcul recursiu:

El factorial de N és N multiplicat pel factorial de N-1 (cas recursiu) fins que N = 1 (cas base).

Codi utilitzant un bucle

long n = factorial(5);

static long factorial(long n) {
    long r = n;
    while (n > 2) {
        --n;
        r *= n;
    }
    return r;
}

Codi recursiu

long n = factorial(5);

static long factorial(long n) {
    if (n == 1) {    // Cas base
        return n;
    } else {         // Cas recursiu
        return n * factorial(n - 1);
    }
}

Off the record, si algú es pregunta per a què serveix calcular el factorial... els factorials s'utilitzen per calcular permutacions, i a partir d'aquí es poden calcular probabilitats.
Per exemple, si tenim 9 cartes (de l'1 al 9) i agafem 3 a l'atzar, quina probabilitat hi ha de que sumin 12 o més?

Exemple 2: cerca binària en un array ordenat

Codi utilitzant un bucle

int n[] = {3,4,6,9};
int posicio = cercaBinaria(n, 6);

static int cercaBinaria(int[] array, int valor) {
    int min = 0;
    int max = array.length - 1;
    int mid = 0;

    while (min <= max) {
        mid = (min + max) / 2;
        if (array[mid] < valor) {
            min = mid + 1;        // Agafar la meitat superior de la llista
        } else if (array[mid] > valor) {
            max = mid - 1;        // Agafar la meitat inferior de la llista
        } else {
            break;                // Valor trobat
        }
    }

    if (array.length > 0 && array[mid] == valor) return mid;
    else return -1;
}

Codi recursiu

int n[] = {3,4,6,9};
int posicio = cercaBinaria(n, 6);

static int cercaBinaria(int[] array, int valor) {
    return cercaBinariaRecursiva(array, valor, 0, array.length - 1);
}

static int cercaBinariaRecursiva(int[] array, int valor, int min, int max) {
    if (min > max) {    // Cas base
        return -1;      // No s'ha trobat el valor
    } else {            // Cas recursiu
        int mid = (min + max) / 2;
        if (array[mid] < valor) {
            // Buscar en la meitat superior de la llista
            return cercaBinariaRecursiva(array, valor, mid + 1, max);
        } else if (array[mid] > valor) {
            // Buscar en la meitat inferior de la llista
            return cercaBinariaRecursiva(array, valor, min, mid - 1);
        } else {
            return mid; // Valor trobat
        }
    }
}
