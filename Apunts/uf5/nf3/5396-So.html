So en Java

Reproduir so

Clip ref. (Java SE 17)

Una de les formes de generar so és carregar i reproduir un arxiu de so.
Els tipus d'arxius d'àudio que es poden utilitzar són AIFF, AU o WAV.

Primer de tot, cal carregar l'arxiu:

public static Clip carregarSo(String path) {
    Clip so;

    try {
        java.net.URL soundURL = ClassLoader.getSystemResource(path);
        if (soundURL == null) return null;

        Line.Info linfo = new Line.Info(Clip.class);
        Line line = AudioSystem.getLine(linfo);
        so = (Clip) line;
        AudioInputStream ais = AudioSystem.getAudioInputStream(soundURL);
        so.open(ais);
        return so;
    } catch (LineUnavailableException lue) {
        System.err.println("No s'ha trobat l'arxiu: " + path);
        return null;
    } catch (UnsupportedAudioFileException uafe) {
        System.err.println("Format d'àudio no soportat: " + path);
        return null;
    } catch (IOException ioe) {
        System.err.println("Error d'entrada/sortida: " + path);
        return null;
    }
}

Després, cada cop que es vulgui reproduir:

so.setFramePosition(0);
so.start();

Utilitzant altres mètodes de la classe Clip es poden reproduir fragments del so, repetir N vegades tot el so o només una part, saber la durada, el format o si s'està reproduint...
