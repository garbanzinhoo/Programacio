JDBC

Gestor de bases de dades relacionals (SQLite)

Fes un programa (mode consola i/o escriptori) que permeti realitzar les següents tasques:

  • Obrir una base de dades de SQLite.
  • Mostrar les seves taules.
  • Per cada cada taula, mostrar les dades que conté i el tipus de dada que conté cada camp.
  • Mostrar un diàleg que permeti introduir una consulta SQL i executar-la.
  • Obrir un arxiu amb comandes SQL i executar-les.
