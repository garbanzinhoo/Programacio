CRUD i DAO

Facilitar la conversió entre objectes i registres

Utilitzar patrons o esquemes estàndard com MVC facilita la creació de projectes grans millorant la independència entre el diferents mòduls que han de ser creats per un equip de programadors.
També facilita el manteniment, sigui pel mateix equip que els va crear o per altres programadors diferents.

Quan es tracta d'emmagatzemar les dades, sigui en una BD, en un arxiu o fins i tot en estructures de dades en memòria (llistes, diccionaris...), també és convenient utilitzar algun dels següents patrons.

CRUD

Les accions bàsiques que es poden realitzar amb un objecte o un registre d'una BD són:

  • Create
  • Read
  • Update
  • Delete

Una forma senzilla de realitzar aquestes accions entre objectes i registres és crear una interfície amb mètodes abstractes que s'hauran d'implementar en les classes que tinguin el seu equivalent en taules de la base de dades.

Els mètodes que s'hauran d'implementar seran les quatre accions CRUD:

  • boolean create(): afegir un registre a la taula corresponent amb les dades de l'objecte.
  • boolean read(): buscar el registre a partir de l'identificador de l'objecte i guardar les dades en els atributs de l'objecte.
  • boolean update(): buscar el registre a partir de l'identificador de l'objecte i guardar en el registre els atributs de l'objecte.
  • boolean delete(): buscar el registre a partir de l'identificador de l'objecte i eliminar-lo.

Si s'implementen dins de la mateixa classe, no caldrà passar les dades de l'objecte a aquests mètodes.

Exemple

public interface CRUD {
    boolean create();
    boolean read();
    boolean update();
    boolean delete();
}

public class Departament implements CRUD {
    int id;
    String nom;

    // Constructor
    public Departament(int id, String nom) {
        this.id = id;
        this.nom = nom;
    }

    // Setters & Getters
    public void setId(int id) { this.id = id; }
    public void setNom(String nom) { this.nom = nom; }
    public int getId() { return id; }
    public String getNom() { return nom; }

    // Mètodes CRUD
    @Override
    public boolean create() {
        String query = "INSERT INTO departaments (id,nom) VALUES (?,?)";
        int r = SQLRW.write(query, id, nom);
        return r > 0;
    }

    @Override
    public boolean read() {
        String query = "SELECT nom FROM departaments WHERE id=?";
        List<Object[]> r = SQLRW.read(query, id);
        if (r == null || r.size() != 1) return false;
        nom = (String)((Object[])r.iterator().next())[0];
        return true;
    }

    @Override
    public boolean update() {
        String query = "UPDATE departaments SET nom=? WHERE id=?";
        int r = SQLRW.write(query, nom, id);
        return r > 0;
    }

    @Override
    public boolean delete() {
        String query = "DELETE FROM departaments WHERE id=?";
        int r = SQLRW.write(query, id);
        return r > 0;
    }
}

DAO

Per aconseguir una major independència entre dades i mètodes, i possibilitar la creació de diferents interfícies depenent de si les dades s'han de guardar en una BD, un arxiu o en memòria, pot ser convenient crear una classe a part per cada tipus d'objecte amb mètodes estàtics als quals s'hauran de passar les dades dels objectes i retornar objectes o valors booleans per indicar el resultat de les accions.

També es poden afegir altres mètodes: comprovar si existeix un registre determinat, quants registres hi ha, obtenir tots els registres, fer consultes que obtinguin més d'un registre...

public interface DAODB<T> {
    // CRUD
    boolean create(T t);
    boolean read(T t);
    boolean update(T t);
    boolean delete(T t);
    // ALTRES
    boolean exists(T t);
    int count();
    List<T> all();
}

public class Empleat {
    int id;
    String nom;
    Date dn;
    int dep;

    // Constructors
    public Empleat(int id) {
        this.id = id;
        set(null, null, -1);
    }

    public Empleat(int id, String nom, Date dn, int dep) {
        this.id = id;
        set(nom, dn, dep);
    }

    public Empleat(Empleat e) {
        this.id = e.id;
        set(e.nom, e.dn, e.dep);
    }

    public void set(String nom, Date dn, int dep) {
        this.nom = nom;
        this.dn = dn;
        this.dep = dep;
    }

    @Override
    public String toString() { return id + " | " + nom + " | " + dn + " | " + dep; }

    // Setters & Getters
    public void setId(int id) { this.id = id; }
    public void setNom(String nom) { this.nom = nom; }
    public void setDn(Date dn) { this.dn = dn; }
    public void setDep(int dep) { this.dep = dep; }
    public int getId() { return id; }
    public String getNom() { return nom; }
    public Date getDn() { return dn; }
    public int getDep() { return dep; }
}

public class EmpleatDAODB implements DAODB<Empleat> {
    // CRUD
    public boolean create(Empleat e) {
        String query = "INSERT INTO " + taula + " (id,nom,dn,dep) VALUES (?,?,?,?)";
        int r = SQLRW.write(query, e.getId(), e.getNom(), e.getDep(), e.getDep());
        return r > 0;
    }

    public boolean read(Empleat e) {
        Empleat er = read(e.getId());
        if (er == null) return false;
        e.set(er.getNom(), er.getDn(), er.getDep());
        return true;
    }

    public Empleat read(int id) {
        String query = "SELECT nom,dn,dep FROM " + taula + " WHERE id=?";
        List<Object[]> r = SQLRW.read(query, id);
        if (r == null || r.size() != 1) return null;
        Object[] o = r.iterator().next();
        return new Empleat(id, (String)o[0], Date.valueOf((String)o[1]), (int)o[2]);
    }

    public boolean update(Empleat e) {
        String query = "UPDATE " + taula + " SET nom=?,dn=?,dep=? WHERE id=?";
        int r = SQLRW.write(query, e.getNom(), e.getDn(), e.getDep(), e.getId());
        return r > 0;
    }

    public boolean delete(Empleat e) {
        String query = "DELETE FROM " + taula + " WHERE id=?";
        int r = SQLRW.write(query, e.getId());
        return r > 0;
    }

    // ALTRES DAO
    public boolean exists(Empleat e) {
        return read(e);
    }

    public int count() {
        String query = "SELECT COUNT(*) FROM " + taula;
        List<Object[]> r = SQLRW.read(query);
        if (r == null || r.size() != 1) return -1;
        Object[] o = r.iterator().next();
        return (int)o[0];
    }

    public List<Empleat> all() {
        List<Object[]> l = SQLRW.read("SELECT * FROM " + taula);
        if (l == null) return null;

        List<Empleat> le = new LinkedList<>();

        Object[] o;
        Empleat e;
        for (Object[] object : l) {
            o = object;
            e = new Empleat((int) o[0],
                    (String) o[1],
                    o[2] == null ? null : Date.valueOf((String) o[2]),
                    (int) o[3]);
            le.add(e);
        }

        return le;
    }
}
