Llenguatge Java

JavaScript

Aquest és un llenguatge interpretat i és el més utilitzat en la programació de webs dinàmiques en la banda del client.

També és un llenguatge orientat a objectes i a esdeveniments (events).

JS proporciona les funcions necessàries per manipular documents HTML:

  • Afegir, modificar i esborrar contingut.
  • Afegir, modificar i esborrar atributs dels elements.
  • Modificar els estils del document.
  • Mostrar, amagar i moure elements.
  • Reaccionar davant les accions de l'usuari i altres esdeveniments.

Eines per fer programes amb JavaScript

Editors

Qualsevol editor de text pla (tipus Bloc de notes) pot servir, però és convenient que inclogui les següents característiques:

  • Marcar amb diferents colors les paraules reservades del llenguatge.
  • Eines avançades per buscar i substituir text.
  • Autotabulació (autoindentació).
  • Marcar i comprovar inici i final de parèntesis i blocs.
  • Agrupar (amagar) i desagrupar blocs de codi.
  • Autocompletar comandes i noms de variables i funcions.

Alguns exemples poden ser:

  • Notepad++
  • GEdit

Navegadors

Alguns navegadors disposen d'eines que faciliten la depuració dels programes.
Entre d'altres opcions, inclouen l'execució pas a pas, punts d'aturada, visualització de variables...

  • Chrome
  • Firefox
  • Edge

Hi ha una versió especial de Firefox anomenada Firefox Developer Edition especialment pensada pel desenvolupament web.

També és recomanable provar els programes amb els navegadors Opera i Safari.

Altres eines

  • GitHub: web de desenvolupament, documentació, control de versions...
  • Visual Studio Code: eina de desenvolupament que permet la gestió de versions amb Git.
    Permet instal·lar extensions, per exemple Live Server per obrir una pàgina HTML en un servidor local.
