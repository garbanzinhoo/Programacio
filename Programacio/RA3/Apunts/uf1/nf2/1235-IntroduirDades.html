Quan es treballa amb el terminal, cal que l'usuari pugui introduir dades escrivint-les pel teclat.

Per fer que el programa s'aturi i esperi que l'usuari introdueixi les dades cal:

  • Importar una llibreria: import java.util.Scanner.
  • Crear un objecte d'aquesta classe: static Scanner scan = new Scanner(System.in).
  • Utilitzar algunes de les seves funcions i guardar el resultat en una variable: s = scan.nextLine().
Exemple

import java.util.Scanner;

public class Main {
    static Scanner scan = new Scanner(System.in);

    public static void main(final String[] args) {
        // Codi del programa
        String nom;
        System.out.print("Com et dius? ");
        nom = scan.nextLine();
        System.out.println("Hola " + nom);
    }
}

Tractar les dades introduïdes

De vegades, els usuaris escriuen espais al principi o al final de la resposta que no s'han de tenir en compte.
O cal que la resposta sigui en majúscules però l'escriuen en minúscules o barrejant majúscules i minúscules.

Per aquests casos hi ha dos mètodes que es poden aplicar a les respostes per evitar errors en el processament posterior:

  • toUpperCase() (o toLowerCase()): converteix tot a majúscules (o a minúscules).
  • trim(): elimina els espais que pugui haver al principi i al final del text.
Exemple

String capital;
System.out.print("Quina és la capital de Portugal? ");
capital = scan.nextLine();
capital = capital.trim();
capital = capital.toUpperCase();
if (capital.equals("LISBOA")) System.out.println("Correcte!");

També es podria haver fet amb menys instruccions:

capital = scan.nextLine().trim().toUpperCase();

Mètodes per llegir diferents tipus de dades

L'objecte creat (scan) inclou mètodes per poder llegir les dades introduïdes de diferents formes.

Llegir tot el què ha escrit l'usuari

El mètode scan.nextLine() llegeix tot el text introduït amb el teclat, incloent l'INTRO que s'ha de prémer al final, i retorna un text que s'ha de guardar en una variable de tipus String:

String nomCognoms;
...
nomCognoms = scan.nextLine();

Quan el programa arribi a aquesta línia, esperarà fins que rebi un salt de línia (INTRO), i guardarà el text en la variable nomCognoms.

També es pot utilitzar per llegir un valor numèric, però s'ha de convertir després de llegir-lo:

int edat = Integer.parseInt(scan.nextLine());

Si el què ha escrit l'usuari no és un número, es generarà una excepció i es tancarà el programa.

Llegir només fins que trobi un separador (espai, tabulador, intro...)

Els següents mètodes salten els separadors que pugui haver-hi fins al primer caràcter vàlid i llegeixen els caràcters vàlids fins a trobar un caràcter separador (aquest separador no es llegeix, queda pendent).

Si queden caràcters pendents, es llegiran amb la següent comanda next???().

  • scan.next(): retorna un text (sense separadors) que s'ha de guardar en una variable String.
  • scan.nextInt(): converteix el text llegit a un número enter i s'ha de guardar en una variable int.
    Si el text no es pot interpretar com un número enter, es genera una excepció i es tanca el programa.
  • scan.nextFloat(): converteix el text llegit a un número real de precisió simple (float).
    Si el text no es pot interpretar com un número real, es genera una excepció i es tanca el programa.

També es pot utilitzar amb Boolean, Byte, Short, Long o Double.

Es poden utilitzar quan s'introdueix més d'una dada en la mateixa línia:

System.out.print("Introdueix el teu nom i la teva edat: ");
// Suposant que l'usuari escrigui John 35
nom = scan.next();        // Llegeix John i ho guarda a la variable 'nom'
edat = scan.nextInt();    // Llegeix 35 i ho guarda a la variable 'edat'
scan.nextLine();          // Llegeix el salt de línia que ha quedat pendent

És important afegir al final un scan.nextLine() per què no quedin caràcters pendents que puguin ser llegits erròniament en una lectura posterior.

El següent codi sembla que funciona correctament (al menys fins que s'hagin d'introduir més dades):

System.out.print("Introdueix el teu nom: ");
String nom = scan.nextLine();
System.out.print("Introdueix la teva edat: ");
int edat = scan.nextInt();
// Aquí cal afegir scan.nextLine();

El següent codi no funciona (cal afegir scan.nextLine() després de int edat = nextInt()):

System.out.print("Introdueix la teva edat: ");
int edat = scan.nextInt();
// Aquí cal afegir scan.nextLine();
System.out.print("Introdueix el teu nom: ");
String nom = scan.nextLine();

Llegir només un caràcter

Per llegir només un caràcter, es pot utilitzar:

  • scan.next().charAt(0): llegeix fins que troba un separador però només agafa el primer caràcter.
  • scan.nextLine().charAt(0): llegeix fins un salt de línia però només agafa el primer caràcter.

Suposant que l'usuari escriu "   Hola   " (sense les cometes), amb el primer cas, saltarà els espais inicials, llegirà només Hola (quedaran pendents 3 espais i el Intro final) i agafarà la H; en el segon cas, llegirà tot el text, incloent l'Intro final, i agafarà el primer caràcter, que és un espai.

En tots dos casos, el caràcter llegit s'ha de guardar en una variable de tipus char:

char opcio;
System.out.print("Tria una opció (A, B o C): ");
opcio = scan.nextLine().charAt(0);

Comprovar si la següent dada és d'un tipus concret

Quan l'usuari ha d'introduir més d'una dada en la mateixa línia, es pot fer una comprovació abans de llegir cada dada per assegurar-se que és del tipus correcte i evitar que el programa s'aturi al intentar llegir-la.

Els mètodes, que s'han d'utilitzar amb un objecte de tipus Scanner, són:

  • hasNext(): comprova si hi ha més dades per llegir.
  • hasNextInt(): comprova si la següent dada és un número enter.
  • hasNextFloat(): comprova si la següent dada és un número real.

També hi ha els equivalents per a short, long i double.

En el següent exemple es veu com es poden utilitzar (s'ha d'utilitzar un condicional, una estructura que es veurà més endavant):

String nom;
int edat;
System.out.print("Escriu el teu nom i la teva edat separats per un o més espais: ");
nom = scan.next().trim();
if (scan.hasNextInt()) edat = scan.nextInt();
scan.nextLine();
