Classes i objectes

Crear i treballar amb objectes

Constructor d'objectes

Al definir una classe amb la qual es puguin crear objectes, cal definir un constructor (una funció amb el mateix nom que la classe i, opcionalment, paràmetres que defineixen l'objecte):

public class Persona {
    // Atributs privats de l'objecte (no són estàtics)
    String nom;
    int edat;

    // Constructor
    public Persona(String _nom, int _edat) {
        nom = _nom;
        edat = _edat;
    }

    // Mètode públic de l'objecte (no és estàtic)
    public void mostrarDadesPersona() {
        System.out.println("Nom: " + nom);
        System.out.println("Edat: " + edat);
    }
}

Alguns IDEs tenen la capacitat de crear automàticament un constructor, els getters i els setters a partir dels atributs de la classe.

En el cas de IntelliJ cal obrir el menú Code o el menú contextual i triar l'opció Generate...
En el cas dels getters i setters, es pot triar quins es volen crear.

Crear objectes

Per crear objectes d'una classe cal definir una variable de la classe corresponent, utilitzar la paraula new i cridar el constructor de la classe amb els paràmetres adequats:

Persona persona1 = new Persona("Mary", 18);
Persona persona2 = new Persona("Peter", 20);

Utilitzar els objectes

Per utilitzar els mètodes d'un objecte, s'ha de posar al davant el nom de la variable que el conté.

persona1.mostrarDadesPersona();
persona2.mostrarDadesPersona();

Scanner és un exemple de classe per crear objectes que serveixen per llegir dades seqüencialment:

// Objecte per llegir dades introduïdes amb el teclat
Scanner scan = new Scanner(System.in);
int n = scan.nextInt();

// Objecte per llegir dades d'un arxiu de text
Scanner reader = new Scanner(new File("arxiu.txt"));
String l = reader.nextLine();

Paraules especials relacionades amb els objectes

La paraula reservada this

Aquesta paraula es pot utilitzar per distingir variables locals dels atributs de l'objecte si tenen el mateix nom:

public Persona(String nom, int edat) {
    this.nom = nom;
    this.edat = edat;
}

La paraula reservada null

Aquest és el valor que han de prendre les variables quan no estan assignades a cap objecte.
Si s'intenta fer alguna operació amb un valor nul, es produirà l'excepció NullPointerException:

Persona p = null;
if (p == null) System.out.println("La variable no està assignada a cap objecte");
String nom = p.getNom();   // NullPointerException

En el cas de String, no és el mateix assignar una cadena buida ("") que un valor null.

String s = "";
if (s.isBlank()) System.out.println("La cadena està buida o només conté separadors");
if (s.isEmpty()) System.out.println("La cadena està buida");
s = null;
 if (s.equals("")) System.out.println("La cadena està buida"); // NullPointerException
